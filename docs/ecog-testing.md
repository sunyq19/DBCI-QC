# ECoG 接入与测试

适用版本：1.0.0rc3.dev2。ECoG 基础路线为 `ecog-basic/1`；本页说明软件测试流程，非临床质量标准。末节保留dev1的真实计算验收。

## 1 页面入口

统一入口为 `http://127.0.0.1:8769/`，不预选模态。上传后提取信息；FIF的明确类型可预填ECoG建议，确认本次分析通道后载入对应方法。BrainVision默认EEG类型不能代替模态声明。已登记示例从统一记录列表直接载入；旧`?modality=ecog`地址保留兼容，不作为数据证据。

模块详情进入 `/standards/ecog/modules/M01` 至 `M09`；规范总览为 `/standards/ecog`。英文文档在路径前加 `/en`。文档“返回质控台”和 Alt+Q 返回 ECoG 页面；通过报告返回时保留对应模态及任务。

## 2 准备公开样例

```bash
python scripts/public_examples/prepare_ecog_example.py --output /path/to/ecog-examples
```

脚本下载固定 MNE 官方镜像，核对大小及 SHA-256；保存原 BrainVision、BIDS 侧车和许可；另外生成全长 double FIF，不滤波、不重参考、不重采样、不删道。文件均位于指定仓库外目录。

| 文件 | 用途 |
| --- | --- |
| `upload-samples/MNE_ECoG_pt1_raw.fif` | 最简上传测试；原生类型声明89道ECoG与9道MISC |
| `upload-samples/MNE_ECoG_pt1_BrainVision.zip` | 原格式三件套接入测试；必须依据配套说明选择89道ECoG |
| `additions.json` | 两份格式示例的登记草案，含明确选道和临床点事件 |
| `independent-reader.json` | 原始字节解码与两个读取器的全长逐样本比较 |
| `conversion-lineage.json` | FIF转换来源、类型、事件及数值一致性证据 |
| `dataset-review.json` | 单位、时长、来源标签和语义事件核对 |

两份格式属于同一位受试者的同一记录，不能作为两个独立样本。实际共269080个采样点、1000 Hz，区间长度269.080秒；源侧车的269.079对应最后采样时刻。记录包含89道ECoG和9道MISC，分析不按名称推断ECG角色。原始坏道标记保留，不用于删道或算法判断。

## 3 最简测试

1. 进入质控台首页，上传上述FIF。
2. 核对98道总通道、89道建议分析通道、1000 Hz和269.080秒；显式确认模态为ECoG，参考不清楚时保留未知。
3. 确认推荐的M03、M04、M05及必要接入/报告模块。M06显示未接入，不能启用。
4. 先运行短窗，检查报告中的完整性候选、频谱、触点描述及未评原因。
5. 再选择整份检查，核对120秒、120秒和29.080秒三个窗口，完整覆盖269.080秒。
6. 从报告返回任务，检查模态及配置是否保留；再载入一份EEG记录，确认系统自动切换方法，历史记录仍全部可见。

直接上传只读文件内信息，不自动加载外部的7个临床语义点事件。预登记示例默认分析60–180秒，并带明确的事件表，因此推荐包含M07。原29条BrainVision非结构事件和7条语义事件并非同一计数口径；点事件不自动拼成发作区间。

## 4 结果解释

ECoG M03定位非有限及相邻精确恒值样本；M04输出Welch PSD及可测窄带描述；M05提供逐触点统计。它们不复用头皮PREP、LOF、桥接、α评分或肌电阈值。高频、强幅值和病理活动不自动标为坏数据，分项执行完成率不作质量分，总分保持null。

原文件头给出的nV标定与读取器数值可以互相核对，BIDS侧车单位为未提供。数值一致不代表源采集物理标定、病理解释或检测准确率已经独立核实。具体方法边界见[ECoG技术约定](ecog/qc-standards.md)。

来源：[MNE ECoG临床示例](https://mne.tools/stable/auto_tutorials/clinical/30_ecog.html)、[OpenNeuro ds003029](https://openneuro.org/datasets/ds003029)。版本与文件指纹见[固定示例清单](../datasets/ecog-examples.json)。
