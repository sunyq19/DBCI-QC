# EEG 方法分项与数据标签

2026-10-29，工作台 0.4。九个顶层模块保留，详情中列出24个方法/功能分项：16个基础或条件分项、5个已接入的可选方法、3个尚未接入的方法目录。24项不等于24个独立的伪迹检测算法。预登记有8份真实记录，来自5个公开数据集；见[数据说明](public-examples.md)。工具箱可独立浏览方法，再由明确的数据条件生成可修改的推荐。

## 三类分项

| 分类 | 意义 | 例子 |
|---|---|---|
| 通用 | 在当前头皮EEG接入范围内通常需要；仍须满足输入条件 | 文件核验、连续性、功率谱、分项汇总 |
| 条件 | 需要特定技术条件或配套材料 | EOG/ECG锁时线索、同参考组坏道线索、睡眠分期对齐 |
| 可选 | 默认关闭的增强方法；已经接入的才有开关 | MNE平线、高频线索、桥接、LOF、autoreject全局阈值 |

分类与运行状态是两件事。分类说明方法的位置，执行计划说明本份数据能否做；实际结果另外记录完成、条件受限、跳过或失败。条件不满足必须保留原因，不能变成满分。基础及条件分项随所属模块执行，五个可选扩展提供方法级独立开关。

## 标签怎样决定适用性

当前每份数据显示18项标签。技术标签来自已登记的原始技术头、明确选道及配套材料，不能通过背景下拉框伪造。未知不自动补全。

| 标签 | 对检查的影响 |
|---|---|
| 模态、格式 | 当前登记范围为头皮EEG、连续EDF；不声称已支持其他模态/格式 |
| EEG通道数、采样率、电压单位 | 决定数值是否可比、哪些频率可评、标定是否可用 |
| EOG、ECG、EMG辅助导联 | 分别决定相关锁时证据和EMG支持是否可用；未配置不表示原文件绝对没有 |
| 参考比较组 | 相对坏道判断只在已声明的比较组内进行；4道是现有实现默认门槛，可以显式提高 |
| 参考构型（新增） | 分清共同参考、连接耳、双极、混合和未知；桥接与LOF目前只允许前两类，且要求单一完整比较组 |
| 睡眠分期、任务事件、临床事件（新增） | 决定M07哪些核对可做；填“睡眠”或“癫痫”标签不能代替实际标注文件；这些标注都不是伪迹真值 |
| 电极位置 | 未来空间预测、局部插值及空间解释所需；不凭通道名赋予坐标 |
| 滤波处理史 | 高采样率不保证高频仍被保留；未知处理史只支持探索性高频输出 |
| 疾病、年龄、任务 | 记录解释背景及来源，供后续分层验证；本版不改变阈值或分数，不构成平台作出的诊断 |

疾病背景包括未知、健康对照、癫痫、睡眠障碍、帕金森病、脑卒中、其他神经系统疾病、其他。年龄和疾病在没有来源材料时保持未知；登记场景中“adult”一词不被当作受试者年龄证据。Sleep-EDF和CHB-MIT的新记录根据官方队列/病例说明登记背景，并保存依据。任务默认来自登记的实验场景，可人工更正。背景变动会生成新计划标识，旧报告保留原背景及来源。

## 五个已接入的可选方法

### MNE相邻采样变化/平线

调用[annotate_amplitude](https://mne.tools/stable/generated/mne.preprocessing.annotate_amplitude.html)。检查相邻样本的变化，并非固定窗口峰峰值；同时保留时间标注和通道建议，不能把零条时间标注误读为没有通道候选。

初始参数：`peak_volts=null`（突变阈值未启用）、`flat_volts=0`、`min_duration_seconds=0.1`、`bad_percent=5`。0.1秒是项目研究参数；5%是软件默认分流规则，均不表示通道临床不可用。通道建议没有精确时段时，输出时段为null，另保留分析范围。

### MNE跨通道高频线索

调用[annotate_muscle_zscore](https://mne.tools/stable/generated/mne.preprocessing.annotate_muscle_zscore.html)。本版固定110–140 Hz，阈值4，间隔合并0.1秒；是软件参数，不是公认临床质量阈值。要求原生采样率高于280 Hz；160/256 Hz数据明确跳过，不自动换频带冒充同一方法。

输出聚合时间候选及分数，不提供单道定位。滤波史未知、缺少同步EMG确认时仅为探索性线索；120 Hz工频谐波也可能影响结果。原始输入复制后计算，不删除原始数据，不自动清洗。非有限/恒定聚合分数保留未评或失败原因，不能当作无伪迹。

### MNE电极桥接候选（本轮新增，M05）

调用[compute_bridged_electrodes](https://mne.tools/stable/generated/mne.preprocessing.compute_bridged_electrodes.html)，检查成对电压差的方差及其分布。输出通道对候选、每个固定段的电气距离（μV²）。只在计算副本上使用0.5–30 Hz滤波，不改写原波形。

默认`lm_cutoff_uv2=16`、`epoch_threshold=0.5`、段长2秒。16是拟合分布的范围上限，不是最终桥接判定阈值。适配器要求已核实共同/连接耳参考、一个覆盖全部所选EEG的比较组、至少8道及10秒、至少5个完整段，采样率须支持指定频带。这些门槛是本项目的保守接入条件，不是行业标准。检测本身不要求坐标；解释邻近关系仍需位置和硬件记录。相似信号不等于已经证实短接，退化分布导致拟合失败时保留失败原因。

### MNE LOF通道离群候选（本轮新增，M05）

调用[find_bad_channels_lof](https://mne.tools/stable/generated/mne.preprocessing.find_bad_channels_lof.html)。比较所选片段各EEG通道的波形向量，输出通道候选、原始负LOF及绝对值；不虚构异常开始/结束时间。

默认邻居数20、欧氏距离、阈值1.5，来自软件默认设置，不是共识坏道阈值。要求共同/连接耳参考、单一完整比较组、至少10秒；通道数须大于邻居数，因此默认至少21道。没有自动缩减邻居数、归一化、重参考或插值。幅值、参考、片段长度和真实病理活动都可能影响结果。本轮两份DS记录分别给出7和18道候选，尚未验证它们是否真是坏道。

### autoreject全局阈值估计（本轮新增，M03）

调用[get_rejection_threshold](https://autoreject.github.io/stable/generated/autoreject.get_rejection_threshold.html)，将当前连续片段划为不重叠的2秒固定段，用5折交叉验证估计一个EEG峰峰值阈值。输出阈值（V）、各段峰峰值、同一选区的超阈值段候选及未使用的尾段。至少需要20个完整段，且不少于`4×cv`；固定随机种子0，不降采样。

这是全局阈值估计，尚未接入local AutoReject、通道插值或试次剔除。固定连续段不是独立任务试次，相邻段有时间相关性；在同一选区拟合和标记候选，不能据此声称独立验证准确率。允许双极导联作探索性运行，但睡眠慢波和癫痫样活动也会影响阈值，因此始终标为`partial`并交给人工复核。疾病标签、发作标注、源坏道标签都不参与此方法计算。

五个方法均复制输入后计算，不执行删除、插值或清洗。时间候选、通道候选、通道对候选分别计数，不汇成“坏数据总数”。

## 三个待接入方法

- [PyPREP RANSAC](https://pyprep.readthedocs.io/en/stable/generated/pyprep.NoisyChannels.html)：需核实位置、参考和足够的可用通道。不能把已安装PyPREP等同于已接入空间坏道预测。
- [local AutoReject](https://autoreject.github.io/stable/index.html)：需分段规则和足够可比试次；local AutoReject的拟合本身就需要有效电极位置，即使只读取建议、不执行插值也一样。有事件文件不等于已具备可交叉验证的试次。已接入的全局阈值功能不能代替它。
- [ICA/ICLabel](https://mne.tools/mne-icalabel/stable/generated/examples/00_iclabel.html)：需检查训练条件，包括平均参考、1–100 Hz和extended-infomax等。分类概率不等于质量分。

MNE、autoreject、MNE-ICALabel采用BSD-3-Clause，PyPREP采用MIT。方法详情保留原项目来源与许可；BrainElecQC许可仍需单独确认。本平台调用本机已有算法包，不复制第三方源码。

## 代码与证据

`src/ephys_qc/tagging.py`负责标签来源；`method_registry.py`负责方法分项和资格条件，`method_descriptions.py`补充原理、解释、来源和验证边界；`recommendations.py`组合可解释推荐；`extensions.py`与`extra_methods.py`负责可选方法适配；`planning.py`冻结配置；`runtime.py`保存实际执行结果。API 0.4与计划/结果1.3结构保留来源、用途和标签，并记录明确的模态来源。旧任务缺少字段时显示未记录，不借用新目录补写历史事实。
