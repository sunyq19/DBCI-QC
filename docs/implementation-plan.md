# 第一版实施与验收

日期：2026年10月28日。首个可运行版本以 EEG 为范围。

| 顺序 | 交付物 | 验收条件 |
| --- | --- | --- |
| 1 | 顶层设计、数据卡和验证矩阵 | 已有、待补与尚未实现内容可区分；数据来源和标签含义有记录 |
| 2 | 接入与计划生成 | 代表性样例的单位、通道和时间读取正确；缺失前提导致明确未评 |
| 3 | 固定 BrainElecQC 基线适配 | 同输入和配置下与原方法输出一致；保留后端指标与分数来源 |
| 4 | 首批独立检测模块 | 每个模块有适用范围、真实输出、异常定位及独立验收数据 |
| 5 | 报告和人工复核 | 指标、波形、异常定位一致；复核决定可保存和导出，不覆写自动结果 |
| 6 | 小规模独立评估 | 校准与评估受试者分离；报告误报、漏检、未评和运行失败 |
| 7 | 可复现发布 | 新环境可按说明安装运行示例；依赖、许可、作者与版本完整 |

第一轮流程数据可使用现有公开静息 EEG 与 PSG 示例。评估检测器需要补独立质量标签；全局评分在有可靠数据和人工判断后单独校准，不能由跑通示例推导为通用标准。

现有工作台暂不搬动，也不改变其算法和评分。先冻结接口、数据说明和基线；后续迁移时逐项核验功能。
