## 云端更新后核对

使用同一发布包更新页面和服务端，保留现有配置、公开源文件挂载及协作持久卷，重建并重启。不要迁移临时上传目录。

1. `/api/v1/health` 返回版本 `1.1.5`。
2. `/privacy` 显示上述日期和主体，没有待填写占位项。
3. `/api/v1/upload-policy` 返回上述协议版本；刷新首页后协议默认未勾选，勾选后才可上传。
4. 使用公开测试文件检查报告、PDF、倒计时及清理；确认另一浏览器看不到该次上传。

GitHub Actions 的容器构建、公开 EEG 验收及完整回归以该次提交的运行结果为准。发布包由固定提交生成，提交号见包内 `RELEASE.json`，下载校验值见 `SHA256SUMS`。公网服务器由部署同事更新。
