日期：2026-11-08。软件：`1.0.0rc3.dev39`。这是公开开发基线，不是正式版或标准审核结论。

## 发布范围

沿 GitHub 已有 `main` 历史补齐源码配套文档、标准草案、测试、安装说明、云部署准备清单和示例展示快照。模块、算法和评分公式没有因本次发布整理而改变。

示例快照：`03a195fecb354d0a`，约 27.1 MiB、256 个展示文件。包含 EEG、ECoG、sEEG、Neuropixels 四类数据集及 13 份记录的报告，并保留 EEG 方案对照；不附原始信号。快照是已有运行的固定展示，不把旧结果重新标记为新方法的计算结果。

未发布本地配置、NAS 路径、个人上传、运行目录、原始数据与旧开发缓存，也未推送本地开发中间历史。共同维护网页的团队说明与固定版本不受此次更新影响。
