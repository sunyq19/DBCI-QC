## 复查入口

```bash
.venv/bin/python scripts/check_release.py
python3 scripts/demo_sample.py --output /tmp/public-eeg
python3 scripts/validate_demo.py --url http://localhost:8769 \
  --edf /tmp/public-eeg/S001R03.edf --output /tmp/demo-acceptance
```

最后一项仅对新建、公共目录为空的验收实例运行，不对已有团队实例执行。GitHub 工作流 `Demo deployment bundle` 从空环境构建并完成同一上传检查。
