# 子方法决定模块启用

日期：2026-11-10。适用：本地与 012 质控台。

## 规则

- M03–M07 为方法分组，没有独立启用开关。任意子方法被选中时父模块启用，全部取消时关闭。
- 基础子方法和扩展子方法均可单独选择。M03 的“缺失、恒值与端点平台”仍是一个方法条目，其内部三类检查未拆为三个选择项。
- 取消子方法后，其计分项从草稿列表移除。选择方法与赋予评分权重仍是两件事，新增可计分方法初始为 0%。
- 高频突发所需的连续性保护可内部执行，不强制启用 M03，不额外产生完整性评分。
- 显式子方法列表只用于新计划；未提供该列表的旧接口保留原有模块配方，已存报告不改写。
