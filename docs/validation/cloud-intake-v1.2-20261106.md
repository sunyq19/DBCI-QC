# 2 GiB 接入策略

日期：2026-11-06。当前默认策略：`cloud-intake/1.2`。

按用户确认，将单文件、单记录含配套、ZIP 展开上限统一提高至 **2 GiB = 2,147,483,648 字节**。数据集仍为 **5 GiB、100 份记录、5,000 个文件**。等于上限允许，超过任一上限拒绝，不自动截断数据。

旧 `cloud-intake/1.0`（512 MiB）和 `cloud-intake/1.1`（1 GiB）保留，历史配置和验收不改写。默认本地网页上传使用 2 GiB；本地登记目录及 CLI 保持原有行为。云端尚未部署。

前后端提示及中英文文档同步更新。算法分窗和内存预算不因上传上限扩大而改变。体积估算和原有样例测量见[多模态体积分析](cloud-intake-v1.1-20261106.md)。

边界验证覆盖 2 GiB 及上限加 1 字节、配套文件合计、ZIP 解压限制、5 GiB 数据集总量和旧策略兼容；1.5 GiB 稀疏文件用于验证实际文件大小判定，不作为完整信号质控性能测试。
