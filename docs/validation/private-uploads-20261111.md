# 临时上传与公开目录验收

## 已验证

- 独立服务与实际 Caddy 代理：上传 → 确认 → 推荐 → 整份检查 → HTML/PDF → 波形查询通过。使用合成信号验证工程流程，不用于证明检测准确率。

- 结束清理删除上传文件、读取信息、修订、日志、结果、图表和报告。异常终止后重新启动，遗留临时上传被清除。

- 全部 Python 回归：857 项通过，10 项因可选环境跳过。目录交互、30 项双语检查和 16 项布局约束检查通过。
- 缓存的四类示例与 234 个已发布文件内容校验通过；来源与许可显示在数据条目下。
