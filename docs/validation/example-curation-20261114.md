## 本轮范围

保留八组公开示例的来源、适用范围及原始结果。总览先呈现数据用途、来源、记录规模、逐份评分与主要发现；资料检查和未评项目放入可展开区域，未知信息仍明确保留。窄屏按记录显示卡片。

只有两份 Allen 小鼠 LFP 新增检查并重新运行，其他记录不调整算法、阈值或历史分数。报告的方法结果表增加已执行的 LF 邻域一致性及 IBL 相干与高频噪声，避免分数出现而方法结果缺席。

## 小鼠示例补查依据

- 上游 [AllenSDK 电极表定义](https://allensdk.readthedocs.io/en/latest/_modules/allensdk/brain_observatory/ecephys/nwb_util.html) 明确 `probe_horizontal_position` / `probe_vertical_position` 单位为微米。
- 原来的裁剪文件保存了位置数值，但没有保存单位说明。新增独立“位置核验版”副本，只补充两列的描述；逐点验证全部电压、时间戳及坐标数值不变。来源清单记录修改前后文件指纹，旧文件和旧报告保留。
- NWB 读取器只接收单位明确且单杆 Neuropixels 1.0 型号明确的几何信息；按 ElectricalSeries 的 electrodes 行索引映射，未知单位或多杆型号不推断。
- 文件保留通道间距为 40 微米，原默认 30 微米半径没有相邻通道。此示例采用 60 微米，纳入紧邻触点而不跨到第二邻居。这个选择由几何条件决定，不以得分为依据；全局默认仍为 30 微米。
- R² 阈值 0.9、20 个 1 秒抽样窗、seed=0 不变。评分仍为数值有效性 30%、通道状态 70%，同一通道同一分析块的候选并集只计一次。
- [AllenSDK LFP 说明](https://allensdk.readthedocs.io/en/latest/visual_coding_neuropixels.html) 表明公开 LFP 已滤波、重参考并抽样。因此示例标明“已预处理的 LFP”，不代表原始 AP 或分选后神经元的质量。

进一步核对电极表：两份文件分别有 12、10 个 `location=unknown` 的触点，均在上述候选中；其余候选分别有 3、5 个已标注脑区的触点。未知脑区不能自行当作脑外电极或坏道，也不能凭得分判断生理质量。示例总览及单份报告均提示此范围。

## 保留的边界

1. 人类 Neuropixels 包含 2/4 秒 AP 与 20 秒 LF 短样本，能演示操作，不足以验证长记录稳定性；页面已显示此范围。
2. 一份灵犀云 EEG 的 PSD 分项缺少足够长的连续干净窗口，维持未评，不填造分数。
3. 公开样本不提供的临床、采集或同组资料仍为未评；资料完整性与信号分数分开。
4. 当前评分为项目方案，尚未完成独立专家校准；高分不代表所有质量问题均被排除。
5. 非 EEG 独立 PDF 和灵犀云全部图表的 PDF 收录尚未完全统一；浏览器打印与 HTML 报告可用。英文扩展方法表仍有中文内容。
