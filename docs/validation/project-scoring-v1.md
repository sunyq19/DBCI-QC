# 项目加权评分 v1 验证记录

2026-11-07 · 实现 `1.0.0rc3.dev16` · 规则 `project-weighted/1.0`

## 已验证

- 分项分数按原始候选量与有效检查量计算；100、60、95 分按 1∶2∶1 汇总为 78.75。
- 权重同比放大不改变分数；负数、非有限数、全零、未知分项及未选择模块的正权重被拒绝。
- 正权重项目缺测、通道身份不完整或整份覆盖不足时不输出总分；零权重的缺测项目仍显示未计分。
- 配置保存在计划中，推荐与执行使用同一配置；修改权重使原计划失效。
- ECoG、sEEG、Neuropixels 不继承头皮 EEG 评分。M08 只聚合，不重复加权；数据集与可视化模块声明不计分。
- HTML、工作台和 PDF 使用同一分项值及权重；历史原文件不改写，评分修订缓存随检测证据变化失效。
- 示例目录只读取任务记录和报告存在状态，不聚合频谱证据。4 组示例共 13 份已存报告链接通过实际处理器检查。

## 实际公开数据

OpenNeuro ds002034 的两份完整 EEG 记录，使用已有检测证据生成明确标注的新评分修订版。等权总分分别为 74.43 和 74.12；第一份工频分项为 23.37。原始检测与历史报告保留。分数变化来自已公布的汇总公式，不修改阈值。

另从第一份公开记录选取 0–30 秒，以 1∶2∶1 权重新执行 M03、M04、M06，实际生成报告，总分为 55.18。该选区结果不能与整份记录直接比较。M06 辅助导联分支仍有缺项，已计算的高频突发有独立证据。

本地示例目录处理约 0.25 秒；这是直接调用服务适配层的测量，不含浏览器渲染或网络开销。报告修订在发布时预计算，浏览时不重新扫描频谱。

## 验证边界

以上支持软件计算、配置与展示的一致性，不证明检测灵敏度、特异度、评分权重的科学有效性或临床适用性。未完成浏览器视觉验收。四类示例是兼容性演示，不能替代其他模态评分的建立和独立数据验证。
