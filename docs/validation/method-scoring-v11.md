# 方法计分与示例缓存验证

2026-11-07 · 软件版本 `1.0.0rc3.dev17` · 计分版本 `project-weighted/1.1`

## 验证范围

本轮检查原方法结果到分项、加权总分、整份汇总及报告的传递。没有重新校准检测阈值，也不将接口测试当作检测准确率或专家一致性验证。

17 项方法提供 18 个输出；EEG 默认仅纳入完整性、工频、高频突发，各权重为 1。其他方法默认权重为 0。可选项、缺项与全零权重、旧版规则、跨模态隔离均有自动检查。原版可选依赖和适用条件仍需满足，计分接口不替代原算法运行环境。

第一组运行声明了用于接口验证的参考与比较组；该声明不代表来源参考已获专家核验。辅助信息不足时，未计分项目继续保留未评状态。整份汇总不把缺项补为满分，不平均大小不同的分析块分数。

公开来源：[EEGMMIDB](https://physionet.org/content/eegmmidb/1.0.0/)；[OpenNeuro ds004584](https://openneuro.org/datasets/ds004584)。不同数据和配置间的分数不作优劣比较。

## 报告与示例交付

- 窗口运行产生 14 个分项输出；HTML 保留各项，PDF 将额外分项置于后续页，不压进首页。
- 首页预置 4 类数据集、13 份记录的中英文报告快照，包含所需图像和样式，EEG 提供预生成 PDF。
- 请求示例时不运行算法、不读取 NAS、不查运行记录；无本地任务目录的处理器测试仍可返回首页及报告。
- 自动核对缓存文件哈希、内部链接、路径边界、原始数据排除和来源说明；路径包含内容版本，服务端使用不可变缓存响应。
- 页面交互以 JavaScript 合约检查验证；本轮没有浏览器视觉验收，也没有部署远端云服务。

示例快照与运行原始证据分开保存；调整新任务权重不改变已发布示例。发布流程见 [工作台说明](../../apps/workbench/README.md)，公式和输出目录见 [项目评分规则](../eeg-scoring.md)。
