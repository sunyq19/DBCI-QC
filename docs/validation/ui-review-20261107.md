# 界面一致性修正与验证

2026-11-07 · `1.0.0rc3.dev18`

## 修正范围

| 问题 | 原因 | 修正 |
| --- | --- | --- |
| 示例、我的数据、检查记录不对齐 | 两个 ID 另设 20px 内边距和 14px 字号，其他入口沿用 0px 与 13px | 统一为 `rail-section`，标题、计数、符号与正文共用规则 |
| 示例卡片拥挤 | 按整页宽度强制两列，未考虑窄侧栏 | 保持单列，长名称换行，手机上操作置于下一行 |
| 展开符号重复 | 打开后的旧前缀优先级高于共享清除规则 | 移除旧前缀，只保留一个加减符号 |
| 检查记录收起后又展开 | 轮询触发的呈现函数反复设置 open | 仅进入活动任务时展开一次，刷新尊重用户选择 |
| 目录失败仍显示加载中 | 异常分支未清理初次加载占位 | 首次失败清理占位；后续失败保留已加载列表 |
| 报告在窄屏撑开页面 | 部分表格缺少自身滚动容器，长文本不可换行 | 表格局部滚动并支持键盘聚焦，导航与长文件名可换行 |
| 模块详情和键盘焦点不一致 | 移动规则权重不足、共享焦点覆盖局部规则 | 小屏输入输出单列，工具箱焦点轮廓保留在容器内 |

## 已完成的检查

- 标准 CSS 解析、实际 DOM 选择器匹配及级联检查：320、480、768、1001、1440px；包含打开/关闭、伪元素、隐藏控件与字体/内边距。
- 工作台 151 项纯 JavaScript 状态检查；数据目录失败恢复与缓存保留检查。
- 数据集交互、审核与复验、报告筛选/标签切换、30 项翻译检查、15 项文档导航检查。
- 86 项 Python 检查涵盖级联、报告结构、数据集汇总呈现、标准页面和示例缓存；旧样式用同一解析器能够复现原始错位。
- 重新发布四类数据集、13 份记录的示例快照，共 144 个展示文件。48 个已有图像/PDF 的内容哈希不变；本次未更改检测或计分结果。

开发者运行方法见 [界面维护说明](../../apps/workbench/web/README.md)。示例发布脚本仅处理已保存结果，不在用户浏览时重新分析。

## 尚未完成的验收

本轮实际尝试浏览器访问本机质控台，被已保存的站点权限设置拒绝。未使用其他浏览器方式绕过。上述检查不测量浏览器实际几何、文字换行或截图效果，不能代替最终浏览器视觉验收。

## 同日补充：悬停与颜色

- 示例卡片和多行数据名称链接移除整块文字的悬停下划线；通过底色、边框和标题颜色反馈。普通文字链接仍保留下划线，键盘焦点仍可见。
- 工作台使用冷灰背景与白色内容区域。蓝色表示操作和运行状态，青绿色表示执行完成，琥珀色表示待复核；完成颜色不代表数据质量合格，状态文字保留。
- 规范文档、报告和打印保留白色纸面，不随工作台背景变更。未更改检查结果、评分、跳转或示例缓存。
- 静态选择器检查覆盖悬停、按下和键盘焦点；11 项布局/报告检查及 151 项 JavaScript 检查通过。主要文字及状态颜色对比度达到 4.5:1。
- Chrome 扩展已连接，并可枚举质控台标签页；此前本地地址的访问拒绝尚未确认解除，本次仍未宣称完成浏览器视觉验收。
