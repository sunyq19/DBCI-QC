# 报告定位、跳转与布局修正

2026-11-07 · `1.0.0rc3.dev20` · 本地验证

## 本次修正

| 用户遇到的问题 | 原因与处理 |
| --- | --- |
| 展开工具箱、模块或接触点表格时页面宽度变化 | 页面滚动条占位不一致，网格受内容最小宽度影响。统一预留滚动条，固定主栏比例，表格在自身区域内滚动。 |
| 报告松散，技术文字抢占重点 | 改为报告概览、检查结果、问题定位、图表分析、方法与依据。压缩字号、间距和边框层级；SHA、运行编号和计算细节放入折叠区。 |
| 不清楚异常在哪个通道、哪个时段 | 定位表给出真实通道标识和原记录时间；点击条目切换对应原始波形，阴影标记候选区间。仅使用已有检测证据中的位置。 |
| 新结果回退到旧版冗长呈现 | 首页补充识别 `eeg-report-view/6`，使用已有紧凑报告组件。 |
| 图表跳转失败或定位不生效 | 缓存发布保留页内锚点；补齐已声明的基础图表；跳转时展开对应图表；嵌入图表返回报告时离开 iframe。 |
| 示例链接看似可点，却没有文件 | 未发布的证据文件改成非链接文字，不再伪装成跳转到快照说明的入口。 |
| 实际运行的图表页首次打开超时 | 直接读取保存的报告摘要，跳过通用结果摘要对大候选索引的逐项遍历。 |
| 导入提示难理解 | 首屏区分一份文件和多份记录 ZIP；配套文件要求及七天保留期放入文件要求。 |

## 验证结果

- 37 项报告测试、11 项可视化测试、8 项缓存及发布测试、7 项 CSS 级联检查通过。
- 151 项工作台 JavaScript 契约检查通过；8 份交互检查脚本覆盖数据目录、数据集、报告、翻译、规范导航和布局。
- 新增定位图交互测试：选择切换、并发请求先后顺序、加载失败、保留新标签打开方式、展开锚点目标。
- 新增图表服务测试：有保存的报告摘要时不得调用通用结果解析，不改变分析窗口和文件声明。
- 示例快照 `81ab4d20d2b1cac3`：4 类数据集、1 项 EEG 方案对照、15 份记录报告、248 个展示文件。所有发布文件哈希、内部资源与锚点目标检查通过。
- 本地 HTTP 检查 81 项全部通过，其中 70 个为缓存 HTML；包含推荐方案、灵犀云方案的实时报告、定位 PNG 及图表入口。
- 重启后两套图表页首次请求耗时分别为 9.10 秒、8.98 秒；此前通用解析路径在相同检查中超过 45 秒超时。此数据仅为本机一次测量，不是服务容量承诺。
- 两份报告返回耗时约 0.05、0.07 秒；首次定位图分别约 1.66、0.63 秒。定位图已检查实际通道标题、原始时间轴、单位与候选阴影。
