# 模块内选择检查方法

2026-11-10，本地与 012 同步。本次交互替代同日早期版本的顶层卡片勾选。

## 交互

- 点击 M03–M07 卡片，在所属流程阶段下展开方法列表；同一时间展开一个模块，卡片和列表均可收起。
- 子方法显示“推荐”“可用 / 部分受限 / 当前不可用”和“可计分 / 仅测量”；受限时给出原因，未接入方法折叠展示。
- 基础方法仍随所属模块运行，明确标记“随基础检查”；扩展方法可以逐项勾选。不能运行的未选扩展禁用，已选扩展仍可取消。
- 推荐标记来自当前数据的默认推荐，与沿用的上次选择分开。勾选扩展不自动赋予评分权重，权重在计分设置中调整。
- 完整方法列表默认折叠，流程图为主要选择入口。历史报告保持只读。

## 条件与状态

推荐接口支持返回未选方法的元数据条件评估，不读取波形、不运行算法。前端只读取建议，不采用其配置；实际运行前仍校验最终方案。更换数据、时间范围和参数后重新核对，切换勾选和权重不重复请求。过期响应不覆盖新数据，核对失败显示错误及重试入口。

修复 ECoG/sEEG 恢复默认方案时，评分要求与预规划空模块列表冲突的问题；恢复后的基础扩展和非零评分权重可直接重新规划。
