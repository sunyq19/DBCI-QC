# LF 邻域复核与页面提示验收

日期：2026-11-14。范围：M05 LF 邻域一致性展示、读取与检查结果页面、问题定位。

## 行为与接口

- LF 检查属于通道级判定：分析范围不是异常起止时间，不对整段波形涂色。
- 定位接口的可选 `comparison` 来自运行时冻结的 M02 坐标、针柄和 M05 半径。自动带出同针柄、距离严格小于半径的实际邻居，并标识邻居的已存分类。缺坐标不猜测。
- 原版返回分类，不返回逐通道 R²。本轮未补造 R²，也未更改算法、0.9 阈值、30 μm 半径、抽样参数、评分或权重。
- 首屏保留判定、邻居及波形；算法解释折叠。通道按采集顺序排列。
- 确认后进入“检查方案”。完成页收起执行明细、重复警告及流程图，隐藏新运行控件。分项结果默认展开；合并项中的方法放在该项下面，避免误写成“不计入”。

## 测试中发现并解决

1. 图注缩短后原测试仍匹配旧句子：按保留的实际语义更新断言。
2. 临时上传测试中 HTTP 响应体已到达但处理线程尚未释放请求占用，提前推进模拟时钟导致偶发失败：测试夹具等待请求结束再推进时间。生产清理策略没有修改。
3. 前端测试把所有节点映射到同一对象，隐藏元信息时误判为隐藏结果：改为分别模拟对应节点。
4. 执行覆盖测试要求固定冗长免责声明：改为验证“已计算”、失败、未执行及数据间隙数值明确，不含“合格”表述。
