# 云端接入限额：本地实现与验收

日期：2026-11-06。策略：`cloud-intake/1.0`。

已实现可独立调用的限额核心、现有文件上传校验，以及登记目录/记录任务的可选限额模式。仍在本机运行，尚未接入阿里云、OSS 上传、身份隔离或断点续传。

## 1 实现范围

| 对象 | 限额 | 服务端行为 |
| --- | --- | --- |
| 单文件 | 512 MiB | 上传前检查声明长度，接收后核对实际文件；登记目录检查实际大小 |
| 单记录及配套 | 512 MiB | ZIP 按展开大小检查；多文件格式根据读取器与绑定资料累计 |
| 数据集完整目录 | 5 GiB | 统计实际文件总量，包括清单外文件和隐藏目录文件 |
| 记录 | 100 份 | 合并清单记录与目录内发现的受支持主文件；缺件保留计数，不通过漏填清单绕过 |
| 普通文件 | 5,000 个 | 统计展开后的实际文件数 |

记录发现包含 EDF/BDF 文件头识别，不只看后缀。无法读出配套关系时，以同目录文件总大小作为保守上界，证据标明 `directory_upper_bound`，不冒充已确认关系。该规则可能保守拒绝部分大目录；可明确组织记录目录后再提交，或使用本地模式。

超限返回 HTTP 413，含策略、超限字段、实测值和上限；不创建任务、不生成报告、不修改输入。登记任务保存接入证据及文件状态指纹，执行前重新核验，新增、删改或超限时停止。状态指纹基于路径与文件状态，不代替已有的内容 SHA-256 核验，也不是云端不可变对象证明。

保留单记录 ZIP 至多 64 条目的既有规则；拒绝嵌套压缩包和符号链接，限制目录遍历条目数为 20,000。未来云端上传展开后的快照须满足相同要求。

## 2 自动验收

新增 23 项接入测试，覆盖：

- 各项恰好上限、超过 1 字节/1 记录/1 文件，以及非法计数类型。
- 真实文件大小与伪造清单大小、清单外文件和非标准后缀 EDF。
- 多个小文件累计超过 5 GiB，读取器配套及表格合计超过单记录上限。
- ZIP 体积小但展开超限、嵌套压缩包、失败后不保留半成品。
- HTTP 413、上传请求体尚未读取时拒绝、拒绝后没有任务。
- 排队后目录发生变化即停止，原有登记记录不能绕过单记录限额。
- 正常范围进入 D01–D03，并保存报告和接入证据；本地模式保留大目录处理能力。

5 GiB 边界使用稀疏文件验证逻辑字节数，不实际分配 5 GiB 内存或宣称完成 5 GiB 波形计算。完整回归通过 544 项 Python 测试、142 项工作台 JS 检查、30 项中英文检查、15 项文档导航检查、12 项布局契约及数据集页面状态检查。浏览器视觉效果不在本次验收范围内。

复现：在项目科学计算环境运行 `python scripts/check_release.py`。本地完整日志：`.local/admission-release-check.log`；真实数据结果：`.local/admission-20261106/real-packages.json`，两者不随公共仓库发布。

这里计算全部目录文件，包含本地 `.qc` 等资料，所以数量和字节数大于先前只统计交付清单的结果。最大的已核验记录及配套合计 508,732,106 字节（约 485.16 MiB），低于 512 MiB。ds003029 中已有结构问题的记录使用目录保守上界，仍低于限额。数据原件未修改。

另以独立本机 HTTP 实例启用此策略，对上述两组公开子集实际完成“提交 → 接入判定 → D01–D03 后台执行 → HTML 报告”流程，12 份 EEG 和 7 份颅内记录的任务均完成，报告接口均返回 200。结果及运行目录索引保存于 `.local/admission-20261106/http-smoke.json`；该临时服务已关闭，不占用现有工作台端口或运行目录。

接入允许只说明规模在界限内，不表示质量合格。本轮没有再次执行完整信号算法；数据集规则与已知问题见[数据集一致性验收](dataset-consistency-20261106.md)。

## 4 启用与后续

本机配置增加 `"admission_policy": "cloud-intake/1.0"` 即可启用；省略或设为 `local` 保持本地目录模式。也可通过 `server.py --admission-policy cloud-intake/1.0` 指定。使用独立运行目录进行验证，不与当前服务共享任务状态。

后续必须实现并验证：OSS 对象版本与最终收据核验、分片/续传后的完整快照、多用户配额预留、持久队列与认证隔离。现有限额模块是这些流程的共同判定入口，不能替代它们。

设计依据见[顶层设计 v1.0](../design/platform-v1.md)，接口说明见[工作台文档](../../apps/workbench/README.md)。
