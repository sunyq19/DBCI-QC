## 实际数据

OpenNeuro ds002034 sub-01，733 秒、512 Hz；同一原始文件的基础方案与灵犀云扩展方案。

| 查看范围 | 对照数 | 两套报告的波形接口响应 |
| --- | --- | --- |
| 40–50 秒 | 1 道 | 0.383–0.388 秒 |
| 30–60 秒 | 3 道 | 0.412 秒 |
| 673–733 秒（文件末尾） | 6 道 | 0.456–0.460 秒 |

以上是本机单次 HTTP 读取时间，不是浏览器帧率或并发容量承诺。原文件共有 82 个同采样流通道，其中本次 QC 选择 62 道；对照目录保留其他源通道，不将其自动纳入 QC 或计分。

- 六次读取均按通道标识与原生采样时间，逐点回查原始读取器输出；数值及物理单位换算一致。
- 两份原结果的文件大小与修改时间保持不变；综合分仍分别为 74.42835030157782 和 98.36856938273846。
- 超过 60 秒、超过 6 道、越过文件末尾的请求均返回明确输入错误；旧波形 API 仍保留 10 秒限制。

## 自动检查

- Python：原生时钟、非零样本原点、连续段缺口、重复通道名、冻结来源变化、无来源验证、64 MiB 限制、显示点数及不重算 PSD。
- JavaScript：平移和窗宽缩放边界、精细移动、同步对照、同单位共用幅度刻度、无效值断线、名称转义、串行读取、过时响应、拖动松手后读取、回到候选与失败回退。
- 报告与快照：通道标识和时间属性转义；公开静态示例移除原始信号浏览地址，保留保存的图片；原有图表折叠和候选静态切换继续通过检查。
