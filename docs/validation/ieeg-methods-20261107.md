## 真实运行改变了默认选择

FieldTrip原版差分z值在这些记录上返回大量很短的区间。结果可能同时包含技术异常、发作及真实神经活动，目前没有独立质量标签可区分其准确率。因此保留原始参数和输出，将方法作为显式选择的“跳变复核”，不加入默认基础方案，也不为减少候选调整阈值。报告显示总数和累计时长，候选详情折叠，首屏不展开数千条。

MNE返回的合并时间标注保留原定位范围，未编造对应单道。平线结果包含记录末尾片段，这可以帮助复核，但不能仅凭它断言接触不良。

## 分组规则验证

在真实MNE pt1第一窗的89触点上执行分组测量，试验池只用于验证数值路径，不作为已确认解剖分组。参考可比性保持false：89道有测量，无离群判定、无分数。源资料缺少分组或参考时，不补造元数据以获得“可计分”结果。

独立模拟测试覆盖首通道异常、通道换序、组间增益变化、无参考、通道不足、恒值/MAD为零、非有限及文件端点连续长度。它们验证实现，不构成颅内坏道敏感度/特异度验证。
