# 同址演示部署核验

日期：2026-11-11。范围：将质控台与模块协作整理为可迁移的同址部署；不改质控算法和评分规则。

## 结构

- 一个反向代理入口，`/` 进入 Python 质控服务，`/flow/` 及协作 API 进入 Node.js 服务。
- 质控运行记录与协作 SQLite/附件分别持久保存；源码发布不包含用户运行目录。
- 模块实现目录从质控代码生成。团队草稿修改不自动改变计算配置，固定版本不被实现更新覆盖。
