# 数据集完整性与一致性首版验收

日期：2026-11-06。规则：dataset-consistency/0.1。工程执行验收，不是医院分级验收或算法准确性验证。

## 已实现

- D01：事先清单、文件指纹、缺件和记录结构。
- D02：编号及配套表对应、单位/采样率/通道/事件、个体内重复记录。
- D03：显式组内配置、配套表结构、重复文件线索。
- 独立 Python/CLI、后台任务、单份记录/数据集切换、个体汇总、可展开证据、HTML/JSON 导出及规则页面。

## 实际数据结果

| 案例 | 规模 | 预期与结果 |
| --- | --- | --- |
| ds003555 v1.0.1 原包子集 | 2 人、12 记录、49/49 文件 | 原始与派生分开比较；空单位保留复核；6 份事件表有超出宽界的索引，原始行号可查 |
| ds003029 v1.0.7 原包子集 | 3 人、7 记录、51/51 文件 | 6 份 ECoG 的源单位与通道表不符；1 份 sEEG 末尾采样帧不完整；重复记录采样率一致 |
| 人工缺件副本 | 3 人、7 记录、50/51 文件 | 缺少指定 channels.tsv 被检出；依赖该表的比较未评 |
| 人工采样率冲突副本 | 3 人、7 记录、51/51 文件 | 一份通道表改为 500 Hz：文件头/表、个体内、数据集同组比较各检出一项冲突 |
| 恢复原通道表副本 | 3 人、7 记录、51/51 文件 | 逐项状态恢复到原包基线；上游已有问题仍保留 |

异常副本使用新的本地测试清单并标明修改文件；原始发布清单保留。对两份原包的 100 个来源文件进行前后 SHA-256 比较，确认未改动。

## 自动验证

完整回归通过 521 项 Python 测试及既有前端契约检查。新增 17 项 Python 测试覆盖真实 EDF 读取、合法子集、跨文件冲突、缺失字段、事件边界、原始/派生分组、颅内布局差异、后台任务与 HTTP 边界。

新增前端状态测试覆盖范围确认、提交、结果显示、转义、语言切换和过期提交响应。修改标准返回导航后，文档链接和导航测试再次通过。

本机服务已通过 API 实际完成上述五次任务，保存独立结果；报告、下载、冻结清单及标准页面路由均可访问。浏览器工具被已保存的权限设置拒绝访问 localhost，因此本轮未完成浏览器截图、几何布局和键盘走查，不能将接口测试视为视觉验收。

## 复现与边界

按[数据包运行说明](../dataset-inventory.md)下载固定子集、生成明确方案并执行 `validate_package_consistency.py`。核心检查不针对数据集 ID 分支；只有样例方案映射脚本使用对应目录约定。

尚未实现：任意数据包的网页上传和方案编辑、真实身份核验、跨植入期电极映射、医院最终分级、人工签署、自动增量复验、脱敏和完整 BIDS 验证。当前检查不读取 MRI/CT 配准。
