# 质量检查与计分组成联动

2026-11-10，本地与 012 同步。

## 交互与边界

- “计分组成”直接放在“02 质量检查”下方、“03 结果与报告”之前；左侧不再保留重复的评分编辑器。
- 选择方法时同步显示计分项目、百分比权重和预计占比。新增可计分方法初始为 0%，不会自动改变既有评分组成。
- 调整一个项目的百分比，其余已有非零权重按比例分配；0% 项保持不计入。全部设为 0% 时只展示检查结果。
- 已知不可执行的项目保留配置权重，但预计占比为 0%；其余有效项目重新分配。部分受限项目显示“待运行确认”，不能仅因部分受限就推断没有有效得分。最终计入情况由运行结果决定。
- sEEG 的数值有效性、信号稳定性、频谱分项分别保留 30%、50%、20% 默认权重。稳定性子项可展开调权重，只通过汇总项计入一次；全部子项权重为 0% 时，汇总项预计不计入。
- Neuropixels 通道状态展开显示合并项目，维持原有去重汇总方式。历史报告不显示可编辑权重。
- 本次修改选择与展示逻辑，不修改检测算法、评分公式或历史结果；“预计占比”不是预计质量得分。
