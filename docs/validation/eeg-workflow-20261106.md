# EEG 检查、复核与批量流程验收

日期：2026-11-06。流程图固定版本：`workflow-v14`；处理范围：`processing-scope/1.0`；报告视图：`eeg-report-view/4`；批次：`signal-batch/1`；比较：`report-comparison/1`。

## 实现范围

1. 首次读入及记录修订共用处理史声明，保存高通、低通、陷波及来源说明；检查方案按子方法列明适用条件。
2. 结果区分为概览、问题复核、可视化。基础及灵犀云候选可定位原始波形，并查看原生采样计算的局部 Welch PSD；人工结论独立留痕。
3. 数据集已确认记录可预览批量方案，确认后后台逐份运行；保存父子任务、报告、失败原因及取消状态。
4. 保存的 EEG 报告按条件和版本分组比较；条件未知、不同或只有一份报告的组独立展示。缺项不补零，不跨组排名。

## 展示与限制

- 已在公开协作网页核对 v1.4 固定版本、展开层级及新增“处理史与检查范围”详情。v1.0–v1.3 源码中的固定快照保持不变。
- 本机浏览器地址仍被已保存的浏览器策略限制；本轮通过代码和直接执行器验证本机流程，未完成本机浏览器视觉或医生操作验收。
- 两份公开数据的可运行性不能替代专家判据和评分校准。评分公式仍为项目试行 `eeg-basic-screen/0.2`。
- 长记录的完整候选证据较大，首次汇总和比较仍有读取开销；摘要缓存不替代后续持久化索引与性能优化。
- 云端队列、身份隔离、敏感字段处理、自动清洗及跨模态评分仍在 TODO 中；本轮不宣称完成。
