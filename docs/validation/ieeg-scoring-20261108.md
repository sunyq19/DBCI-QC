# ECoG / sEEG 默认评分验收

日期：2026-11-08。软件版本：1.0.0rc3.dev37。基础方案：ieeg-basic-recipe/0.3。评分规则：ieeg-score/0.1。

## 评分配置

ECoG和sEEG分别保存`ecog-basic-score/0.1`与`seeg-basic-score/0.1`，初版均为数值有效性30%、信号稳定性70%。稳定性取有效相关方法的最低分，原始证据不再独立加权。全部分析段先按各方法实际分子分母汇总，再合成稳定性。

权重可调；无有效结果的分项权重自动归零，其余有效权重重新归一化。全部不可用或执行范围不完整时没有总分。相关方法重复计权在配置入口和汇总入口均被拒绝。详细定义见[颅内评分规则](../ieeg-scoring.md)。

- 六份报告均显示两项计分、有效权重、综合分和可展开的稳定性依据；逐项核对加权公式和最低证据分。
- 六次运行均已进入本地“我的数据”。相同HUP064和HUP060输入各归于同一个数据条目，方案和运行分别保留，历史报告不覆盖。
- 六份报告、图表接口及报告中的波形图片返回HTTP 200；中英文报告、规则页可访问。四个顶层折叠区为检查结果、问题定位、图表分析和报告详情。

- 本次没有浏览器视觉验收。已有浏览器访问限制仍存在；接口、页面结构与交互逻辑检查不能替代实际浏览器显示检查。
