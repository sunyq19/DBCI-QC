# 数据归档验证 · 2026-11-10

## 功能范围

- 归档单位是“我的数据”中的一份记录或一个数据集。同一数据的重复上传、确认版本及不同检查方案统一处理。
- 归档状态保存在服务端；可恢复，报告仍可访问。归档后不能启动新检查，需先恢复。
- 永久删除仅允许从归档发起，先预览范围再确认；预览之后内容变化则要求重新确认。
- 一并清理关联任务、报告、数据集审核记录、批次和独占上传副本。外部数据目录、原文件、其他条目仍引用的副本不删除。
- 数据删除标记先持久化，文件清理失败可重试；服务重启不复活已删记录。保留不含报告内容或来源路径的简短删除记录。
- 归档不改变上传副本的 7 天保留规则。

## 自动验证

`tests/test_library_lifecycle.py` 使用隔离的临时上传副本及报告，覆盖：

1. 同一数据多方案整体归档、恢复和重启后状态保持。
2. 删除必须先归档和确认，过期预览不能删除。
3. 单文件、确认修订、数据集任务及关联批次统一清理。
4. 运行中的检查禁止操作，共用文件和外部原文件得到保留。
5. 清理失败后重试、配置记录不复活、重新上传相同文件可正常使用。
6. HTTP 接口中归档数据从当前目录与任务历史隐藏，报告仍可读；恢复可见，删除后报告不可访问。

`tests/check-data-library.mjs` 覆盖列表切换、归档报告、删除预览、取消确认、清空范围和错误反馈。另执行数据读取、数据集审核、部署、界面结构、中英文及版面相关回归检查。

最终 Python 回归：89 项测试、31 项子测试通过；界面契约 168 项、中英文 30 项、版面 15 项及数据目录交互检查通过。
