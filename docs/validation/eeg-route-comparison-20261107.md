# EEG 两种方案实际运行记录

日期：2026-11-07。目的：在同一份真实 EEG 上展示当前推荐方案与灵犀云扩展方案的检查内容、报告和可视化区别。

## 1. 输入与运行范围

- 数据：[OpenNeuro ds002034 v1.0.3](https://openneuro.org/datasets/ds002034/versions/1.0.3)，`sub-01 / ses-01 / task-offline / run-01`，公开注意任务数据，CC0。
- 文件：`sub-01_ses-01_task-offline_run-01_eeg.edf`；62 个 EEG 通道；512 Hz；完整 0–733 秒。
- 来源配套 JSON 声明连接耳参考、硬件带通 0.01–250 Hz、软件滤波 `n/a`、电源频率 50 Hz；未配置 EOG、ECG、EMG。
- 两方案均分为 7 个不重叠分析块：前 6 块各 120 秒，末块 13 秒。未裁掉记录末尾。
- 原文件 SHA256：`7edb1d6b813cf0b9c33e1b627f3181f8a9a2fb56603d6be3aca0879281a45f2e`。

## 2. 方案差别

| 项目 | 当前推荐方案 | 灵犀云扩展方案 |
| --- | --- | --- |
| 共同流程 | M01–M09；包含 MNE 幅度补充检查 | 保留相同共同流程 |
| 新增方法 | 无 | 线长、伪差区间、低频异常、高频异常、频带功率、频带幅值、PSD 通道差异、参考范围 |
| 计分项 | 完整性、工频、高频突发，等比例 | 灵犀云线长、伪差、低频、高频、PSD 差异，等比例；共同流程分项不进入此汇总 |
| 数据处理 | 基础检测读取确认后的原信号 | 灵犀云各方法使用分析副本：256 Hz、1–70 Hz、共同平均参考；不覆盖原始数据 |
| 频域输入 | 原始 Welch PSD 及工频证据 | 默认筛除伪差后保留连续超过 10 秒的片段；拼接用于 1–40 Hz 频域计算 |

灵犀云原版来源：[GnosisNeuroDynamicSE](https://github.com/Gnosis-Neurodynamics/GnosisNeuroDynamicSE)，登记提交 `3547548bb81e1e1e2bc90226add5574437921c0c`，SignalQualityEval 3.0.0。当前封装不执行 ICA，也不按某项候选自动删除后续分析通道。

两个汇总分使用不同检查项、不同分析信号，不能用于判断哪种算法更好，也不能据此宣称数据被改善。灵犀云五项汇总为平台自定义的评分适配，并非提供方发布的官方评分公式。

灵犀云 8 项 × 7 块共 56 次方法执行：51 次完成，4 次不满足条件，1 次统计不可用。前 6 块的 8 项均完成；限制集中于末尾 720–733 秒：

- 伪差筛选后最长净片段为 5.43 秒，频带功率、频带幅值、PSD 差异、参考范围因而未评。
- 高频方法上游 `get_power_ratio` 出现指数溢出并返回非有限统计量；适配层拒绝将其作为有效结果，记录 `Degenerate band statistic`。
- 线长、伪差、低频方法完成。共同完整性检查在此末块也检出约 0.56 秒的恒值线索。

未评项目没有被写成 0 分或满分，也没有仅对成功的前 6 块凑出整份总分。频谱有效输入为前 6 块筛选后合计 646.90625 秒；它与整份任务执行覆盖 733 秒含义不同。
