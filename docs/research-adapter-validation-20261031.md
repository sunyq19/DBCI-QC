## 2. 应保留的负结果

在上述EEG选区，逐道相对RMS变化的中位数分别为CleanLine约0.0185、ASR约0.0120、Zapline-plus约0.815。ASR使用与校准相同的高通副本作为变化基准；各方法输入处理不同，不能将这些数值排成算法优劣。

Zapline-plus的上游最终诊断仍为`proportionBelowLower=1.0`，高于其允许比例0.005；sigma已调到5，仍去除1个成分。上游日志多次指出处理过强。本平台现将这一最终诊断直接写入扩展摘要和报告。

这个案例支持保留为研究评估，不支持自动清洗：工频功率显著下降并不证明神经信号保留。没有使用改动后的副本重新计算基础QC，也没有删除原始数据。

ASR校准使用此选区中的前30秒，为明确的探索性测试选段，不是已由专家标注的干净基准。校准矩阵、滤波器、秩、实际样本范围和SHA256均保存；运行成功不验证该段干净。

## 3. 自动验证

- Python自动回归包含原有全套契约及新增研究适配测试。新增测试实际调用上游FASTER、SpikeInterface和已配置的四项Octave路径，不用模拟函数代替算法执行。
- 合成异常覆盖：FASTER按特征命中注入的异常通道；SpikeInterface按不同shank保留候选身份并固定抽样种子；FieldTrip命中注入跳变并验证一基闭区间到秒时间半开区间转换。
- 清洗评估覆盖：CleanLine对注入工频的效应及不足滑窗尾部声明；Zapline-plus固定chunk的配置与已知工频效应；ASR校准状态、前后基准和原始输入不变。
- 拒绝覆盖：NaN、恒值、数据事实与数组矛盾、错误模态、LF误用、缺shank、未知参考、低采样率、缺执行环境、无效参数、未确认ASR校准、整记录自动重校准。
- 原有工作台、翻译、文档导航和布局静态检查保留。未进行新的浏览器视觉或键盘验收；不据静态检查声称完成视觉QA。

命令：

```bash
python scripts/check_release.py
python scripts/validate_research_adapters.py \
  --asr-engineering-calibration --output /path/to/new-acceptance.json
```

第二条命令使用已登记的四份公开样例，参数标志明确表示ASR校准只是工程试运行。支持`--input-id`复跑指定样例，已有证据文件不会覆盖。新部署应先安装运行依赖并登记来源相同的数据；不能只复制输入ID。

本地验收目录内保存`acceptance-01.json`、`acceptance-02.json`和两次补充验收清单，清单包含任务ID、报告URL、源指纹、选区、状态及证据URL；每份报告目录保留HTML、JSON和PNG。公共仓库只保留本说明和验收脚本，不提交数据、本机目录、服务任务日志或临床标注。
