## 1 采用原则

公开规范中的模块划分、字段、执行状态、覆盖口径和版本规则为项目规定。下列外部资料用于编制参考，未整体列为规范性引用文件；不据其名称宣称合规、认证或临床有效性。

标准原文的“应”“宜”及适用范围分别记录。目录信息不代替正式正文，临床指南不代替团体标准，软件默认值不转化为行业合格线。实现参数与运行限制保留在模块说明，不写入通用规范。

## 2 来源核验与条款映射

以下内容由规范 0.2 的资料性附录转存。条款映射按规范 0.3 的章节范围核对；外部资料状态与版本的核验日期为2026年10月29日。

### 2.1 数据集质量与管理

**YY/T 1833.2—2022《人工智能医疗器械 质量要求和评价 第2部分：数据集通用要求》**，现行，2023年7月1日实施。适用对象为人工智能医疗器械数据集。§4.1.1–4.1.4（正文第3–4页）支持数据形态、用途、版本、采集依据和标注流程的说明；§4.1.1.7的计算机化文档管理为推荐要求。对应本文件4.1、4.2、7.3、8章。

[官方目录](https://hbba.sacinfo.org.cn/stdDetail/ad8c7508b67bea44c82a1d0dd7f749d35b7b258990738862da863ef34317ad30) · [官方全文](https://app.nidc.org.cn/jianybz/bz_file_pdf/wwgk/ylqxtjxhybz/2022/20220720/YYT183322022.pdf)

### 2.2 脑电数据集采集与追溯

**YY/T 2029—2026《脑机接口医疗器械 用于人工智能算法的脑电数据集质量要求与评价方法》**，2027年9月1日实施，本版编制时尚未实施。适用对象为相应 BCI 医疗器械数据集。§5.1、§5.2.1–5.2.9（正文第2–3页）、§6.3–6.5、§7.4、§7.7（正文第6–10页）为电极、采集、处理、标注和追溯提供前瞻参考；§5.2.6、§8.2.2的噪声核对依据为责任方声明值，不构成统一坏道阈值。对应4.2–4.5、5.4、6.1、8章。

[官方目录](https://hbba.sacinfo.org.cn/stdDetail/866eaadd4e5c255fdb8e12030faa6b574a71658ab56fa22d356104c3561fd11b) · [官方全文](https://app.nidc.org.cn/jianybz/bz_file_pdf/wwgk/ylqxtjxhybz/2026/2026-10/2c9048cca08f981001a12512f7a54d97.pdf)

### 2.3 临床记录与报告

**CAAE 2022《临床脑电图技术操作指南》**为专家指南。指南九§1–3（期刊第38–39页）支持检查资料、状态、背景及事件描述；该类临床内容不使研究质控报告自动具备诊断效力。对应4.2、5.9、6.3。

**IFCN/ILAE 2023 Routine and sleep EEG: Minimum recording standards**适用于其规定的非急诊常规及睡眠临床 EEG 场景。其临床采集建议不直接作为所有研究数据的拒收线。对应4.2和4.4的场景适用原则。

[CAAE 官方全文](https://www.caae.org.cn/Public/Uploads/20220118/video/61e6242d78ca7.pdf) · [IFCN/ILAE 正式论文](https://doi.org/10.1016/j.clinph.2023.01.002)

## 3 模块验证项目示例

下表是验证设计参考，不是已完成验证的声明。实际验收应给出输入、预期行为、结果和适用范围。

| 模块 | 验证项目 | 主要验收证据 |
| --- | --- | --- |
| [M01 接入核验](/standards/modules/M01) | 不同技术头、单位、采样率、重名通道与损坏文件 | 独立读取对照、错误输入处置、原始指纹 |
| [M02 检查计划](/standards/modules/M02) | 缺条件、依赖补齐、配置变更及未知信息 | 可重建计划、适用性理由和版本一致性 |
| [M03 完整性](/standards/modules/M03) | 已知非有限、恒值与端点平台；正常低幅对照 | 原始坐标定位、分类、原始数据保全 |
| [M04 频谱](/standards/modules/M04) | 已知频率成分、50/60 Hz、谐波及带宽不足 | 频率/单位一致性、可测范围和未评原因 |
| [M05 通道质量](/standards/modules/M05) | 可比参考、少导、桥接及独立坏道标签 | 候选与标签对照、误报/漏检、适用条件 |
| [M06 生理伪迹](/standards/modules/M06) | 辅助导缺失、锁时结构、高频及病理对照 | 时间定位、支持证据、确认性与探索性输出区分 |
| [M07 事件核对](/standards/modules/M07) | 点事件、区间、重叠、越界和覆盖缺口 | 原始与映射时间、异常行及未知覆盖 |
| [M08 汇总](/standards/modules/M08) | 未评、重叠、不同覆盖及无校准情形 | 分母可复算、状态不混淆、无伪造总分 |
| [M09 报告](/standards/modules/M09) | 图、表、JSON和人工修改的一致性 | 通道/时间/单位对应，原判与修改均可追溯 |

## 4 实现边界与维护规则

- 模块登记项包含数据接入、计划、标注核对、汇总和报告，不全部属于独立算法。已接入与待接入分别记载。
- 当前执行限于已确认的头皮 EEG 连续 EDF/EDF+ 选区；软件支持范围不能由规范条款反向推定。
- 当前没有校准总分和人工复核回写。规范对总分及人工修改的要求是启用这些能力时的约束，不代表功能已经提供。
- 数据来源标签、任务事件、睡眠分期和临床事件不等同于技术伪迹真值。工程一致性与独立检测准确率分开记载。
- 版本 0.3 压缩规范正文并转移编制材料，未增加数值合格阈值。后续改变判据、适用条件或算法时，应同步核对模块说明与验证证据。
