# M03 信号完整性

模块说明 · 适用实现：工作台 1.0.0rc2 · 文档版本：0.2

本模块定位非有限样本、精确恒值和文件标定端点平台，并提供可选的相邻采样变化与固定段幅度检查。输出是待复核候选，不自动删除通道或时段。

[关联规范](/standards#53-m03-信号完整性) · [前置模块：M02 数据画像与检查计划](/standards/modules/M02) · [下游模块：M06 生理伪迹线索](/standards/modules/M06)

## 1 用途与适用范围

适用于已完成电压标定的头皮 EEG 选区，用于发现影响数值分析的缺失、恒值及异常幅度线索。精确恒值与有变化但幅度较低的生理信号不同；文件量程端点平台也不能直接证明硬件饱和。

本模块可单独选择；当选择 M06 时自动加入，以向高频检查提供完整性保护区间。

## 2 输入与前置条件

依赖 M02。输入为所选 EEG 的标定电压、原生采样率、原始通道索引、样本起点，以及文件声明的数字和物理量程。辅助 ECG/EOG/EMG 不作为本模块 EEG 判定目标。

不同方法各自核验最短窗口和样本数量。某项扩展不满足条件时保留原因，不能用基础完整性检查完成来替代扩展的执行状态。

## 3 处理流程与方法

### 3.1 缺失、恒值与端点平台（已接入）

BrainElecQC 扫描连续非有限样本和相邻有限值严格相等的区间。恒值判断容差为零，最少样本数为 `max(2, ceil(0.1 × fs))`；非有限区间不受该恒值最短时长限制。

已找到的恒值段依次检查是否靠近文件标定端点、是否近零，再保留其他恒值类别。近零容差结合电压阈值和量化步长，端点容差结合量化步长与数值精度。近零阈值只用于恒值段分类，不是整段低幅度 EEG 的合格线。

### 3.2 MNE 相邻采样变化 / 平线（可选，已接入）

调用 `mne.preprocessing.annotate_amplitude`，计算相邻样本差的绝对值。平线条件使用差值不大于阈值，峰值条件使用差值不小于阈值；这不是固定窗口峰峰值检查。

达到坏段占比路由阈值时，可返回整通道候选；其余命中可形成时间注释。整通道候选未必带有异常起止区间，不应补造时间定位。

### 3.3 autoreject 全局阈值估计（可选，已接入）

调用 `autoreject.get_rejection_threshold`，将当前连续选区划为固定、不重叠的小段，估计全局峰峰值阈值，再描述哪些固定段超过该阈值。这里的小段不是原实验的任务试次。

当前结果始终保留探索性限制：阈值拟合与描述来自同一选区，内部交叉验证不等于独立数据验证。该扩展不调用删段或插值流程。

### 3.4 local AutoReject 试次质量估计（待接入）

目录保留该方法及来源，当前不执行。后续接入需充分的试次数、可靠的通道位置以及适当的验证设计；不能把已接入的全局阈值估计称为完整 local AutoReject。

## 4 输出与解释

基础证据文件为 `M03_continuity.json`，可选扩展另保留实际运行结果。

| 输出或量 | 单位与定位 | 如何解释 |
| --- | --- | --- |
| `candidates`、`kinds` | 原始通道索引、秒、样本半开区间 | 区分非有限、端点平台、近零恒值与其他恒值 |
| 恒值或端点值 | V；可显示 µV | 对照文件量程与量化步长，不直接认定硬件损坏 |
| MNE 幅度候选 | 通道候选或时间候选 | 两类输出不同，不能用通道数冒充区间数 |
| 全局阈值 | V | 当前选区估计的峰峰值阈值，不是通用临床阈值 |
| 固定段候选 | 段索引、原始时间 | 仅表示超阈固定段，不代表任务试次失败 |
| 自动排除记录 / 计数 | 详细产物中 `automatic_exclusions` 为空列表；模块摘要计数为 0 | 原始通道与信号没有自动删改 |

候选数量为零只能说明本次条件下未检出这些定义的候选，不证明不存在断连、伪迹或其他完整性问题。一般重复数据块检测尚未实现。

## 5 配置参数

以下均为当前实现配置，不是行业合格线。实际报告应保留本次采用值。

| 方法 | 参数 | 当前默认与来源 |
| --- | --- | --- |
| 基础恒值 | `min_constant_seconds` | 0.1 s，BrainElecQC 默认；最少 2 点 |
| 恒值分类 | `near_zero_volts` | `1e-7 V`，即 0.1 µV；并考虑半个量化步长 |
| 端点分类 | `endpoint_tolerance_lsb` | 0.25 个量化步长，并考虑浮点精度 |
| MNE 幅度 | `flat_volts`、`peak_volts` | 0 V、未启用；传入上游 `flat`、`peak`，作用于相邻差值 |
| MNE 幅度 | `min_duration_seconds` | 0.1 s，本平台覆盖值；传入上游 `min_duration`，不同于上游默认 0.005 s |
| MNE 幅度 | `bad_percent` | 5%，上游通道与时间注释路由参数 |
| 全局阈值 | 固定段、交叉验证 | 2 s、5 折；平台适配默认 |
| 全局阈值 | 随机种子、降采样因子 | 0、1；不做降采样 |

全局阈值适配器允许 1–256 条 EEG，固定段 1–10 s、交叉验证 2–10 折；完整段数至少为 `max(20, 4 × 折数)`，默认至少 40 s。固定段长度须能映射到整数原生采样点，未满一段的尾部不纳入。MNE 幅度检查至少需要两个样本，并须能在窗口内形成设定时长的相邻差值区间。

## 6 验证与使用限制

基础检查已核对已知恒值、非有限值、量程端点和原始时间坐标等边界；可选扩展已有真实公开记录的执行证据。上述结果支持实现与接口行为，不构成自然伪迹检出准确率或临床灵敏度验证。

全局阈值对当前窗口、通道组成和生理幅度分布敏感；病理波形也可能超阈。M03 不诊断病因，不将临床或来源坏道标签作为检测输入，也不根据候选自动修复数据。
