# M06 生理伪迹线索

模块说明 · 适用实现：工作台 1.0.0rc1 · 文档版本：0.2

本模块利用 ECG/EOG 辅助信号观察 EEG 锁时响应，并检查高频突发及 EMG 支持证据。它区分生理事件、一般高频线索与辅助导联支持的候选，不把单一相关性或高频能量自动认定为伪迹。

[关联规范](/standards#56-m06-生理伪迹线索) · [前置模块：M02](/standards/modules/M02) · [完整性依赖：M03](/standards/modules/M03)

## 1 用途与适用范围

适用于已确认角色的头皮 EEG 与同采样时钟辅助信号。ECG、EOG、EMG 条件分别检查；某类辅助信号缺失时，该类证据未评，不能解释为没有对应伪迹。

本模块不执行 ICA 清理、回归去伪迹或自动删段。一般高频突发在缺乏 EMG 支持时仅作为线索；即使有 EMG 支持，仍需结合原始波形和事件背景复核。

## 2 输入与前置条件

依赖 M02 和 M03。输入包括所选 EEG 电压、明确的 ECG/EOG/EMG 辅助导联、原生采样率、原始时间坐标，以及 M03 完整性候选。

M03 区间用于高频检查的保护机制，降低缺失、恒值边界等造成的误导。所选 EEG 与辅助导联须具有相同原生采样率；当前不做跨流时钟对齐或重采样。辅助角色信息不能替代采集参考信息。

## 3 处理流程与方法

### 3.1 ECG 锁时证据（已接入）

直接调用 MNE `find_ecg_events` 检测 ECG 事件，再由 BrainElecQC 汇总对应 EEG 片段。默认 ECG 检测频带为 5–35 Hz，使用自动 QRS 阈值；自动搜索中的事件率启发式不用于判定心率正常与否。

围绕事件提取 −0.5 至 +0.5 s 的完整 EEG 片段，保留原始标定 EEG，不额外基线校正、重参考或拒绝片段。输出锁时均值、中位数、标准误和幅度描述。检测到心搏事件本身不等于 EEG 已受心电污染。

### 3.2 EOG 锁时证据（已接入）

直接调用 MNE `find_eog_events`，默认检测频带为 1–10 Hz。阈值未显式设置时，采用滤波后 EOG 峰峰值的四分之一。随后按与 ECG 相同的 EEG 锁时框架生成证据。

有足够事件时计算拆半与奇偶事件平均波形的一致性，用于观察重复性；不设统一相关系数或幅度合格线。缺少 EOG、频带不足或无事件分别记录。

### 3.3 高频突发与 EMG 支持（已接入）

这是 BrainElecQC 组合方法，使用 MNE 的滤波与 Hilbert 原语，不是直接调用 `annotate_muscle_zscore`。在副本中抑制可测工频及谐波，提取每条 EEG 的高频包络，标准化并平滑，再按滑动窗联合检查包络、功率增幅、非工频成分、频带覆盖和尖跳集中程度。

M03 完整性候选、局部恒值以及窗口边缘形成保护范围。满足联合条件后才生成一般高频候选；若同采样时钟 EMG 的包络强度及相关性同时支持，则标记为 `emg_supported_burst`，否则为 `high_frequency_burst`。

### 3.4 MNE 跨通道高频线索（可选，已接入）

直接调用 `mne.preprocessing.annotate_muscle_zscore`。当前固定检查 110–140 Hz，对各 EEG 的 Hilbert 包络作标准化，再跨通道汇总和平滑，产生时间候选。

该结果是跨所选通道的全局时间线索，没有单通道定位。已知采集滤波不保留目标频带时阻断，滤波史未知时保留受限状态；成功运行仍按探索性结果解释。120 Hz 等工频谐波可构成混杂。

### 3.5 ICA 成分 / ICLabel（待接入）

当前没有 ICA 分解、ICLabel 分类或自动成分删除。接入前需核对数据秩、有效坐标、参考、滤波及模型训练适用条件；不能以目录存在该方法宣称已完成成分级伪迹识别。

## 4 输出与解释

基础证据文件为 `M06_auxiliary_events.json` 和 `M06_muscle.json`，MNE 高频扩展另保留实际结果。

| 输出 | 单位或定位 | 如何解释 |
| --- | --- | --- |
| ECG/EOG 事件 | 原始秒时间、样本坐标、事件数和每分钟事件率 | 生理事件检测，不是伪迹真值 |
| EEG 锁时波形 | 均值、中位数、标准误为 V | 同时查看事件数量及完整片段覆盖 |
| 锁时幅度与一致性 | 峰峰值、去直流 RMS 为 µV；相关系数无量纲 | 描述重复响应，没有统一污染阈值 |
| 高频候选 | 原始通道与时间窗、功率 µV²、包络标准分等 | 多条件筛查证据，不自动确定病因 |
| EMG 支持 | 包络峰值与相关性、参考状态 | 有支持与无辅助信号须明确区分 |
| MNE 高频候选 | 跨通道时间区间 | 不补造单条通道身份 |
| 模块状态 | 完成、受限或未评原因 | 缺辅助证据通常为 `partial`，不算“无伪迹” |

## 5 配置参数

下表是当前实现配置，不是行业肌电、眼电或心电污染合格线。

| 分项 | 当前默认或条件 | 解释 |
| --- | --- | --- |
| ECG / EOG 滤波 | 5–35 Hz / 1–10 Hz；10 s FIR；至少 10 s 输入 | 使用 MNE 检测函数；Nyquist 分别须大于 35.5 / 10.5 Hz |
| EEG 锁时 | −0.5 至 +0.5 s；仅完整边界片段 | 不做基线校正、重参考或自动拒绝 |
| 锁时资源上限 | 最多 1000 个事件；每道片段元素不超过 200 万 | 超限按时间均匀抽取用于汇总，不是质量筛选 |
| 重复性描述 | 至少 4 个事件 | 才计算拆半和奇偶一致性 |
| 基础高频范围 | 30 Hz 至 `min(100, 0.45 × fs)`；带宽至少 20 Hz | 至少 10 s 输入；每个数据集可用频带不同 |
| 基础高频窗口 | 1 s，步长 0.25 s；包络平滑 4 Hz | 可重叠候选，数量不等于独立事件数 |
| 高频联合条件 | 包络 z 大于 4 累计至少 0.15 s；功率比至少 3 | 累计时长不要求连续；仍须同时满足其余条件 |
| 频谱与尖跳条件 | 有效频点至少 5；非工频比例至少 0.2；高频/总带功率至少 0.01；最大差分能量占比不超过 0.25 | 联合使用，不能只取一个数代替完整规则 |
| 完整性保护 | M03 与局部恒值范围向两侧扩展 0.5 s；选区边缘保护 0.5 s | 局部恒值差分不超过 `1e-15 V`，持续至少 0.1 s |
| EMG 支持 | 包络 z 峰至少 2 且相关系数至少 0.5 | 取窗口周围上下文核对，不是独立诊断阈值 |
| MNE 高频扩展 | 110–140 Hz、阈值 4、`min_length_good=0.1 s` | 该时长用于合并短正常间隙，不是最短伪迹长度 |
| MNE 扩展适用性 | fs 大于 280 Hz、窗口至少 10 s | 已知高通不低于 110 Hz 或低通不高于 140 Hz 时阻断；滤波史未知时受限 |

基础高频方法的功率基线来自当前选区，换窗口可能改变候选。MNE 扩展与基础高频方法的频带、聚合方式和输出粒度不同，不应混为同一检测器。

## 6 验证与使用限制

已核对公开记录中的辅助信号读取、事件时间坐标、缺失辅助信号的受限状态及真实扩展执行。当前没有足以支持通用准确率声明的独立专家伪迹验证集。

眼动、心搏、肌肉活动、病理高频及设备干扰可能共享部分波形或频谱特征。锁时一致性和 EMG 支持是证据，不是病因结论。采集显示滤波建议也不能直接作为全部算法的预处理：高频方法需单独核实带宽和滤波史。
