# M07 状态和事件检查

模块说明 · 适用实现：工作台 1.0.0rc2 · 文档版本：0.4

本模块将已登记的睡眠分期、任务事件或临床事件映射到本次检查选区，保留来源、原始时间和覆盖问题。标签用于解释记录背景，不作为信号质量真值或检测器输入。

[关联规范：5.7](/standards#57-m07-状态与事件核对) · [前置模块：M02](/standards/modules/M02) · [结果汇总：M08](/standards/modules/M08)

## 1 用途与适用范围

适用于具有明确时间基准、标签含义和来源关系的外部事件表。当前支持三类已登记 TSV：睡眠分期、包含 `event_name` 的任务事件、临床事件。

读取器可提取格式内嵌注释，但不会自动将它们作为 M07 已登记事件表，也不会自动发现同目录分期或事件文件。使用者可在记录修订中明确映射已有原始注释，确认其任务、睡眠分期或临床事件含义后生成带指纹的派生 TSV。外部配套表仍须采用支持格式单独登记；原始标注与派生表的来源关系应保留。

本模块核对时间和覆盖，不评价诊断正确性、分期准确率或任务执行表现。未登记标注时跳过本模块，不推断记录正常或没有事件。

## 2 输入与前置条件

依赖 M02 提供原始记录中的选区起点、时长、采样率和样本起点。标注时间必须已转换为相对同一记录起点的秒数，不能直接混用绝对时刻、毫秒或另一设备时钟。

每份标注需声明格式和文件位置，可登记文件 SHA-256 及原始来源文件的 SHA-256。当前使用单个声明格式，不自动合并多种来源的事件表。

| 格式 | 必需列 | 标签用途 |
| --- | --- | --- |
| `sleep_stages_tsv` | `onset_s`、`duration_s`、`stage` | 睡眠阶段与覆盖 |
| `bids_events_tsv` | `onset`、`duration`、`event_name` | 任务事件；可另存 `event_value` |
| `clinical_events_tsv` | `onset_s`、`duration_s`、`label`、`label_type` | 临床事件及来源类别 |

`bids_events_tsv` 是当前适配器名称，不表示接受任意 BIDS 事件表，也不表示完成整套 BIDS 验证。质量标签的独立性能评估接口尚未接入。

## 3 处理流程与方法

### 3.1 显式映射与文件核对（已接入）

文件内注释映射要求选择原始标签、填写解释并明确确认。不存在的标签、越出记录的事件和技术断点不能映射为任务、睡眠或临床事件；睡眠分期须有正持续时间，不能由点事件推断。映射保留原始描述与来源指纹，且生成新输入版本，不改变旧记录。

核验登记指纹和必需列。起点须有限且不小于零，持续时间须有限且不小于零；睡眠阶段持续时间必须大于零。睡眠表若提供 `end_s`，其与起点加持续时间的差不得超过 `1e-6 s`。

无效时间行记录问题并不映射。乱序、超出登记记录长度的有效时间行记录问题，但当前不会一律丢弃：保留计数，并对与选区相交的部分继续映射。文件指纹不一致或缺少必需列会使读取失败。

### 3.2 原始时间与样本映射（已接入）

区间事件按与选区的交集裁剪，保留未裁剪的原始起点、持续时间和终点。零时长点事件使用左闭右开规则：`选区起点 <= 事件起点 < 选区终点`。

映射样本采用 `选区原始样本起点 + round((事件选区时间 − 选区起始秒) × fs)`。区间的 `stop_sample` 为不包含的结束位置；点事件起止样本相同，不贡献持续时间。

### 3.3 阶段覆盖与临床事件时长（已接入）

睡眠分期的覆盖秒数按重叠区间并集计算；选区内未覆盖部分显式标为 `unknown`。睡眠阶段互相重叠会记录问题，不能把冲突阶段同时解释为已确认状态。

临床事件时长也取区间并集，避免同一时段重复累计。任务事件仅提供列表和定位，不将事件间空白解释为“无伪迹”，也不生成任务覆盖率或成功率。

### 3.4 标签与信号检测隔离（已接入）

睡眠、任务和发作标签不输入 M03–M06，不改变候选阈值或总分。时间对齐沿用提供方声明的原始时钟；没有据此测得硬件同步误差。

## 4 输出与解释

证据文件为 `M07_annotations.json`。表中数量均针对明确的行或区间，不是质量得分。

| 字段 | 单位或类型 | 含义与解释 |
| --- | --- | --- |
| `total_rows`、`valid_rows` | 行数 | 全表行数、通过时间字段解析的行数；后者仍可能有越界问题 |
| `selected_count`、`events` | 事件行数、列表 | 与选区重叠的来源事件及原始、裁剪后坐标 |
| `stage_seconds` | s | 各阶段逐行累计；有重叠时可重复计数，应先查看 `issues` |
| `covered_seconds` | s 或 null | 仅睡眠表：选区内阶段区间并集长度 |
| `uncovered_intervals` | 秒区间 | 睡眠表的未知覆盖；任务或临床事件不借此推断正常区间 |
| `clinical_event_seconds` | s 或 null | 仅临床表：选区内事件区间并集长度 |
| `sources`、`source_unchanged` | 指纹、布尔值 | 所读标注的身份与读取期间一致性；不是标签正确性证明 |
| `issues`、`status` | 问题列表、状态 | 有问题或睡眠覆盖缺口时为 `partial`，不能只看事件数量 |
| `quality_ground_truth`、`used_for_signal_detection` | 均为 false | 当前标签不作为质量真值，也不参与信号检测 |
| `unlabelled_means_normal` | false | 无标签不等于正常 |

## 5 配置参数

| 配置 | 当前规则 | 性质 |
| --- | --- | --- |
| `annotation.format` | 三种声明格式之一 | 当前接口能力，不自动猜测 |
| `annotation.expected_sha256` | 提供时必须匹配 | 标注身份核验 |
| `annotation.source_path`、`source_expected_sha256` | 可保留原始标签及预期指纹 | 转换来源追踪 |
| `annotation.label_scope` | 声明标签用途；缺失为未确认非质量用途 | 不把文字声明转换成质量真值 |
| 时间一致性容差 | `1e-6 s`，用于睡眠终点及记录终点核对 | 数值检查容差，不是同步精度指标 |
| 检查范围 | 沿用 M02；每窗最多 120 s，整记录逐窗映射 | 短尾窗、缺口和未执行窗分别保留 |
| 文件内注释映射 | 最多 512 个原始标签；解释最多 500 字；说明最多 2000 字 | 明确确认后生成新版本，非自动语义判断 |

没有睡眠阶段、发作时长或事件数量的质量扣分阈值。修改标签不会在本模块生成新的生理诊断。

## 6 验证与使用限制

已有点事件、区间裁剪、选区偏移、分期覆盖缺口、非有限时间及指纹不一致等边界检查；公开睡眠、任务及临床事件表已有实际映射证据。这些验证支持坐标与接口行为，不验证来源标签本身的准确性。

读取器注释只经使用者显式映射与确认后登记；当前不自动猜测语义，不执行通用 BIDS 校验，不校正外部时钟漂移，也不裁决标注者分歧。临床标签可能包含真正的病理信号，不能将其当作技术伪迹删除。

超范围标注记录问题后仍可能进入选区列表；复核人员应结合 `issues`、来源文件及记录长度判断。规范提出的完整标注管理要求不表示当前已实现全部功能。
