# M05 坏通道候选

模块说明 · 适用实现：工作台 1.0.0rc1 · 文档版本：0.2

本模块在明确的可比通道组内生成幅度、噪声、相关性、桥接和离群线索。它输出候选及判据，不把通道差异自动认定为技术故障，也不自动插值或重参考。

[关联规范](/standards#55-m05-通道质量候选) · [前置模块：M02 数据画像与检查计划](/standards/modules/M02)

## 1 用途与适用范围

适用于头皮 EEG 的通道质量筛查。比较组须有明确的参考与可比性依据；不同参考、双极导联或混合测量条件不能未经确认放入同一组。

本模块仅依赖 M02，自行计算所需指标，不依赖 M03 或 M04 的检测结果。来源坏道标签不进入检测器，只能另用于外部对照。

## 2 输入与前置条件

输入为所选 EEG 电压、原生采样率、原始通道索引、分析窗口及逐通道 `comparison_groups`。未知参考不会自动按名称推断。

PREP 非空间组内阈值至少需要四条可用通道；不满足时仍保留能计算的描述量。桥接与 LOF 的当前适配器要求已确认共同参考或联耳参考、所有所选 EEG 属于同一个比较组，并满足各自时长与通道数量门槛。

## 3 处理流程与方法

### 3.1 PREP 非空间坏道线索（已接入）

BrainElecQC 对 PREP 的非空间分项作独立实现，主流程没有调用完整 PyPREP。首先记录非有限样本和极低离散程度，再在副本上高通滤波，计算组内稳健幅度、相对高频噪声、逐窗相关性与 dropout。

幅度使用 `0.7413 × IQR` 描述，并以组中位数和相应组内尺度标准化。高频指标使用高通信号与低通信号之差的 MAD 相对于低通信号 MAD 的比值，再作组内稳健标准化。

相关性在完整 1 s 窗中计算绝对 Pearson 相关矩阵，令对角线为零后，取 98% Hazen 分位数。输出字段名含 `max_abs_correlation`，但实际量是这个高分位数，不是字面上的最大值。低相关窗和 dropout 窗分别按已评窗口比例触发候选。

组内尺度为零或有效通道不足时不制造无限大的标准分。该流程不包含空间预测、RANSAC、插值或稳健平均参考。

### 3.2 MNE 电极桥接候选（可选，已接入）

调用 `mne.preprocessing.compute_bridged_electrodes`，在固定分段中计算通道差波形方差，即电距离，再利用分布估计桥接候选。

结果是通道对及其距离证据。`lm_cutoff` 是寻找分布局部极小值时的范围上限，不是最终桥接判定阈值。当前接口未返回该实际分界点，不补造一个阈值或异常起止区间。相似波形也不直接证明电极短接。

### 3.3 MNE LOF 通道离群候选（可选，已接入）

调用 `mne.preprocessing.find_bad_channels_lof`，对所选整段通道向量使用欧氏距离和局部离群因子。绝对离群因子达到当前阈值时形成通道候选。

当前不额外归一化、滤波、重参考或自动降低邻居数。结果依赖参考、幅度分布和通道集合；它是整段通道离群描述，没有时间定位。

### 3.4 PyPREP 空间预测 / RANSAC（待接入）

方法目录保留来源，但当前不运行。接入需要可靠电极坐标、足够的空间采样及单独验证，不能以非空间 PREP 已运行宣称空间坏道预测完成。

## 4 输出与解释

基础证据文件为 `M05_bad_channels.json`，桥接与 LOF 的可选结果单独保留。

| 输出 | 单位或范围 | 如何解释 |
| --- | --- | --- |
| `channels`、`candidates` | 原始通道身份、分项值与命中原因 | 逐分项复核，不把任一命中直接作为删道决定 |
| 幅度与离散程度 | V 或 µV，按字段标注 | 与参考和真实生理幅度一起解释 |
| 标准分、相关性、噪声比与窗口比例 | 无量纲 | 同时查看比较组与有效窗口分母 |
| `groups`、`thresholds_active` | 可用道数、组状态 | 阈值未启用不表示该组通过检查 |
| 桥接电距离与候选 | µV²、通道对 | 通道对数不是坏通道数，也不是异常时段数 |
| LOF 因子与候选 | 无量纲、整段通道 | 反映相对离群，不定位异常时间 |

相关性较低或幅度较大也可能来自生理、病理或覆盖位置差异。报告应保留原始波形和背景证据，而不是只输出“坏道”结论。

## 5 配置参数

以下为当前实现设置和筛查条件，不是行业合格线。

| 方法 | 关键默认或门槛 | 说明 |
| --- | --- | --- |
| PREP 副本滤波 | 高通 1 Hz；完整窗 1 s | 组内比较至少四条可用通道 |
| 高频分项 | fs 大于 100 Hz 时使用 101 点低通，过渡带 45–50 Hz | 采样率不足时该分项未评 |
| 幅度离群 | 稳健标准分绝对值大于 5 | 当前组内判据 |
| 相对高频噪声 | 稳健标准分大于 5 | 单侧判据，不取绝对值 |
| 低相关 | 分位相关量小于 0.4 的已评窗口比例大于 0.01 | 严格大于 1% 才触发 |
| dropout | 低通 MAD 为零的已评窗口比例大于 0.01 | 与生理低幅度不能混称 |
| 平坦通道 | 标准差或 MAD 小于 `1e-15 V` | 数值级平坦条件 |
| 桥接 | 0.5–30 Hz、2 s 固定段、`lm_cutoff=16 µV²`、`epoch_threshold=0.5` | 16 µV² 是搜索上限，不是最终阈值 |
| 桥接适用性 | 至少 8 道、10 s、5 个完整段；Nyquist 大于高截止 | 当前适配器执行门槛 |
| LOF | 20 个邻居、阈值 1.5、欧氏距离 | 绝对离群因子大于或等于 1.5 |
| LOF 适用性 | 至少 8 道、10 s，且通道数大于邻居数 | 默认 20 邻居实际需要至少 21 道 |

PREP 副本滤波的长度条件为至少 `max(304, ceil(3.3 × fs / 高通频率) + 1)` 点。桥接与 LOF 还须满足第 2 节的已确认参考与单一比较组条件。

## 6 验证与使用限制

PREP 非空间实现已有指标与边界检查，桥接和 LOF 已在真实公开记录上完成执行核对。不能据此声明候选准确率已通过独立验证。

必须保留一项负证据：对 ds002034 的两份完整记录，PREP 非空间流程曾返回零候选，而来源文件合计标有四条坏道。差异原因尚未确认；短窗结果不同也不能视为该差异已经解决。来源坏道标签本身的标注标准仍需核对。

目前缺少覆盖多设备、参考方式与病理背景的独立专家伪迹标注。候选应结合通道空间位置、波形、参考及实验状态复核，不自动用于排除或插值。
