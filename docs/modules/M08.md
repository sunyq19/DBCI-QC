# M08 分项评价与可比性

模块说明 · 版本 0.6 · 适用实现 1.0.0rc3.dev17

本模块汇总执行证据并复核来源一致性。EEG 额外提供独立、版本化的基础试行评分，完整定义见[EEG 评分规则](/standards/eeg-scoring)。

[相关规范：5.8](/standards#58-m08-分项评价与汇总) · [检查计划 M02](/standards/modules/M02) · [报告 M09](/standards/modules/M09)

## 1 目的与范围

保留每个实际检查的测量、覆盖、候选和未评原因，区分执行完成与数据质量。EEG 默认基础评分只覆盖信号完整性、工频干扰、高频突发，不代表其他模块均已通过，不直接用于 ECoG、sEEG 或 Neuropixels。

## 2 输入与前置条件

输入为冻结计划、所选通道、方法配置、实际模块产物和 M01 的源文件指纹。必要依赖随选择集合形成。未选择、条件不足和失败应分别记录，不能补零。

EEG 计分还需要每个所选通道中正权重项目的有效分子分母；整份计分需要每个窗口完整、无来源缺口并通过运行后来源核验。记录时间和有效计分时间应区分。

## 3 处理流程与方法

### 3.1 证据与来源汇总

保留模块编号、状态、理由与原始摘要；重核主文件及必要配套文件 SHA-256。发现来源变化时 M08 失败；缺少指纹不能补成通过。

### 3.2 EEG 项目试行评分

评分核心独立存放于 `src/ephys_qc/project_scoring.py`，报告适配层读取方法产物后调用。它不改动检测器、原始信号或 M08 冻结产物。

- 分项：`100 × (1 − 候选量 / 有效检查量)`。
- 总分：`Σ(分项 × 权重) / Σ权重`；EEG 默认三项等权，扩展项默认 0；0 表示不纳入。
- 正权重项目缺失时不出总分。可疑通道与时段独立保留。
- 整份记录：先合并各通道各窗的原始分子分母，再评分，不平均窗口分数。

公式、单位、判据、算例、缺项及限制以[评分规则](/standards/eeg-scoring)为准。当前不采用疾病权重、数据集排名或统一合格线。

### 3.3 可比性

比较须固定评分版本、权重、通道集合、参考、方法参数、频带、处理史及分析范围。相同疾病或格式不足以证明可比。删除问题通道后应保存新配置，不覆盖原记录。

## 4 输出与解释

| 位置 | 内容 | 解释 |
| --- | --- | --- |
| M08_assessment.json / score.value | null | 通用跨模态校准分数尚未建立 |
| M08_assessment.json / module_assessments | 模块状态、原值与理由 | 不将完成率当作质量 |
| M08_assessment.json / source_unchanged | true 或 null；冲突则失败 | 仅证明文件字节一致，不证明采集声明正确 |
| result.json / report_view.score | 项目加权评分、分项、权重、分母及规则版本 | 项目试行指数，缺项时总分为空 |
| report_view.local_quality | 通道分项与最低项 | 通道未命中比例用于定位 |
| report_view.window_scores | 整份检查逐窗分数 | 不直接平均为整份分数 |
| report_view.score_revision | 历史重算的新旧版本和旧值 | 原始冻结文件保持不变 |

## 5 配置与追溯

当前采用 `project-weighted/1.1`：分项为 100 ×（1 − 候选量 / 有效检查量），总分按配置权重平均。M08 只汇总，不重复参与加权。配置随计划冻结；正权重项目缺失时不生成总分。历史 v0.2 保留追溯。详见[评分规则](/standards/eeg-scoring)。

## 6 验证与限制

数学契约包括无候选满分、完整异常零分、候选负担增加不升分、局部候选保留、缺项不补分、非等长窗口处理和历史证据保全。原始信号注入检查与公式测试分开记录。

当前分数不计已命中后的幅度严重性，不合并全部独立风险，不证明临床或应用可用性。检测器误报、漏报及专家评分一致性仍需独立验证。校准之前不赋予优良等级或行业合格结论。

## 方法评分接口

各方法先输出独立的 `method-score/1`，M08 按冻结权重汇总。统一适配器为 `method_scores.py`，目录为 `score_registry.py`。灵犀云五个候选检测方法和其他已接入、具有明确判定与分母的方法可选计分；只描述功率或处理变化的输出不计分。全部权重为 0 时不计算总分。具体目录和分母以[项目评分规则](/standards/eeg-scoring)为准。
