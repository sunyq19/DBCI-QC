# M08 分项评价与可比性

模块说明 · 版本 0.5 · 适用实现 1.0.0rc3.dev13

本模块汇总执行证据并复核来源一致性。EEG 额外提供独立、版本化的基础试行评分，完整定义见[EEG 评分规则](/standards/eeg-scoring)。

[相关规范：5.8](/standards#58-m08-分项评价与汇总) · [检查计划 M02](/standards/modules/M02) · [报告 M09](/standards/modules/M09)

## 1 目的与范围

保留每个实际检查的测量、覆盖、候选和未评原因，区分执行完成与数据质量。EEG 基础评分只覆盖信号完整性、工频干扰、高频突发，不代表其他模块均已通过，不直接用于 ECoG、sEEG 或 Neuropixels。

## 2 输入与前置条件

输入为冻结计划、所选通道、方法配置、实际模块产物和 M01 的源文件指纹。必要依赖随选择集合形成。未选择、条件不足和失败应分别记录，不能补零。

EEG 计分还需要每个所选通道的三类有效分子分母；整份计分需要每个窗口完整、无来源缺口并通过运行后来源核验。记录时间和有效计分时间应区分。

## 3 处理流程与方法

### 3.1 证据与来源汇总

保留模块编号、状态、理由与原始摘要；重核主文件及必要配套文件 SHA-256。发现来源变化时 M08 失败；缺少指纹不能补成通过。

### 3.2 EEG 项目试行评分

评分核心独立存放于 `src/ephys_qc/scoring.py`，报告适配层读取方法产物后调用。它不改动检测器、原始信号或 M08 冻结产物。

- 通道异常占比：每项候选量除以对应有效量。
- 分项：`100 × (1 − sqrt(各通道异常占比平方的均值))`。
- 总分：三个分项的最低值，其他满分项不抵消问题项。
- 整份记录：先逐通道合并各窗的原始分子分母，再评分，不平均窗口分数。

公式、单位、判据、算例、缺项及限制以[评分规则](/standards/eeg-scoring)为准。当前不采用疾病权重、数据集排名或统一合格线。

### 3.3 可比性

比较须固定评分版本、通道集合、参考、方法参数、频带、处理史及分析范围。相同疾病或格式不足以证明可比。删除问题通道后应保存新配置，不覆盖原记录。

## 4 输出与解释

| 位置 | 内容 | 解释 |
| --- | --- | --- |
| M08_assessment.json / score.value | null | 通用跨模态校准分数尚未建立 |
| M08_assessment.json / module_assessments | 模块状态、原值与理由 | 不将完成率当作质量 |
| M08_assessment.json / source_unchanged | true 或 null；冲突则失败 | 仅证明文件字节一致，不证明采集声明正确 |
| result.json / report_view.score | EEG v0.2 分数、分项、分母及规则版本 | 项目试行指数，缺项时总分为空 |
| report_view.local_quality | 通道分项与最低项 | 通道未命中比例用于定位 |
| report_view.window_scores | 整份检查逐窗分数 | 不直接平均为整份分数 |
| report_view.score_revision | 历史重算的新旧版本和旧值 | 原始冻结文件保持不变 |

## 5 配置与追溯

通道等权、RMS 指数 2、最低分项汇总均为 v0.2 固定规则，不允许因某份数据得分偏高而临时修改。检测器参数从冻结任务读取。评分核心及聚合版本改变时应更新标准、报告与验证记录。

## 6 验证与限制

数学契约包括无候选满分、完整异常零分、候选负担增加不升分、集中负担可见、缺项不补分、非等长窗口处理和历史证据保全。原始信号注入检查与公式测试分开记录。

当前分数不计已命中后的幅度严重性，不合并全部独立风险，不证明临床或应用可用性。检测器误报、漏报及专家评分一致性仍需独立验证。校准之前不赋予优良等级或行业合格结论。
