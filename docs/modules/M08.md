# M08 分项评价与可比性

模块说明 · 适用实现：工作台 1.0.0rc2 · 文档版本：0.4

本模块汇总本次实际执行的分项结果、未评原因和来源一致性。当前总分未校准，固定保留空值；不会把候选数量、执行完成率或缺失项目换算成数据质量分。

[关联规范：5.8](/standards#58-m08-分项评价与汇总) · [检查计划：M02](/standards/modules/M02) · [报告模块：M09](/standards/modules/M09)

## 1 用途与适用范围

适用于本次选区内已选择的方法及其真实执行证据。M08 是固定步骤，用于把不同检查的观察量放在同一报告中，并保持各自的定义、单位和局限。

它不是自动质量评级器，不提供跨设备、跨状态或跨方法统一的合格等级。单次窗口结果不代表整夜记录、整份文件或整个数据集已经完成质量评价。整记录模式另按各窗实际状态汇总执行覆盖；部分可评、未执行及来源缺口不计为质量合格。

## 2 输入与前置条件

执行依赖随实际选择集合形成：M08 汇总此前已选模块及必要依赖的执行结果，不为汇总而强制运行所有检查。未选择的模块保留跳过状态。

输入包括冻结计划、方法配置、分项摘要、实际扩展状态、错误或未评原因，以及 M01 保存的主文件及必要伴随文件指纹。来源标签的作用限于独立注释和结果复核。

汇总允许保留部分失败的结果，但不能将失败输出补零或解释成未发现问题。运行状态和质量结论必须分开阅读。

## 3 处理流程与方法

### 3.1 保留分项结果与状态（已接入）

收集各模块的编号、执行状态、原因和原始摘要。可选扩展是否真正运行、是否受限，以实际执行输出为准，不把计划中的 `ready` 当作完成。

未选择、条件不足、执行失败及完成检查分别保留。已有模块出现 `partial` 或 `failed` 时，M08 汇总状态为 `partial`，同时保留具体原因；某项检查的成功不能覆盖其他方法的失败。

### 3.2 来源文件一致性复查（已接入）

重新核对主文件和必要伴随文件的 SHA-256，与本次 M01 保存的成员清单比较。发现文件变化时 M08 失败，相关结果不能按来源未变接受。

缺少前序来源指纹时，一致性为未知，不补成通过。成员清单和指纹一致证明本次输入文件字节一致，不证明数据采集、标签或设备声明均正确。

### 3.3 分项与总分分开表达（已接入）

`score.value` 固定为 `null`，显示“未校准”，保留原因说明。当前没有总分方向、归一化、权重、缺项补分或统一合格线的实现。

通道候选、时间候选、通道对和固定分析段属于不同统计对象，不直接相加。多个方法可能命中同一数据，也可能覆盖不同频率、通道或时间，不能把数量求和当作故障规模。

### 3.4 可比性与未实现能力（说明）

当前保留冻结的选区、配置、数据事实和各方法证据，供使用者核对可比条件；尚无自动跨数据集可比性认证或跨方法统一坏时长计算。

需要合并候选时，应另行定义通道范围、时间并集、方法重叠及未评区域的口径，并验证结果。现有汇总不会代替这些规则，也不会据疾病或任务标签生成质量权重。

## 4 输出与解释

主要证据文件为 `M08_assessment.json`；任务最终状态另保存在 `result.json`。

| 字段或结果 | 单位或类型 | 含义与解释 |
| --- | --- | --- |
| `score.value` | null | 总分未建立可用校准，既不是零分，也不是满分 |
| `score.label`、`score.reason` | 文字 | 未校准状态及原因 |
| `module_assessments` | 分项列表 | 模块状态、理由及摘要；指标单位沿用原方法 |
| `source_unchanged` | true 或 null | 与 M01 指纹一致，或缺少可比较依据；发现变化则模块失败 |
| `execution_status_is_not_quality` | true | 执行状态不得转换为质量结论 |
| `missing_capabilities` | 文字列表 | 当前明确未接入的能力，不是对已做检查的扣分 |
| `status`、`reason` | 状态、说明 | 分别查看模块行及最终任务结果，不混同方法候选 |

当前未接入能力包括空间坏道预测、local AutoReject、ICA/ICLabel、一般重复数据块检测。列表用于说明边界，不表示其他已接入方法已经完成临床验证。人工候选复核已另行追加保存，不修改 M08 冻结结果或生成质量总分。

最终任务在 M01、M02 或 M08 失败时为 `failed`；其他模块有失败或部分可评时为 `partial`。这是执行组织规则，不是数据质量等级。

## 5 配置参数

| 配置或约束 | 当前行为 | 性质 |
| --- | --- | --- |
| 模块选择 | M08 固定加入，汇总实际选择及依赖 | 工作流规则 |
| 总分配置 | 无可用数值权重或评级阈值；固定 null | 尚未校准的能力边界 |
| 分项参数 | 沿用本次冻结的方法配置 | 不在汇总时重新调阈 |
| 统计对象 | 保留各方法原有单位与定位 | 不自动合并数量或坏时长 |
| 来源核验 | 复查主文件与必要伴随文件的 SHA-256 | 成员清单及文件一致性检查 |

前端执行进度按实际选中的步骤统计，仅用于了解运行进展；它不属于 M08 的质量评分。参数或方法版本变化后的结果，不应直接当作同一评价配置比较。

## 6 验证与使用限制

已有模块状态、依赖选择、缺条件、扩展失败、原始指纹及空总分等契约检查；真实公开记录的报告保留了分项结果和未校准总分。该证据支持汇总行为，不提供跨场景评分有效性证据。

当前没有统一的坏通道比例合格线、跨方法坏时长、自动质量等级或目标应用效用评分。某方法候选为零，不代表未运行的方法也通过；未评区域不计作正常数据。

总分投入使用前仍需明确目标用途、方向、权重、缺项处理、关键问题规则与独立校准。规范提出这些要求，不表示当前实现已经满足，也不授权把空总分替换成任意百分比。
