# M09 报告与人工复核

模块说明 · 适用实现：工作台 1.0.0rc1 · 文档版本：0.4

本模块提供本地报告、可定位的候选清单和有界原波形预览。人工复核按版本独立追加保存，不改写算法结果、原始信号或质量总分；不提供临床诊断。

[关联规范：5.9](/standards#59-m09-报告与复核) · [前置模块：M08](/standards/modules/M08) · [来源核验：M01](/standards/modules/M01)

## 1 用途与适用范围

适用于已形成运行结果或明确失败、未评原因的本地任务。M09 是固定步骤，便于使用者查看结果依据、回到对应方法证据，并区分计算结果与人工确认。

报告只描述本次实际检查范围。选区报告不代表整份记录；整记录报告按各窗实际状态展示已执行、部分可评、失败、未执行及来源缺口，覆盖率不代表质量合格率。

本页说明当前功能，不构成平台已满足规范全部报告和审核要求的声明。未经审核的算法候选应继续保留为待复核状态。

## 2 输入与前置条件

依赖 M08 的分项汇总，同时使用任务保存的来源指纹、冻结配置、运行范围、实际模块结果及可用证据文件。波形绘制还需要成功读取的原始标定选区。

报告沿用本次任务保存的通道身份、时间和配置，不借用之后修改的草稿。未执行模块和失败方法只报告其真实状态，不补造计算量。

缺少可绘制信号时，可以保留失败与未评说明，但不能补出示意波形。报告能打开或文件生成成功，都不表示信号检测有效或数据质量合格。

## 3 处理流程与方法

### 3.1 HTML 与结构化证据呈现（已接入）

报告展示所选通道数、采样率、原始时间范围、各模块状态和摘要，并提供对应 JSON 证据入口。来源指纹、配置标识、选道和实际参数保留在任务结果及结构化内容中。

模块摘要使用适合阅读的说明，但不替代详细证据。例如工频命中窗不是相互独立的伪迹段，整段坏道候选不是精确时间定位，辅助事件出现也不直接证明 EEG 污染。

### 3.2 报告内静态波形示意（已接入）

图中最多展示前 6 个所选 EEG 通道、选区最初 15 s；通道或时长不足时按实际范围绘制。横轴为原始记录秒数，纵轴由 V 换算为 µV。

绘图使用显示步长 `max(1, N // 3000)`，其中 N 是拟绘制时间范围内的原生样本数。此步长只抽取显示点，不改变分析输入，也不保证每个瞬时尖峰都在示意图中可见。

`waveform_selection.json` 保存图的通道名、起点、实际展示时长、显示步长和单位。该静态图不随工作台复核操作改变，也不能代替原生样本复核。

### 3.3 原波形与候选定位（已接入）

工作台从任务冻结输入及来源指纹重新读取原始标定值，每次最多 10 s、16 道、每道 2000 个显示点，原生读取数组最多 64 MiB。读取须位于一个原生采样流和连续段内；跨缺口、无效通道或来源变化会拒绝，不自动重采样或连接断点。

超过显示点数时使用分桶极小值、极大值包络，保留极值先后顺序和非有限值标记。返回源样本坐标、实际秒时间、物理单位及显示换算；电压显示为 µV，其他物理量不冒充电压。包络不是每个原生样本，也不改变分析信号。

候选区分真实检测区间与整窗通道/通道对结果。仅整窗定位时，显示该分析范围并明确未定位异常起止；生理事件及临床标签不提升为质量候选。整记录候选保留窗口编号和原始时间，未完成窗口的局部产物不提升为最终候选。

### 3.4 失败与未评结果保留（已接入）

波形绘制失败时保留结构化结果，并将 M09 标为 `partial`，记录原因。信号未成功加载时，不生成虚构波形，只报告已经取得的失败或未评证据。

不同模块可能只有部分方法完成。报告保留各分项状态、原因和实际可用证据，不以一个“报告已生成”状态掩盖下游限制。

### 3.5 独立版本复核（已接入）

工作台校验候选标识后，将 `accepted`、`rejected` 或 `uncertain` 结论、备注、复核者声明与时间追加到 `reviews.json`。每次提交携带 `expected_version`，过期版本返回冲突；先前意见保留在历史中，最新意见作为当前复核视图。

算法 `result.json`、冻结请求与方法产物不改写，静态报告的初始 `review_status=pending` 不是当前复核进度。当前运行摘要以 `human_review_writeback=separate_versioned_review_store` 指明独立存储；旧报告保留原字段。复核意见不生成临床诊断、不自动删改信号，也不把空总分换成百分比。复核者为使用者填写标识，不是经认证的电子签名。

## 4 输出与解释

| 文件或字段 | 单位或类型 | 内容与解释 |
| --- | --- | --- |
| `report.html` | HTML | 本次任务的范围、状态、摘要与证据入口 |
| `result.json` | JSON | 最终任务状态、模块结果、配置与产物清单 |
| `M08_assessment.json` | JSON | 汇总依据及未校准总分，不能替换为人工结论 |
| `waveform.png` | 图像 | 有限通道与时间范围的显示抽样波形；可能因绘图失败而缺失 |
| `waveform_selection.json` | 名称、s、样本步长、µV | 图的实际展示范围与处理说明 |
| `plan.json`、`environment.json` | JSON | 运行计划及依赖环境、方法来源信息 |
| 算法 `review_status` | `pending` | 冻结报告的初始状态；最新进度另读复核记录 |
| `human_review_writeback` | `separate_versioned_review_store` | 当前运行指向独立版本复核能力，不修改算法产物 |
| `reviews.json` | `version`、`history` | 追加意见与版本；当前决定和计数由独立复核接口返回 |
| 原波形接口 | 源索引、秒、样本、单位、极值包络 | 有界原始值预览，不是重新运行检测 |

图、摘要和原始方法 JSON 的详细程度不同。解释候选前应核对具体通道、时间、覆盖范围和未评理由，而非只读取摘要中的数量。

## 5 配置参数

| 展示设置 | 当前值或规则 | 性质 |
| --- | --- | --- |
| 静态图通道 | 所选 EEG 中前 6 道，最多 6 道 | 固定预览范围，不是通道筛选结论 |
| 静态图时长 | 选区最初最多 15 s | 固定预览范围，不是实际全部检查时长 |
| 显示步长 | `max(1, N // 3000)` 个原生样本 | 仅绘图使用，不进行分析降采样 |
| 波形单位 | µV；原始计算电压为 V | 显示换算 |
| 原波形请求 | 最多 10 s、16 道、每道 2000 点、64 MiB 原生读取 | 极值包络仅用于显示；不跨连续段 |
| 复核状态 | `pending` / `accepted` / `rejected` / `uncertain` | 不等于全记录质量等级或临床签署 |
| 复核字段 | 复核者最多 160 字、备注最多 4000 字；版本必须匹配 | 追加保存，禁止并发覆盖 |
| 总分显示 | 未校准 | 沿用 M08 的 null，不在报告层生成分数 |

静态图设置为固定行为；原波形接口允许在上述资源上限内选择通道、起点和时长，均不改变冻结分析参数。检查范围和方法设置须在 M02 中确认，并以任务保存值为准。

## 6 验证与使用限制

已有真实公开 EDF 任务生成本地 HTML、结构化证据和波形；相关检查覆盖通道身份、原始时间、单位、未评状态及报告入口。它们支持报告链路行为，不构成专家审核或临床有效性证明。

报告模块不写回原始数据。输入文件是否在运行中被外部操作改变，应以 M08 的来源一致性结果为准，不能仅凭报告里的“保留原始数据”说明判断。

候选归一化、原始通道/时间映射、极值包络、版本冲突和算法文件不变已有独立工程检查及真实公开记录 HTTP 流程证据。静态图抽点仍可能遗漏快速变化；有界包络保留桶内极值，但不是诊断级全样本浏览器，也不提供跨任务统一质量比较。

规范要求报告与人工修改可追溯，当前实现覆盖自动报告与独立候选复核历史，不覆盖经认证的临床签署。质量报告不替代临床诊断，也不因病例或来源标签存在而获得诊断效力。
