# M02 数据画像与检查计划

模块说明 · 适用实现：工作台 1.0.0rc2 · 文档版本：0.4

本模块把“检查哪份数据、哪些通道、哪段时间、哪些方法”变成可核对的执行计划。技术事实决定方法是否可运行，背景信息辅助结果解释；未知信息不会被自动补成确定事实。

[关联规范](/standards#52-m02-数据画像与检查计划) · [前置模块：M01 数据接入与结构核验](/standards/modules/M01)

## 1 用途与适用范围

本模块用于头皮 EEG 的选区检查和方法适用性判断，是固定执行步骤。它组织通道角色、采集参考比较组、分析时间窗、数据标签和方法配置，不计算质量总分，也不通过背景标签改变检测阈值。

支持选区与整记录两种范围。选区只评价指定窗口；整记录按原生连续段分块，逐窗执行并汇总实际覆盖，不能将执行覆盖率解释为质量合格率。

## 2 输入与前置条件

依赖 M01。先读取格式无关的技术信息，再由使用者确认模态、EEG 与辅助导联、参考和背景，随后生成质量检查建议。输入还包括文件内分析起点、时长及所选模块和方法参数。

未确认模态时不生成头皮 EEG 建议。sEEG、ECoG、MEG 等可以保留已提取技术信息，不执行错配的头皮检查。

`selection.reference_indices` 指 ECG/EOG/EMG 辅助导联，各角色对应一个原始通道索引；它不是采集参考电极。`method_config.comparison_groups` 则为每条所选 EEG 指定可比较组，须有明确的参考与可比性依据。两类信息不能互相替代。

## 3 处理流程与方法

### 3.1 技术条件与背景分开登记（已接入）

从文件技术头和实际选道生成采样率、通道数、单位、辅助导联等标签。疾病、年龄组、任务等背景保留其来源；来源未提供或使用者未确认时，保留未知。不能仅凭文件名、波形形态或同一数据集名称推断诊断与参考。

采集参考未知时仍可执行部分描述性检查；需要同参考比较组的方法则标为受限或不可用。

已登记记录可更正模态、通道角色、参考、背景、处理史及标注映射。更正生成新的输入版本，保留父版本及修改记录；旧任务继续使用冻结输入，过期版本提交会被拒绝。处理史为使用者声明，不代替独立测量。

### 3.2 分析范围与时钟核对（已接入）

核对窗口不越出记录和连续段边界，选择长度满足资源限制，所选 EEG 与辅助信号具有相同原生采样率。选区秒时间相对文件首样本，映射时保留源样本起点和时间偏移；FIF 的非零源起点不能丢失。

整记录分块不跨连续段边界，保留短尾窗与来源缺口；逐窗参数估计、滤波和边缘保护可能产生不同结果，不自动合并跨窗候选。

当前不自动重采样、重参考或对齐不同采样时钟。仅数字标定统一为 V；各方法按自身要求在副本上滤波，不存在全平台统一滤波后再做所有检查的隐含步骤。

### 3.3 依赖展开与适用性规划（已接入）

M01、M02、M08、M09 固定执行。M03–M07 按选择执行；选 M06 时自动补入 M03，以提供完整性保护区间。M05 仅依赖 M02，自行计算坏道指标，不依赖 M04 的频谱结果。

可选扩展会补入所属模块。推荐、采用配置、计划预览与实际执行分别记录；计划中显示可运行不表示已经计算。输入、选区或方法配置改变后，应以更新后的计划为准。

## 4 输出与解释

计划记录与 `M02_selection.json` 保留本次配置和实际选区。运行报告不应借用后来修改过的数据标签补充旧结果。

| 输出 | 内容 | 如何解释 |
| --- | --- | --- |
| `qc_config` | 选道、时间窗、背景和方法配置 | 本次实际采用的配置，不是其他运行的默认值 |
| `selected_modules`、`auto_added_modules` | 执行集合及依赖补入项 | 未选择与因条件不足跳过应分别理解 |
| `nodes`、`edges` | 模块状态、原因与依赖 | 规划状态，不是检测结果 |
| `data_tags` | 技术与背景标签、来源、已知或未知 | 未知不能解释为正常或不存在 |
| `method_applicability` | 每项方法能否运行及原因 | 受限、未选、未接入均应保留 |
| `recording` | 通道数、Hz、原始起点及实际时长 s | 报告覆盖范围的分母 |
| `windows`、`coverage_plan` | 逐窗坐标与计划覆盖 | 与执行后覆盖分开；来源缺口不计为正常 |
| `record_revision`、`parent_input_id` | 输入修订版本和父记录 | 不覆盖历史任务的配置 |
| `raw_signal_mutation`、`quality_labels_used_for_detection` | 均为 `false` | 不修改原始信号，不把质量标签输入检测器 |

计划中的 `ready` 表示条件满足；`partial` 表示仅部分能力可用；`skipped` 表示未纳入或不能执行，须结合原因读取。它们不表示数据通过或未通过质量判定。

## 5 配置参数

| 参数或约束 | 当前实现 | 来源与性质 |
| --- | --- | --- |
| `scope` | `window` 或 `recording` | 选区或整记录分块范围 |
| 单窗时长 | 大于 0 且不超过 120 s | 整记录每块也遵守此限制；不是总记录长度上限 |
| `recording_options.window_seconds` | 默认 120 s；还受内存预算限制 | 原生样本网格内分块，最多 10000 窗 |
| `recording_options.expensive_methods` | 默认 `skip`；可明确选择 `run` | 当前默认跳过逐窗 autoreject 全局阈值重复交叉验证 |
| 起点 | 不小于 0；窗口不越界 | 原始记录秒时间 |
| 原生采样率 | 所选 EEG 与辅助导联相同 | 当前时钟适配约束，不自动重采样 |
| 选区内存预算 | `(EEG 道数 + 辅助道数) × round(时长 × fs) × 8` 不超过 256 MiB | float64 信号数组的执行预算 |
| 背景 | 未知保留 `unknown` | 已知背景须有来源，不默认疾病或年龄 |
| 比较组 | 逐 EEG 通道明确指定；未知不补造 | 方法适用性约束，具体门槛见 M05 |

这些是当前软件配置和运行限制，不是临床记录时长、采样或通道数量的通行合格线。疾病、年龄与任务背景目前不自动调整检测阈值，也不构成行业质量判据。中文与英文只改变显示，不改变原始通道名称、稳定 ID、数值、单位或配置。

## 6 验证与使用限制

依赖补入、未选模块不执行、超长窗口拒绝、角色不重叠、采样率一致性以及配置变更后的计划失效均有工程检查。工程检查证明计划与执行约定一致，不构成推荐策略的临床有效性验证。整记录已有真实公开记录的多窗执行证据；逐窗覆盖、取消与失败分别保留。窗口不是独立受试者或任务试次。

缺少采集参考、坐标、滤波史或辅助导联时，应保留具体受限原因。当前推荐仅用于选择可用检查，不可替代研究设计、临床判断或人工通道确认。

## 7 来源与关联条款

- [BIDS EEG 官方规范](https://bids-specification.readthedocs.io/en/stable/modality-specific-files/electroencephalography.html)：元数据、参考与通道信息的组织依据；BIDS 合规与信号合格是不同问题。
- [YY/T 1833.2—2022 官方全文](https://app.nidc.org.cn/jianybz/bz_file_pdf/wwgk/ylqxtjxhybz/2022/20220720/YYT183322022.pdf)：第 4.1.1–4.1.3 条的数据说明与来源要求，为计划记录提供设计参考。
- [YY/T 2029—2026 官方全文](https://app.nidc.org.cn/jianybz/bz_file_pdf/wwgk/ylqxtjxhybz/2026/2026-10/2c9048cca08f981001a12512f7a54d97.pdf)：第 5.1、5.2.1–5.2.9 条涉及 BCI 医疗器械脑电数据集的电极与采集信息；2027 年 9 月 1 日实施，当前仅作前瞻参考，不扩大为所有头皮 EEG 的强制要求。
- [M05 坏通道候选](/standards/modules/M05)、[M06 生理伪迹线索](/standards/modules/M06)：比较组和依赖条件的具体用法。
