# M01 数据接入与结构核验

模块说明 · 适用实现：工作台 1.0.0rc1 · 文档版本：0.3

本模块通过格式适配器提取技术信息、核对配套文件，并将可用电压转换为统一分析单位。读取成功不等于模态已确认，也不等于信号质量合格。

[关联规范](/standards#51-m01-数据接入与结构核验) · [下一模块：M02 数据画像与检查计划](/standards/modules/M02)

## 1 用途与适用范围

当前接入连续 EDF/EDF+、BDF、BrainVision 三件套、连续 EEGLAB SET（内嵌数据或配套 FDT）及单文件 Raw FIF。多文件记录通过 ZIP 一起上传；配套文件保持同目录引用。

EDF+D、BDF+D、注释专用 EDF、分段 EEGLAB、FIF 分卷及非 Raw FIF 不纳入本版连续检查。当前 BrainVision 适配器明确拒绝重名通道。读取器可以保留非 EEG 通道和可提取的其他模态技术信息；只有确认的头皮 EEG 才进入相应质量检查。

## 2 输入与前置条件

本模块是固定步骤，没有计算前置模块。输入为单文件或包含唯一记录入口的 ZIP。主文件及其引用的成员须完整，引用不得指向包外、远程位置或符号链接。

技术信息先读取，模态和通道角色随后确认。原始索引是通道身份依据；支持重名的格式保持独立，不支持的适配器应明确拒绝，不静默改名。扩展名、名称推断和读取器默认类型不能替代来源核对。

## 3 处理流程与方法

### 3.1 格式适配与结构核验（已接入）

按入口格式选择读取器，核对文件结构、记录长度、采样信息、通道定义和伴随文件关系，并输出统一的数据描述。各格式的读取与信号算法分离。

EDF/BDF 核对头长度、记录完整性及数字/物理端点，按原生采样流读取。BrainVision 由 VHDR 引用波形和标记文件；EEGLAB 由 SET 的数据字段确定内嵌或外置 FDT；FIF 保留声明的信号类型和源样本起点。

### 3.2 单位与电压标定（已接入）

EDF/BDF 按数字和物理范围标定；其他适配器依据格式声明、分辨率或读取接口的标定转换。BrainVision 规范默认单位与文件显式单位分别注明来源。分析所选信号须可靠转换为 V。

非电压单位保持原义，不强制赋予 V。缺少文件量程端点时，不补造端点平台证据。此处是数值读取核验，不是设备计量、噪声或电极阻抗试验。

### 3.3 来源、时间与注释保留（已接入）

主文件和必要伴随文件分别记录指纹。源通道名、原始索引、原生采样率、样本起点与时间偏移保持可追溯。FIF 的非零 `first_samp` 不重置为源样本 0；选区秒时间仍相对文件首样本。

可读出的注释作为来源信息保留，不自动作为质量真值或 M07 已登记事件表。EEGLAB 边界按连续段表示，不将删除段静默拼接为无间断采集。

当前只有 FIF 适配器提取源文件声明的高通和低通信息；该声明不构成实际滤波传递函数验证。其余格式缺少的采集滤波史保留未知。

## 4 输出与解释

主要证据文件为 `M01_input.json`，`header` 为格式统一核验结构。

| 输出 | 内容与单位 | 如何解释 |
| --- | --- | --- |
| `header` | 结构核验、通道声明及问题 | 读取通过不等于信号无伪迹 |
| `streams` | 原生采样率 Hz、样本数、起点、时长 s | 保留时钟和连续段，不表示已重采样 |
| `source_files` | 主文件和必要伴随文件及各自指纹 | 多文件身份，不以主文件指纹替代全部成员 |
| `reader_id`、`reader_version`、`backend_version` | 适配器和依赖版本 | 复现读取行为的依据 |
| `annotations` | 格式中可提取的注释 | 来源事件，不是确认的伪迹标签 |
| `metadata.modality_evidence` | 声明的通道类型及需确认状态 | 技术证据，不直接给出诊断或模态结论 |
| `warnings` | 结构、解释或能力限制 | 与实际所选通道和方法一起复核 |

条件不足或警告保留具体原因。无法安全读取、不能可靠标定所选信号，或文件指纹不一致时，不继续解释相应下游数值。

## 5 配置参数

| 约束 | 当前实现 | 性质 |
| --- | --- | --- |
| 上传大小 | 单文件或 ZIP 请求最多 512 MiB | 平台资源约束，不是记录质量标准 |
| 多文件引用 | 唯一入口、同目录实体成员 | 不自动猜文件、不读包外成员 |
| EDF/BDF 通道数 | 1–4096；每记录采样点大于 0 | 对应格式适配器的结构检查 |
| 分析单位 | V；显示可换算 µV | 根据可核验标定转换 |
| 隐式处理 | 不自动重采样、重参考或跨流对齐 | 各方法副本处理另行记录 |

上述为当前接入配置，不是行业信号合格线。选区和执行资源限制见 M02；格式可读也不表示每项检测都满足带宽与时长条件。

## 6 验证与使用限制

已有八个代表性 EDF 默认选区的独立读取逐点一致性证据。新增 BDF、BrainVision、EEGLAB、FIF 小样例已核对上游指纹、技术头及读取结果；这些工程样例不构成自然伪迹准确率验证集。

五类格式已完成实际 HTTP 接入至报告流程，未出现失败模块；部分方法仍因时长、带宽或信息不足未评。该结果验证流程连通，不表示所有方法均可评或检出准确率已通过验证。

BDF 和 BrainVision 夹具分别仅 1 s 和 7.9 s，部分方法必然因时长不足未评。FIF 示例含 MEG 与 EEG，不能全部作为头皮通道。EEGLAB 教程事件不等于技术质量真值。

文件头不能保证采集说明完整真实，缺少的坐标、滤波史、参考与背景保留未知。读取器的格式默认值应与文件明确声明区分。后续计算不写回原文件，并复查来源一致性。

## 7 来源与关联条款

- [EDF 官方格式](https://www.edfplus.info/specs/edf.html)、[BioSemi BDF 说明](https://www.biosemi.com/faq/file_format.htm)：记录结构、标定与状态通道。
- [Brain Products BVCDF](https://www.brainproducts.com/support-resources/brainvision-core-data-format-1-0/)、[EEGLAB 数据结构](https://eeglab.org/tutorials/ConceptsGuide/Data_Structures.html#saved-set-files)：配套文件与存储组织。
- [MNE BrainVision](https://mne.tools/stable/generated/mne.io.read_raw_brainvision.html)、[EEGLAB](https://mne.tools/stable/generated/mne.io.read_raw_eeglab.html)、[FIF](https://mne.tools/stable/generated/mne.io.read_raw_fif.html)：相应读取接口与时间、单位语义。
- [BIDS EEG](https://bids-specification.readthedocs.io/en/stable/modality-specific-files/electroencephalography.html)：元数据组织参考；本模块不是完整 BIDS 验证器，FIF 支持不改变 BIDS EEG 格式范围。
- [YY/T 1833.2—2022 正文](https://app.nidc.org.cn/jianybz/bz_file_pdf/wwgk/ylqxtjxhybz/2022/20220720/YYT183322022.pdf)：第 4.1.1–4.1.3 条涉及数据说明、来源及采集依据，不构成读取软件认证。
