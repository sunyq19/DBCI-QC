# EEG 评分 v0.1 历史记录

本页保留 2026-10-31 的旧公式，用于解释历史报告；当前规则见 docs/eeg-scoring.md。

### 项目试行基础评分

EEG 选区报告可展示 `eeg-basic-screen/0.1` 基础初评分，明确标注“项目试行 v0.1”。此指数反映以下三项检测的候选负担，尚未经过专家校准，不是可用数据百分比或行业合格标准。

| 分项 | 计算公式（0–100） |
| --- | --- |
| 信号完整性 | 有限且非恒值样本数 / 已检查样本数 × 100 |
| 工频干扰 | （1 − 命中通道窗数 / 有效通道窗数）× 100；同通道同窗跨频带去重 |
| 高频突发 | （1 − 候选通道秒数 / 有效通道秒数）× 100；使用已合并的每通道候选时长 |
| 基础初评分 | 三项未舍入分数的等权平均 |

三项均覆盖选中通道且有有效分母时才计算总分。缺项保留 null，不重新分配权重。ADC 端点、参考组内异常判定及辅助锁时结果另行展示，暂不计入此基础指数。任何局部候选仍应和分数一起显示，不设“合格”分界线。不同配置、版本和范围不直接比较。

结构化数据保存在 `report_view.score`，含版本、各项分子、分母、权重和有效通道数；它与原有未校准的 `score.value` 分开。新运行保存该视图；历史运行只生成新的显示视图，不回写原检测结果。整记录和其他模态不套用此单选区公式。
