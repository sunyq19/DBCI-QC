# EEG 质控标准与规则记录

版本：0.1 · 更新：2026年10月29日 · 状态：项目研究草案，待团队审议

**这份文档回答三件事：依据什么检查、怎样解释结果、拿什么证明判断可靠。** 先面向头皮 EEG 建立可核对的规则，再按数据与应用扩展。它是项目的规则账本，列明引用依据、当前实现和待验证事项；尚未形成统一的 EEG 质量合格线。

## 一 会议讨论与会后目标

会议部分根据2026年10月26日15:00的文字稿整理，不据转写结果认定具体发言人；以下为讨论方向，并非已经表决通过的标准。会后提出的实施目标另行标记。

- **会后目标：以数据为入口。** 先接收有来源、采集说明和配套标注的代表性数据，按模态、采集条件和用途拆分模块，跑通报告，再汇总不同场景下的评价规则。
- **数据本身质量与应用适用性分开。** 噪声较大的通道仍可能用于负样本研究；电极未覆盖任务相关脑区，可能影响运动解码，但不能仅凭没有任务响应就判为技术坏道。
- **每个判断要有理由。** 报告给出分项指标、受影响的通道和时段、判断依据与适用范围，让使用者知道问题在哪里。
- **总分是待研究的目标。** 会议讨论了统一到 0–100 分及相对评分的可能性，没有确定换算公式、权重或合格分数。当前先保留分项和证据，不生成没有校准依据的总分。
- **模块服务于不同需求。** 先形成可组合的工具和规则；后续自然语言或智能体可以据需求组织流程，其采用的规则和实际执行过程仍需可追溯。
- **会后目标：近期先形成可运行的典型流程。** 结合雷老师提供的方法与数据、灵犀云后续提供的工具和其他开源方法收敛方案。11月26日前跑通若干典型数据完整报告，是后续提出的阶段目标，不作为本次会议决定或已经完成的事项。

以下为项目拟采用的报告口径。**缺失、未知、不适用、未执行和执行失败要分开记录。** 当前已有字段优先复用，待补字段不以默认值冒充实际采集信息。

| 信息组 | 应记录什么 | 当前落实与缺口 |
| --- | --- | --- |
| 数据身份 | 匿名记录标识、来源/版本、文件格式、原始或派生、文件指纹 | 已有记录与指纹；上传文件未自动获得完整数据集来源 |
| 分析范围 | 文件总时长、本次原始起止时间、样本范围、实际检查通道、未检查范围 | 已记录选区；当前单次最多120秒，不能写成完成整夜质控 |
| 通道与采集 | 文件通道数、EEG/辅助导联、原始索引和名称、单位/标定、各采样率、参考、位置、滤波史 | 技术头、选道、参考配置可保留；完整位置、阻抗和处理史尚需资料与专门字段 |
| 数据背景 | 模态、疾病/年龄/任务及来源，随时间变化的状态和事件 | 背景可补充；当前疾病、年龄、任务不改变检测阈值，不据文件名推断诊断 |
| 结果与依据 | 方法、原始指标、单位、阈值/参数、适用条件、通道/时间定位、候选及证据图 | 已有方法产物和报告；完整参数通常在 JSON 中，摘要不代表全部细节 |

## 五 九个模块的规则范围

当前入口为连续 EDF/EDF+，须由用户确认属于头皮 EEG，并确认所用通道。EDF 是文件格式，不能据扩展名推断模态。ECoG、sEEG、Neuropixels 及其他文件格式还需要各自的读取、适用条件和验证，尚不套用这一版规则。

| 模块 | 核心检查 | 适用条件与结果解释 |
| --- | --- | --- |
| M01 接入核验 | 结构、通道、采样与电压标定、文件指纹 | 无法可靠标定或不支持的结构明确拒绝；可读取不等于质量好 |
| M02 数据画像与计划 | 明确选道、参考比较组、分析范围，安排可执行方法 | 真实技术条件决定能否运行；未知背景不自动补全，运行前冻结计划 |
| M03 完整性 | 非有限样本、恒值、标定端点平台及可选幅度检查 | 输出原始通道和时间候选；相邻样本恒值与低生理振幅不是同一概念 |
| M04 频谱与干扰 | Welch 功率谱、可测工频及谐波、背景谱与α描述量 | 保留单位与参数；采样和频带不足的部分未评，谱形差异不直接判坏 |
| M05 坏道候选 | PREP 非空间分项及可选桥接、LOF | 同参考可比组内评价；低相关或幅度离群也可能来自生理/病理差异 |
| M06 生理伪迹线索 | ECG/EOG 锁时、高频突发及 EMG 支持 | 需要相应辅助信号与带宽；M03 候选用于保护，缺 EMG 时不确认肌电 |
| M07 状态与事件 | 登记的睡眠、任务、临床事件时间核对 | 没有配套标注则未评；病理事件、任务事件与伪迹真值分别保存 |
| M08 分项汇总 | 汇总实际执行、候选与未评项，明确可比范围 | 当前没有可靠的统一总分；执行完成比例不是信号质量分 |
| M09 报告与复核 | HTML、JSON、证据图和审核状态 | 自动结果保留待复核；不自动清洗原始数据，不自动出具临床诊断 |

当前计算基线包括 [BrainElecQC](https://github.com/Jlei61/BrainElecQC)、[SciPy](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.welch.html)、[MNE](https://mne.tools/stable/index.html) 与 [autoreject](https://autoreject.github.io/stable/index.html)。BrainElecQC 的 PREP 非空间实现不等于调用完整 PyPREP；空间 RANSAC、local AutoReject、ICA/ICLabel 仍在待接入目录。

## 六 当前参数与阈值登记

本节登记的是**软件默认或本项目接入条件**，用于复现与后续校准，不是标准合格值。这里列出影响解释的关键默认，完整参数以该次冻结配置和方法产物为准。技术条件不足应跳过或保留受限结果，不为得到分数强行补值。

### 基础方法

| 规则编号与方法 | 当前默认参数或计算口径 | 使用条件及解释 |
| --- | --- | --- |
| R01 完整性 | 严格相邻值相等形成恒值段，最短0.1秒且至少2样本；近零分类基值0.1 μV，端点容差0.25个量化步长 | 非有限样本单独报告。0.1 μV只用于已找到的恒值段分类，实际近零容差还考虑半个量化步长；不是正常 EEG 振幅下限。文件量程端点平台不直接证明硬件饱和 |
| R02 频谱与工频 | Welch 4秒 Hann 窗、50%重叠，PSD为 V²/Hz；工频检验4秒窗、1秒步长、50/60 Hz及可测谐波±2 Hz，Bonferroni校正后p小于0.01 | 校正范围为全部通道×完整窗×唯一扫描频点；待测中心加2 Hz必须小于奈奎斯特频率。p值说明该算法的显著性，不是临床质量分；没有自动去工频 |
| R03 PREP 非空间 | 高通1 Hz、1秒窗；幅度稳健z绝对值大于5、高频z大于5；相关量低于0.4的可评窗比例大于0.01，或掉线窗比例大于0.01时给出候选 | 组阈值需显式参考比较组且至少4个有效可用通道，高频分项需采样率高于100 Hz；相关量为绝对相关的98%分位。非有限及全段std或MAD低于1e-15 V的平线候选独立于分组；组内离散度为零时z未评 |
| R04 ECG/EOG 锁时线索 | ECG检测带5–35 Hz、阈值auto；EOG为1–10 Hz、默认阈值为检测滤波后峰峰值的四分之一；最短10秒，EEG锁时范围为事件前后各0.5秒 | 需对应的同钟辅助导联、可测带宽和有效事件；输出锁时波形及幅度/相关描述，没有通用污染幅度扣分线。ECG自动选阈中的事件率启发式不是心率正常范围 |
| R05 高频突发及EMG支持 | 频带30至min(100, 0.45×采样率) Hz，带宽至少20 Hz、时长至少10秒；1秒窗、0.25秒步长 | 以下多项证据共同满足才形成候选；没有独立EMG支持时仅称高频线索，不能与R07混用 |

R02 的谱模型使用 FOOOF 1.1.1 的 fixed 背景、2–40 Hz拟合、30秒参数窗；每次拟合至少10秒且至少4个 Welch 子窗。α功率是8–13 Hz的PSD积分，单位 μV²，相对量分母为2–40 Hz功率；它包含非周期背景，不等于模型背景上方的峰高。没有α峰或模型拟合较差都不直接触发质量扣分。

R05 当前候选条件为同时满足：不与连续性保护区重叠；z大于4的累计时间至少0.15秒；相对清洁窗中位数的高频功率比至少3；有效频点数至少5；非工频高频功率占比至少0.2；清洁高频占目标总带功率至少0.01；最大差分能量占比不超过0.25。有同步EMG时，还需其包络z峰至少2且包络相关至少0.5，才标为有EMG支持。这些量依赖分析选区与内部滤波，不能跨任意窗口直接比较。

R01–R05 据本机 BrainElecQC 0.1.0 安装源码 `continuity.py`、`spectral.py`、`alpha_power.py`、`bad_channels.py`、`events.py`、`muscle.py` 核对；实际产物为 M03/M04/M05/M06 对应 JSON。公式、参数全表及源码指纹留存在项目工作目录 `work/qc_standards_method_audit_20261029.txt`、`work/qc_standards_default_snapshot_20261029.json`。软件包版本相同也应核对具体源码与参数。

### 可选方法

| 规则编号与方法 | 当前默认参数 | 使用条件及解释 |
| --- | --- | --- |
| R06 MNE 相邻采样变化和平线 | `flat_volts=0`、`min_duration_seconds=0.1`、`bad_percent=5`；`peak_volts=null` | 看相邻采样差值，不是固定窗峰峰值；5% 是方法分流参数，不是公认坏道界线 |
| R07 MNE 高频线索 | 110–140 Hz、z 阈值4、短好段间隙合并0.1秒 | 原生采样率高于280 Hz、至少10秒，已知滤波不能切掉目标频带；滤波史未知时仅探索性输出。跨所选通道聚合，没有单道定位，不自动确认为肌电 |
| R08 MNE 桥接候选 | `lm_cutoff_uv2=16`、`epoch_threshold=0.5`、2秒段、0.5–30 Hz | 经确认的共同/连接耳参考、单一完整比较组、至少8道与10秒；16 μV² 是拟合范围上限，不是最终桥接阈值 |
| R09 MNE LOF | 邻居数20、欧氏距离，原始负LOF的绝对值大于等于1.5时给出候选 | 同上参考/比较组条件，默认至少21道与10秒；离群是整段通道候选，不能反推出异常起止时间 |
| R10 autoreject 全局阈值 | 2秒不重叠固定段、5折、随机种子0、不降采样；阈值由当前数据估计，单位 V | 至少20个完整段且不少于4倍折数；同一选区拟合并标记候选，内部交叉验证不等于独立准确性验证 |

来源：[MNE 幅度](https://mne.tools/stable/generated/mne.preprocessing.annotate_amplitude.html)、[MNE 高频](https://mne.tools/stable/generated/mne.preprocessing.annotate_muscle_zscore.html)、[MNE 桥接](https://mne.tools/stable/generated/mne.preprocessing.compute_bridged_electrodes.html)、[MNE LOF](https://mne.tools/stable/generated/mne.preprocessing.find_bad_channels_lof.html)、[autoreject 全局阈值](https://autoreject.github.io/stable/generated/autoreject.get_rejection_threshold.html)。适配条件以本项目 `extensions.py`、`extra_methods.py` 为准，不能只照搬线上最新版的默认值。

## 七 分项 总分与数据间比较

**当前先看指标与证据，总分保持 `null / 未校准`。** 平台尚未实现跨疾病、跨模态的0–100分质量映射。不得把候选数、方法投票数或运行完成率直接换算为“数据质量”。

同一模态和同一疾病只构成初步分组。实际比较还要核对参考/导联、采样和有效带宽、处理史、状态/任务、分析时长、通道覆盖、方法与参数版本。无法对齐时报告差异，不能强行排名。来自同一个人的不同记录也不能当作完全独立样本。

拟建立的分项包括完整性、频谱干扰、通道一致性、伪迹及元信息完整程度。分项应先报告原始量、方向和单位；一个指标可以用于描述，不必马上设“合格/不合格”。候选时间、候选通道、通道对和分析分段分别计数。未来计算比例时，必须明确已分析时间/通道等分母，重叠时段取并集，未分析部分不能当作正常；当前尚未形成跨方法的统一坏时长或综合评分。

总分落地前，团队需固定目标用途和独立专家标签、分项方向与归一化方法、权重及缺项处理、关键问题能否被平均分抵消、校准集与独立评价集划分。阈值冻结后报告误报、漏检、复核一致性及适用范围，再决定总分能否用于比较。尚未确定合格分数、通用坏道比例或跨模态换算方式。

## 八 数据与验证依据

已有本地验收环境保存5个公开数据集的15份 EDF 上传副本，目录以 `/path/to/edf-upload-examples` 表示。该路径为目录占位，克隆仓库不会附带样例文件。其中11份另有预登记场景配置。两者不是相同入口：手动上传不会从文件名继承事件、疾病、参考或特殊时间窗。目录内的来源清单与指纹用于追溯原件，15份记录不等于15名独立受试者。

| 数据 | 主要验证用途 | 已有标签的边界 |
| --- | --- | --- |
| EEGMMIDB | 静息、真实运动与运动想象；多通道、160 Hz 的接入和方法适用性 | 任务事件不是伪迹真值；没有独立 ECG/EOG/EMG 配置时不能作辅助导确认 |
| HMC | 睡眠及心眼肌电辅助信号；少 EEG 通道与参考分组条件 | 睡眠分期不是质量标签；通用上传默认起始段不等于指定睡眠期 |
| Sleep-EDF | 双极少导、混合原生采样率、睡眠阶段对齐 | 低采样率辅助信号不自动上采样混入 EEG；没有标注时不推断睡眠阶段 |
| OpenNeuro ds002034 | 注意任务、512 Hz、来源通道标签与独立比较 | 来源 good/bad 标签需核对其口径；整记录标签不能直接当作每个短窗的真值 |
| CHB-MIT | 临床双极 EEG、重复名称与发作背景 | 发作标签不是伪迹；默认前120秒不覆盖所备记录已知的后段发作 |

截至本版，15份副本均已通过通用读取、角色建议、确认与推荐规划；一份 HMC 副本在无预登记配置的隔离环境中完整生成报告。已完成多种真实场景运行，以及部分已知平线、工频注入检查。**这些证据证明有限范围的功能和可重复运行，不足以证明所有坏道或伪迹判断准确。**

必须保留的负结果：既有 ds002034 两份全长 PREP 非空间结果曾为0个候选，与来源标出的4个 bad 通道存在分歧；原因尚未确定。不能因新增方法给出更多候选就宣布已解决这一问题。

后续验证分别登记四层：工程运行、已知故障注入、独立真实质量标签、目标应用效用。疾病/任务标签不进入质量真值；阈值开发与最终评价按受试者等真实依赖层级隔离。下一批重点补充自然伪迹的通道×时间标注、专家分歧记录及不同设备/参考条件的数据。
