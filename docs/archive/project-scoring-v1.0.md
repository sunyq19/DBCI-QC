# EEG 项目评分规则

项目试行规则 · `project-weighted/1.0` · 2026年11月7日 · 未经专家审核

[技术规范](/standards) · [检查词条](/standards/eeg-checks) · [报告要求](/standards/eeg-report) · [M08 分项评价](/standards/modules/M08)

## 1 范围与含义

本版对连续头皮 EEG 的三个基础检查项提供 0–100 分。分数越高，表示所选检测方法检出的候选占比越低。分数是项目自定义的汇总，不是行业合格标准、诊断结论或数据可用率。

| 模态 | 本版可计分项 | 其他输出 |
| --- | --- | --- |
| 头皮 EEG | 信号完整性、工频干扰、高频突发 | PSD、坏通道候选、辅助导联线索、事件核对 |
| ECoG | 暂无 | 完整性、频谱、触点描述 |
| sEEG | 暂无 | 完整性、频谱、触点描述 |
| Neuropixels 原始 AP/LF | 暂无 | 数值完整性、频谱、通道描述；不评价分选后的单元 |

后三类尚未定义可接受的候选判定和评分分母，不能使用头皮 EEG 的阈值，也不能将“读取成功”换算为质量分。数据集的文件完整性与个体一致性检查仍以数量、检查发现和证据报告，不与信号评分相加。

## 2 模块的评分属性

每个信号模块在目录中声明 `can_output_score` 与 `scoring`，后者包含角色、分项标识、规则版本和原因。可视化方法声明不可计分。

| 模块 | 头皮 EEG 的评分输出 | 加权角色 |
| --- | --- | --- |
| M01 文件读取 | 否 | 来源与结构证据 |
| M02 信息与计划 | 否 | 确认范围、冻结配置 |
| M03 信号完整性 | 是：integrity | 可设置权重 |
| M04 频谱与干扰 | 是：line_noise | 仅工频候选计分；PSD 本身不计分 |
| M05 通道质量 | 否 | 保留 PREP、频谱差异等通道候选 |
| M06 伪迹线索 | 是：hf_burst | 仅高频突发计分；不将辅助线索重复扣分 |
| M07 事件与时间 | 否 | 核对结果 |
| M08 分项汇总 | 是：总分 | 汇总器，不再作为一个加权分项 |
| M09 报告与复核 | 否 | 展示与导出 |

“可计分”是方法能力，不等于本次一定有分数。未运行、必要通道缺失、频带已滤除或有效测量不足时，仍应返回未计分。

## 3 分项公式

```text
分项分数 = 100 × (1 − 候选量 / 有效检查量)
```

| 分项 | 候选量 | 有效检查量 | 单位 |
| --- | --- | --- | --- |
| 信号完整性 | 非有限或恒值样本的并集 | 所选通道全部被检查样本 | 通道样本 |
| 工频干扰 | 至少一个目标频率命中的通道窗；跨频率去重 | 实际可评估的通道窗 | 通道窗 |
| 高频突发 | 检测器给出的候选区间时长 | 检测器实际有效时长 | 通道秒 |

先累加各通道、各时间块的候选量与有效检查量，再算比例。不平均窗口分数，不将重叠工频窗称为污染时长。所有选中通道须具有有效证据；不能用未测通道补零。候选是否形成由原检测器决定，本次公式调整不改变检测阈值。

## 4 总分与权重

```text
总分 = Σ(分项分数 × 权重) / Σ权重
```

默认已选择的可计分项等权，通常为 1∶1∶1。权重可设为 0–100 的有限非负数，不要求加起来等于 100；界面同时显示归一化比例。0 表示不参与总分，至少保留一项正权重。

例如：完整性 100、工频 60、高频突发 95，权重 1∶2∶1：

```text
总分 = (100×1 + 60×2 + 95×1) / 4 = 78.75
```

正权重项目未计分时，总分为空并列出缺项，不自动重新分配权重。未选择模块不能设置正权重。权重为 0 的项目可以继续检查并报告测量结果。整份检查未覆盖完成、来源间隙或来源核验失败时，不生成整份总分。

## 5 报告中的必要内容

总分、分项分数与权重、规则版本、配置标识、实际检查范围、候选量及分母应同时保留。可疑通道及时间段独立展示；加权平均不能遮盖局部异常。

100 分仅表示参与计分的检查没有检出计分候选，不表示全部技术问题均已排除。简单清洗后的数据可能较高分；已确认被滤除的频带不可作为“无干扰”计分。处理史未知时明确保留未知。

## 6 比较和版本

只有模态、方法及参数、选道与时间范围、处理状态、规则版本和权重配置一致，才能解释分数差异。相同权重本身不足以保证可比性。不进行 EEG 与侵入式数据的总分排名。

配置冻结在 `qc_config.scoring` 中并参与计划指纹。更改权重会产生新计划。历史运行的检测证据和原始报告不改写；显式发布评分修订版时，展示旧版本与原报告入口。旧版 `eeg-basic-screen/0.1`、`eeg-basic-screen/0.2` 保留用于追溯，新任务使用本版。

本规则首先解决计算清晰、可配置、可复现的问题。权重、候选判定的准确性、其他模态评分及合格界线仍需代表性数据与专家复核；不因示例得分高而临时改公式。
