# EEG质控顶层设计

日期：2026年10月28日。版本：0.1，方案草案。对象：头皮 EEG。用途：讨论模块边界、数据标签、报告字段及首版验收；本方案尚未改写现有算法或工作台评分。

平台先回答三个问题：这份数据是什么、哪些检查适用、每个判断有什么证据。采用同一套接入和结果接口，以采集条件及研究场景选择检查模块。国内外规范用于确定记录要求和适用场景；算法论文用于选择检测方法；平台评分需要另行验证。

## 可以采用的共识

EEG 的采集描述、技术条件和报告内容已有较成熟的规范。自动坏道判断有成熟的方法体系，但不能据此认定某个软件默认阈值、坏道比例或百分制总分已经成为通用标准。

| 依据 | 可以支撑什么 | 适用边界 |
| --- | --- | --- |
| IFCN与ILAE 2023常规和睡眠EEG最低记录标准 | 临床常规及睡眠记录的技术条件与记录要求 | 针对其临床场景；不能把最低采样率、电极配置直接推广成所有研究EEG的合格门槛 |
| ACNS常规EEG技术和报告指南 | 将采集技术信息与解释性报告组织起来 | 临床诊断报告与科研数据质控报告用途不同 |
| EEG-BIDS 1.11.2 | 数据组织、采集参考、采样、滤波及通道描述等元信息 | 元数据组织规范，不提供统一坏道算法或质量总分 |
| COBIDAS MEEG研究报告建议 | 研究设计、采集、预处理与剩余数据量的可复现说明 | 研究方法报告框架，不指定适合所有数据的唯一质控算法 |
| YY/T 1833.2—2022 | 数据集质量声明、完整性、代表性、评价与追溯框架 | 人工智能医疗器械数据集通用要求；波形检查不能替代全部数据集评价 |
| YY/T 2029—2026 | 特定脑机接口医疗器械脑电数据集的采集、处理、标注与管理要求 | 已发布，2027年9月1日实施；截至本文日期尚未实施；科研平台可以参照，不能直接声明符合 |
| CAAE临床指南及质控文件 | 国内临床采集、记录与人工复核的背景依据 | T/CAAE 002—2026仅核到目录，尚无正文；不能用旧版指南替代其条款 |

参考：[IFCN与ILAE正式论文](https://doi.org/10.1111/epi.17448)、[ACNS指南目录](https://www.acns.org/practice/guidelines)、[BIDS EEG规范](https://bids-specification.readthedocs.io/en/stable/modality-specific-files/electroencephalography.html)、[YY/T 1833.2正式全文](https://app.nidc.org.cn/jianybz/bz_file_pdf/wwgk/ylqxtjxhybz/2022/20220720/YYT183322022.pdf)、[YY/T 2029官方目录](https://hbba.sacinfo.org.cn/stdDetail/866eaadd4e5c255fdb8e12030faa6b574a71658ab56fa22d356104c3561fd11b)、[CAAE 2026团标目录](https://www.ttbz.org.cn/standardDetail/3dbp0828nk5v40yqbkss6m7m651q4sj.html)。

具体例子：IFCN与ILAE在非急诊常规/睡眠临床场景建议可行时使用25电极布局，否则10–20布局可接受；最低采样率256Hz；0.5–70Hz是显示滤波建议。这些数值可放进该临床场景的核对卡，不能当作所有研究数据的拒收线。COBIDAS则更适合支撑研究处理过程的记录。[IFCN与ILAE正文Table 3及§3.2](https://doi.org/10.1016/j.clinph.2023.01.002)、[COBIDAS正式论文](https://doi.org/10.1038/s41593-020-00709-0)。

规范冲突应保留来源。例如，上海2021临床操作共识与CAAE 2022指南对于常规陷波设置的措辞不同。因此平台分别保存采集滤波、已有处理、显示滤波和本次分析滤波，按选定规则解释，不自动把某份指南的显示设置施加到全部原始数据。[上海专家共识](https://www.shsma.org.cn/web/weixin/9099)、[CAAE 2022指南](https://www.caae.org.cn/Public/Uploads/20220118/video/61e6242d78ca7.pdf)。

## 首版的定位

首版评价原始或明确说明处理历史的头皮EEG技术质量，输出记录级概况、通道级异常候选、局部时段证据和复核材料。科研任务的可用性另作一层解释；不自动诊断疾病，不自动删除病理波形。

保留文件原格式。读取器将支持的格式转换成统一的内存访问接口，不要求先落盘转成EDF或NWB。内部必须能表达通道差异、时间断点、标定和已有处理历史。无法可靠表达的数据应明确拒绝对应分析。

首版先验证连续EDF/EDF+。后续分别验收BDF、BrainVision配套文件、EEGLAB文件及具体厂商格式；NWB可另加适配器。BIDS是一套数据组织约定，不等于单个文件容器。扩展名`.eeg`本身不足以识别厂商和编码。[EEG-BIDS原始论文](https://www.nature.com/articles/s41597-019-0104-8)。

## 九个顶层模块

流程为：M01读取 → M02确定适用项目 → M03至M07计算并产生证据 → M08汇总与比较 → M09报告与复核。M05可汇合M03和M04的指标，也调用独立空间一致性子模块；不要求重复计算同一指标。

| 模块 | 主要职责和子模块 | 输入与输出 | 关键边界 |
| --- | --- | --- | --- |
| M01 数据接入与结构核验 | 格式识别、配套文件、头字段、稳定通道ID、长度、时间轴、单位标定、读取器验证 | 文件包 → 统一记录及接入问题 | 文件能打开不等于单位和时间正确；错误标定应阻止幅度判定 |
| M02 数据画像与检查计划 | 整理标签、核对参考和布局、选择场景、判断每项能否运行 | 记录与提供方说明 → 冻结的检查计划及未评原因 | 未知值不自动填成健康成人、同一参考或无滤波 |
| M03 信号完整性 | 非有限值、缺失、恒值、近零平线、重复块、削波和饱和候选、断点 | 信号与时间轴 → 通道及时间区间指标 | 断点可能是合法暂停；低电压不直接等于掉线；缺少设备量程时只报削波候选 |
| M04 频谱与干扰 | PSD、50/60Hz及可测谐波、低频漂移、高频噪声、分窗变化 | 信号、采样、带宽和滤波史 → 频谱指标及证据 | 已陷波的数据只能描述当前残余干扰，不能反推采集时没有工频 |
| M05 坏通道候选 | 汇总基础异常、稳健幅度偏离、噪声比、相关性、空间预测、疑似桥接 | 基础指标与可比较通道组 → 逐项原因及局部/持续异常 | 空间和相对统计各自核对前提；不因一个算法投票就删除通道 |
| M06 生理伪迹线索 | EOG/ECG锁时或相关检查、EMG同步线索、无辅助导联时的弱证据 | EEG及辅助导联 → 伪迹候选与证据强度 | 无ECG/EOG导联时，不输出“已排除心电/眼电污染” |
| M07 状态和事件检查 | 睁闭眼/睡眠等分段、事件合法性、数量、持续时间、时钟及同步说明 | 标注和任务记录 → 分状态统计、事件问题 | 发作/睡眠等活动保留其来源；无外部时钟依据时不能验证真实刺激延迟 |
| M08 分项评价与可比性 | 按规则汇总、计算覆盖范围、识别关键失败、给出比较组 | 指标与适用性 → 分项结论、覆盖、可选总分 | 技术质量、元数据完整性、应用适用性分别呈现；不给未评项满分 |
| M09 报告与人工复核 | 图表、异常定位、复核修改、复核前后导出、版本及输入追溯 | 自动结果与人工意见 → 可读报告和统一结果 | 自动候选、人工确认、后续清洗分别保存，不能相互覆盖 |

这些是项目拟定的职责边界，不是某一标准规定的九模块模板。Linxi注册处理器与网页接口在边界稳定后分别适配。

## 哪些信息必须进入我们的报告

这里的“必须”指拟定的平台交付要求，不等于每个引用规范都逐项强制要求。每个字段都应区分已知、未知和不适用；从文件推断的值需要保留来源。

| 报告部分 | 应显示的内容 |
| --- | --- |
| 数据身份与范围 | 去标识记录ID、格式及厂商/读取器、原始或派生状态、总时长、本次分析范围、完整扫描或抽样、输入校验值 |
| 通道组成 | 文件总通道数、EEG数、EOG/ECG/EMG/触发等数、实际分析EEG数、排除通道及原因；不能把64个文件通道都默认算成EEG |
| 电极与参考 | 布局与实际覆盖、位置来源、采集参考、当前参考、不同参考比较组、地电极信息、阻抗及测量时间（有记录时） |
| 数值与采集条件 | 各通道或通道组采样率、单位、增益/偏置、可用量程及分辨率、有效带宽、电源频率、设备与软件版本 |
| 处理历史 | 采集滤波、已有离线滤波/重参考/重采样/插值/ICA/ASR等、本次分析与显示设置，保留原始和派生关系 |
| 使用背景 | 年龄、任务/采集场景、睁闭眼及睡眠/清醒时段、提供方确认的疾病背景、镇静和刺激等解释因素 |
| 每项质控结果 | 指标数值及单位、分析范围、分母、阈值及规则版本、异常通道和时段、支持图、判断原因、未评原因 |
| 汇总与复核 | 完整性、噪声、空间一致性、伪迹等分项；已评覆盖；关键失败；人工复核状态；算法及配置版本 |

BIDS为元信息命名提供参照；临床指南为采集和记录信息提供参照。自动候选、覆盖率、规则版本和复核追溯是本项目在这些基础上的设计。电极接触点、记录通道和后续显示导联要分别计数，不能互换。[EEG-BIDS](https://www.nature.com/articles/s41597-019-0104-8)。

## 标签的分层设计

标签用于选择检查和解释结果。采样率、通道数和年龄应保留原始数值，不能只存“高采样”“高密度”“成人”这样的粗标签。睡眠阶段、发作和刺激会随时间变化，应进入有起止时间的标注，而非仅有文件级标签。

| 标签组 | 建议字段或选项 | 对质检的影响 |
| --- | --- | --- |
| 数据形态 | 头皮EEG；格式/厂商；连续/分段/不连续；原始/派生 | 选择读取器、时间轴处理及可解释范围 |
| 通道与空间 | EEG及辅助通道数、通道类型、布局、位置来源（实测/模板/未知）、区域覆盖 | 决定哪些空间方法有条件运行；通道数本身不产生质量扣分 |
| 参考与标定 | 采集参考、当前参考、比较组、单位/增益可信度 | 决定幅度和相关性指标是否可比 |
| 采集与处理 | 各采样率、带宽、工频、滤波、重采样、插值、ICA/ASR、干/湿电极、移动记录 | 决定能测的频段、原始噪声是否已不可恢复，以及处理后残余QC的含义 |
| 年龄和状态 | 实际年龄；新生儿另记适当发育年龄；清醒/困倦/睡眠/镇静/昏迷/未知；睁闭眼时段 | 选择已验证场景；状态相关波形只在适用时解释 |
| 采集目的 | 静息、ERP、运动想象、SSVEP、临床常规/视频EEG、PSG、ICU连续监测、移动记录等 | 决定是否检查事件、同步、分状态统计，以及是否需要应用质量扩展 |
| 临床背景 | 健康对照、癫痫相关、睡眠障碍、脑病/意识障碍、脑卒中或脑损伤、认知/神经退行性、精神/神经发育、其他、未知；允许多个背景并存 | 影响复核重点和验证分层；不直接改变阈值或扣分 |
| 解释与保护标注 | 提供方确认的发作/发作间期活动、睡眠阶段、镇静用药、刺激/植入刺激器、术后颅骨缺损等 | 标识需要保护和复核的活动；有关时段仍接受技术检查，不因此完全豁免 |

临床背景选项是项目用于组织数据的初始词表，并非医学诊断分类标准。不得从波形自动推断并填写诊断。`unknown`不能当作“健康”。药物与状态记录用于解释，不构成平台给出的医疗判断。

每个通道保留稳定ID、显示名、文件原索引以及正负电极映射；后续改名、选道或显示为双极导联时不能丢失身份。若后续加入ICA或ASR，补记有效秩、校准区间及来源；插值通道不冒充独立原始好道。

标签保留来源（文件头、配套说明、提供方确认、人工复核、程序推导）和冲突状态。与算法适用性有关的推断须经过确认；只根据通道名字猜测参考或电极类型，不能直接用于严格比较。

## 坏道方法如何选择

广泛使用的方法可以作为候选工具，并不意味着它们对所有疾病、所有年龄和所有参考方式共享同一阈值。原始指标先保留，再在指定场景中校准判断规则。

| 方法族 | 主要判断依据 | 建议位置及限制 |
| --- | --- | --- |
| 直接信号检查 | 缺失、平线、恒值、削波候选、极端幅度及局部突变 | 首版基础模块；技术原因仍要核实，不能把所有低振幅都叫掉线 |
| PREP / PyPREP | 幅度偏离、异常高频、相关性和空间可预测性等 | 首版头皮多通道基线候选；按子方法判断参考、位置和有效通道条件；检测与插值/重参考分开 |
| EEGLAB clean_rawdata | 平线、噪声、通道相关等检查，流程还可包含ASR | 可作方法对照；ASR是检测/重建或剔除突发污染的处理步骤，不能把重建后的结果当作原始QC |
| Autoreject | 针对分段数据学习通道阈值，结合局部修复/试次剔除 | ERP/试次型扩展；不直接作为所有连续临床EEG的默认流程 |
| FASTER | 多种统计特征的离群判断 | 后续基准对照；默认统计阈值不当成行业标准 |
| 人工复核 | 同时看原始波形、时频、空间分布和采集背景 | 对争议和病理活动形成参考标注；保留分歧与确认理由 |

方法来源：[PREP原始论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC4471356/)、[PyPREP官方文档](https://pyprep.readthedocs.io/en/stable/)、[clean_rawdata官方说明](https://eeglab.org/plugins/clean_rawdata/)、[Autoreject官方文档](https://autoreject.github.io/stable/)、[FASTER原始论文](https://doi.org/10.1016/j.jneumeth.2010.07.015)。

首版优先把直接技术检查、工频/频谱和PREP类坏道候选做好，不同时堆叠所有方法后用多数投票判坏。多方法共享相似特征时，投票并不代表独立证据。低相关可能涉及参考、覆盖和真实局部活动；异常大波形也可能包含研究目标。候选至少保留“哪个方法、什么指标、哪个通道、什么时段、什么条件、为什么可疑”。

## 影响执行的具体规则

| 数据情况 | 执行决定 |
| --- | --- |
| 未核实电压单位或增益 | 可以检查数字结构和缺失；不进行绝对微伏阈值判定 |
| 电极位置未知 | 运行无需位置的子方法；关闭要求空间坐标的预测/插值方法，记录原因 |
| 通道很少或有效空间覆盖不足 | 按具体方法的前提限制相关/空间分析；不预设所有算法通用的最少导数 |
| 混合参考或参考未知 | 核对比较组，限制跨组统计；不能自动视为同一参考 |
| 无ECG/EOG/EMG | 不运行依赖对应导联的确认性检查；可显示经验证的信号线索并说明证据较弱 |
| 采样或实际带宽不能覆盖目标频段 | 对该频段返回未评；提高采样率插值不能补回缺失带宽 |
| 已陷波或去伪迹 | 记录发生阶段；采集时已有滤波不自动等于派生数据，后处理产物才按生成关系标为派生；评价当前残余，不能反推滤波前干扰 |
| 有癫痫背景或发作标注 | 保留病理活动；将仅靠幅度/相关得到的可疑项送人工复核，不自动据此剔除 |
| 有睡眠或镇静时段 | 分状态解释；不把缺少清醒闭眼α峰当作质量不合格 |
| 只有研究用160Hz短记录 | 按目标频段检查；可标明不满足所选临床采集配置，不能直接宣布研究数据不可用 |
| 事件缺失或无法定位到EEG时间轴 | 基础信号QC仍可运行；依赖该事件定位的分析未评 |
| 有采集触发，但缺少物理同步校准 | 可以检查事件数量、次序、间隔及事件锁定片段；不能验证刺激实际到达时间或真实延迟 |
| 存在合法暂停、分段或不同采样率 | 读取器必须显式保留与处理；首版不支持时报告适配限制，不能静默拼接 |

这些是拟实现的门控规则。每条规则要绑定具体方法版本，并接受代表性数据验证。

## 评分和比较

报告首先给出可解释的测量，例如异常候选持续时间、通道时长占比、每道工频指标、疑似坏道数量、可评频段及缺失元信息。局部异常使用通道与时间共同定位；整道问题和某个短窗口问题分开。

各比例必须写分母。通道异常比例的分母是实际纳入该检查的EEG通道数；时段比例使用对应已检查时长。合并重叠区间后再计算时间占比，不能叠加成超过100%。抽样扫描明确抽样策略和覆盖，不推断未检查区域无异常。

保留百分制总分的产品位置，但作为项目特定、待校准的规则输出。规则未冻结时显示“未建立可比较总分”；关键输入损坏或某个必需维度无法评估时不输出看似完整的分数。不得通过把未评项目当满分，或不断缩小分母，制造可比较的高分。

相互比较至少要求：同一目标场景、算法及规则版本、参考和主要采集条件可比、处理阶段/处理历史/有效带宽可比、分析策略一致、评分维度和覆盖一致。疾病标签相同不足以满足这些条件。不同覆盖的旧版自动分数可以留作历史结果，但不能进入同一排名。

技术质量、元数据完整性和应用适用性分别呈现。用于某项ERP指标的质量，不一定等于用于另一频段研究的质量；不能用一个数字替代目标任务评价。[Boudewyn等2023方法论文](https://doi.org/10.1111/psyp.14365)。

## 首版验证矩阵

| 数据组 | 第一版要验证什么 | 支持边界 |
| --- | --- | --- |
| 成年多通道静息或简单任务EEG | 读入、完整性、频谱、可适用的坏道方法、完整报告 | 优先建立主流程；每种参考和布局记录前提 |
| 少导联睡眠或PSG中的EEG | EEG与辅助导联正确分类、不同参考分组、部分项目未评、分状态报告 | 验证降级运行；不承诺睡眠分期或疾病诊断 |
| 临床癫痫相关头皮EEG | 病理活动与技术伪迹候选的区分边界、人工复核一致性 | 等收到配套数据及专家标注后验收，不预先宣称自动坏道规则适用 |
| 新生儿、ICU深镇静、干电极移动记录等 | 先做接入和技术检查，保留场景标签 | 专用阈值、分数和全面适用性在后续独立验证 |

现有公开EEGMMIDB和HMC可用于接入、模块门控及回归核对。它们不能代替临床癫痫验证，也不能把多份文件当成同等数量的独立受试者。

验证分三层：先用已知注入故障检查单模块；再用真实数据和两名独立复核者检查通道及时间段候选，并保留争议裁定；最后完整回放文件接入、处理、页面、报告、导出与复核回写。开发与最终验收按受试者或记录来源隔离，冻结配置后再报告性能。面向疾病分类研究时，不能利用最终评测集的诊断或结局选择阈值或清洗强度。

验收记录至少包括：敏感度与阳性预测值、干净数据误报、病理活动被误标情况、不同标签组表现、专家一致性、每项未评比例，以及运行时间和资源需求。具体合格阈值在试标后与团队共同确定，不能先用一组未经验证的数字宣称达标。

## 对现有实现的安排

BrainElecQC先保留为基线执行器，把现有内部函数映射到上述职责；补齐输入画像、适用性、报告分母和结果追溯，再决定需要替换哪些具体方法。当前工作台能跑出的总分不自动升级为本设计的标准分数。

已有Linxi插件可以承接后续处理器封装。接入前修正通道ID、参考/位置元信息和结果字段一致性。例如`qc_status`与显示侧`status`的更新规则必须一致，才能避免算法发现异常而界面仍显示正常。

面向11月26日的首版目标建议定为：冻结报告字段与标签字典；跑通前两类代表性公开数据；完成一套可独立执行的模块计划和结果结构；完成真实候选复核的小规模试标或清楚标明临床材料待补。界面接入和Linxi封装不应改变这些科研定义。

配套的`eeg-qc-plan.json`保存模块、字段、门控规则和首版场景，状态为设计稿。它不是已安装插件目录，也不会自动启用现有工作台的新功能。
