验收记录 · 2026-10-31 · 软件1.0.0rc3.dev9 · 规范0.7 · 词条eeg-basic/1

本记录验证词条、实际方法参数、产物指纹、页面和报告之间的一致性，不评价自然伪迹准确率或外部标准符合性。原有算法与判据未在本轮重新调参。

## 1 本轮交付

- 12个词条对应M01–M09；14项资料性来源定位；中英文规范、词条与报告要求。
- 单一JSON生成中英文词条；新EEG任务保存目录字节/指纹、有效参数和实际证据索引。
- 模块执行、方法观测和人工结论分离；未评辅助事件及高频检查不把上游占位零解释为实测零。
- 整记录保留逐窗证据及文件名导出映射；子JSON不改写，原始文件不覆盖，旧任务不回填。

## 2 自动与安装核验

完整回归通过453项Python测试及194项前端静态契约。随后根据只读审阅修正未评高频计数和子文件导出映射，专项测试增至19项并全部通过；最终文档内部链接与锚点检查通过。未进行浏览器视觉走查。

实际构建wheel，并在临时隔离目录安装后导入工具包，读出1.0.0rc3.dev9、eeg-basic/1及12个词条。wheel内代码和JSON字节与当前源码一致。该核验只覆盖工具包分发与规则读取，不表示完整科学依赖的一键安装验收。

## 4 复算入口

依赖已配置的本地服务和登记的公开样例；输出文件必须为新路径。

```bash
python scripts/validate_eeg_standard.py --url http://127.0.0.1:8769 --output /path/to/new-eeg-acceptance.json
python scripts/build_eeg_specification.py --check
```

本脚本通过同一API提交真实任务，不使用合成结果替换真实报告。完整回归入口为scripts/check_release.py。词条目录变化应同时更新版本、重新生成文档并按改动范围重新验收。

- 尚无独立专家标注与冻结外部评价集，不报告灵敏度、特异度或临床准确率。
- 完整物种、年龄等字段未迁移至运行API，专项人群范围不作自动确认。
- 总分、分项归一化及跨设备/状态的判据尚未校准；不发布通用接受阈值。
