# 可视化模块

版本：`qc-visualizations/1.0`，2026-11-06。

## 职责与层级

```text
质控算法 → 保存指标、候选和来源 → VIS 结果可视化
                                 ├─ 波形与候选标记
                                 ├─ 通道指标
                                 ├─ 功率谱密度
                                 ├─ 工频命中比例
                                 ├─ 异常时间占比
                                 ├─ 异常时间轴
                                 ├─ 相对频带功率
                                 ├─ 频带平均幅值
                                 ├─ PSD 通道差异
                                 └─ 参考范围对照
```

可视化是独立展示层，不是新的质控算法。每种图可单独选择；只读已有证据，不改变原始信号、候选、评分或固定报告。两家方法按用途放在同一层级；来源信息保留在每个模块和图中。

当前适配头皮 EEG 的单窗口和整份分窗结果。整份报告可选择分析窗口；不简单平均不同窗口的 PSD、参考统计或时间比例。其他模态需要独立核对结果结构和单位后再接入。

## 图表与依赖

| 图表 | 来源指标 | 已实现的展示 |
| --- | --- | --- |
| 波形与候选标记 | 原记录、M09 波形证据 | 保存的起始波形；报告候选区支持前后浏览与最多 6 道同时间轴对照 |
| 通道指标 | PREP 非空间指标、灵犀云线长 | 幅值、高频比例、低相关占比、线长分别展示，不混合量纲 |
| 功率谱密度 | BrainElecQC PSD、灵犀云 PSD | 两条路线分图，统一为 dB re μV²/Hz |
| 工频命中比例 | BrainElecQC 工频观测 | 逐道命中窗口比例；不解释为异常时长比例 |
| 异常时间占比 | 灵犀云伪差/低频/高频检查 | 0–100% 横向条形图，保留缺测 |
| 异常时间轴 | BrainElecQC 高频突发、灵犀云候选 | 逐通道区间，使用原始记录的秒坐标 |
| 相对频带功率 | 灵犀云五频带比例 | 固定 0–100% 色标热图 |
| 频带平均幅值 | 灵犀云五频带幅值 | μV 热图；显示当前色标范围 |
| PSD 通道差异 | 灵犀云距离和候选 | 六频段热图，候选通道名橙色标识 |
| 参考范围对照 | 灵犀云参考上下界与当前值 | 参考区间与落点，按频带选择；不虚构 KDE 曲线 |

输入单位不同的 PSD 先做明确单位转换，再绘制同一物理量；不同处理历史的结果仍分图。通道数量、显示上限及时间区间均明确标注。条形图按值排序，热图保留原通道顺序；最多显示通道数可选择 16/32/64/128。PSD 为可读性展示前 12 道；完整数值仍在原始证据 JSON 中。时间轴最多绘制 500 个区间并显示总数。

颜色只表达数值或既有候选：蓝色为一般数值，橙色为原检查候选/参考范围外，灰色“未评”为缺测。图形渲染不产生新的坏道结论。

## 暂未接入

- **头皮地形图**：需要可信的电极坐标，或用户明确确认的标准 montage。当前不根据通道名静默填坐标；目录列为待接入。
- **多指标雷达图**：需确定每个指标的尺度、方向和归一化方法。当前不把不同量纲或参考范围拼成总分；目录列为待确认。
- 完整参考人群 KDE 曲线尚未进入结果契约，因此当前用真实上下界和当前值展示。

## 使用与开发

质控报告中展开“图表分析”。图表选择与显示配置不写回任务的算法配置。静态图可使用浏览器打印保存；原报告 PDF 导出维持原有内容，不声称包含全部可选图。

### 候选波形浏览（2026-11-07）

- 点击候选后，默认在原位置附近查看 10 秒。左右拖动、滑条或方向按钮可查看前后；窗宽可选择 1、2、5、10、20、30、60 秒，受原始连续段和资源上限限制。
- 移动距离按当前窗宽计算；“精细/正常/快速”分别为基准的 0.25、1、3 倍，按住 Shift 采用精细移动。松手后读取新时段，连续导航串行处理，不累积后台读取。
- “对照通道”最多选择 6 道，候选通道固定保留。同一原生采样流才可并排比较，不隐式重采样或对齐不同设备。所有通道共用时间轴，同单位共用幅度范围；黄色只标记被选候选通道。
- 波形取原始文件的标定物理值，不滤波、不重参考；超过显示点数时保留分桶极值及无效值断点，不用显示包络计算任何质控指标。浏览不会修改候选范围、检测结果或分数。
- 读取按连续段约束，不跨缺口拼接。浏览到本次检查时段之外时单独提示。每次读取仍核对冻结来源；单次不超过 60 秒、6 道、每道 2,000 个显示点及 64 MiB 原生样本。
- 入口：`GET /api/v1/jobs/{job_id}/waveform-context` 和 `waveform-window`。后者接受 `start_seconds`、`duration_seconds`、`channel_indices`、`max_points`；原 `waveform` API 继续维持 10 秒限制。
- 数据到期或来源不可用时，保留固定波形。公开示例只发布保存的展示快照，不含交互所需原始信号；PDF 仍为固定报告，不随用户平移或通道选择改写。

- 登记：`src/ephys_qc/visualizations/catalog.py`
- 渲染：`src/ephys_qc/visualizations/render.py`
- 按需读取：`src/ephys_qc/visualizations/evidence.py`；大型频谱 JSON 使用 `ijson` 流式提取 PSD 和工频计数所需字段，跳过绘图不使用的逐频率检验数组。普通 JSON 限 64 MiB，频谱证据限 1 GiB。
- HTTP 适配：`apps/workbench/visualization_page.py`
- 入口：`GET /api/v1/jobs/{job_id}/visualizations`
- 数据访问由主服务核对任务、文件声明和路径；渲染器只接收允许读取的证据，不接受任意文件路径。
- 不引入绘图脚本执行权限；SVG 和表单不需要第三方脚本或云端信号上传。

工作台安装脚本已包含 `ijson`。仅安装核心包的使用者可安装 `pip install -e '.[visualization]'` 以支持大型频谱证据。

验证包括：独立选择、输入不变、缺测与失败结果、窗口隔离、PSD 单位一致、标签转义。真实展示验证使用保存的 EEGMMIDB S001R01 与 OpenNeuro ds004504 sub-002 首 30 秒结果；这是展示契约验证，不是算法准确率评估。
