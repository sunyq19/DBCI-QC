# M04 频谱与工频观察

模块说明 · 版本 ecog-basic/1 · 2026-10-30

## 1 输入

原始电压、采样率及频谱配置。

## 2 处理

使用SciPy Welch计算PSD；在配置频率附近记录窄带功率和峰值位置。

## 3 输出

频率与V²/Hz密度数组、可测频带、窄带观察量和未评原因。

## 4 边界

不调用FOOOF、α评分、Thomson判定或肌电阈值；谱峰不能证明干扰来源。

## 5 来源与复核

本项目独立适配，读取与报告沿用已有模块；方法实现和执行成功不代表独立检测准确率。

[SciPy Welch](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.welch.html)
