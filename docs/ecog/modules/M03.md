# M03 基础信号完整性

模块说明 · 版本 ecog-basic/1 · 2026-10-30

## 1 输入

原始电压数组、原始样本索引。

## 2 处理

定位非有限值，以及至少两个相邻样本完全相等的连续段。

## 3 输出

触点、原始样本区间、计数及候选证据。

## 4 边界

精确恒值仅是技术描述，不使用头皮幅度或坏段时长阈值，不自动删段。

所有样本均参与扫描，每窗最多保存10,000条候选详细位置。超出时保留完整总数、逐触点计数与省略数量，状态标记为部分可评（partial）；未存下的位置不能视为正常。

## 5 来源与复核

本项目独立适配，读取与报告沿用已有模块；方法实现和执行成功不代表独立检测准确率。
