# M05 逐触点统计

模块说明 · 版本 ecog-basic/1 · 2026-10-30

## 1 输入

各触点电压及稳定源身份。

## 2 处理

逐触点计算有限值数量、均值、标准差、RMS和峰峰值。

## 3 输出

带单位的逐触点统计表，非有限值单独计数。

## 4 边界

不运行头皮PREP、LOF或电极桥接；基础统计不自动判坏。分组离群仅在下述条件满足时列出候选，不将候选等同于坏道。

## 5 来源与复核

本项目独立适配，读取与报告沿用已有模块；方法实现和执行成功不代表独立检测准确率。

## v0.2 补充规则

可选分组幅度离群，需逐道比较组及参考可比性确认；MAD为零或通道不足时不判坏。 完整输入、计算和输出见[颅内检查规则](/standards/ieeg-checks)。
