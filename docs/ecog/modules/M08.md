# M08 分项评价与汇总

模块说明 · 版本 ecog-basic/1 · 2026-10-30

## 1 输入

实际模块结果和未评状态。

## 2 处理

汇总运行覆盖、已评观察量、失败及未评原因。

## 3 输出

分项摘要；默认总分为 null。

## 4 边界

完成率不是质量分；不同参考、窗口和处理史下的统计不直接比较。

## 5 来源与复核

本项目独立适配，读取与报告沿用已有模块；方法实现和执行成功不代表独立检测准确率。

原版 MNE 平线／相邻变化提供通道候选占比与合并区间占比两项可选计分输出，默认权重 0。显式设置权重后按项目公式汇总，未评项按评分规则处理；不能将两项相加解释为污染时长。
