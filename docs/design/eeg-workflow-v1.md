# EEG 检查与复核流程 v1.0

状态：本地软件流程；评分仍为项目试行规则，未完成专家校准。更新：2026-11-06。

## 1. 使用顺序

读取文件 → 确认通道、参考与处理史 → 预览检查方案 → 后台检查 → 概览 / 问题复核 / 可视化。

数据集沿用同一条记录级流程：先做 D01–D03 资料检查，再勾选已确认记录，预览并启动批量信号检查。未确认的记录明确列为不可运行，不猜测其模态、通道或参考。

## 2. 模块与启用条件

| 层级 | 模块 | 本版行为 |
|---|---|---|
| 输入 | M01 读取 | 保留原生通道、单位、时钟和文件指纹 |
| 输入 | M02 确认与推荐 | 确认模态、通道和参考；增加高通、低通、陷波声明及依据。逐方法显示可检查和缺条件 |
| 检查 | M03–M07 | 按各方法条件执行；灵犀云扩展仍逐项可选，不自动并入基础评分 |
| 汇总 | M08 | 三项基础试行评分；未评不计为满分；新增同条件报告比较 |
| 复核 | M09 | 候选定位、原始波形、局部 PSD、接受/驳回/待定及版本历史 |
| 展示 | VIS | 独立可视化层，按已有证据选择图表；选择图表不触发新一轮质控 |
| 数据集 | D01–D03 / 汇总 | 资料检查、批次与记录级信号报告关联；不平均不同模态分数 |

## 3. 处理史与评分范围

已确认声明只表示来源有依据，不等于独立测量了实际滤波器。处理史未知时保留未知，报告只描述当前输入信号。

- 工频：高通、低通覆盖范围之外，或已声明陷波邻域内的目标频率，记为未评。其他目标仍保留测量，但原定可测目标未齐备时不生成该分项分数。原始检测观察保留在证据内。
- 高频突发：已声明滤波未完整保留本次方法频带时，该分项未评；不偷偷改窄频带后套用原分数。
- 缺少完整基础分项时，不生成三项总分；完整性等已有测量仍展示。
- 满分只能表示当前配置未检出对应候选，不证明清洗前无污染，也不证明适合所有任务。

实现版本为 `processing-scope/1.0`。新计划评分采用 `project-weighted/1.0` 的候选占比与配置权重，旧版 `eeg-basic-screen/0.2` 保留追溯；原始运行结果和历史证据不覆盖。

## 4. 复核操作

结果区分为概览、问题复核和可视化三个入口。点击候选后显示原始时间位置及所选通道；局部 PSD 使用所选原生采样计算 Welch 估计，固定记录窗长、单位和频率轴。显示包络不参与 PSD 计算；含非有限值的片段不伪造频谱。

支持基础检查及灵犀云线长、PSD 偏离、整体/低频/高频伪迹候选。仅有整窗定位的方法保持整窗定位，不虚构精确污染起止点。人工复核另存，有版本冲突保护，不改算法候选和试行分数。

## 5. 批量运行

一次最多选择 100 份已登记记录。方案固定输入版本、方法参数、检查范围及计划标识，预览后确认启动。后台依次执行，父批次关联每份子任务、状态和报告；重复确认同一预览不会创建重复任务。

缺信息的记录保留原因；单份失败继续后续记录。停止批次时取消本批次的活动任务并停止后续提交。服务重启将未完成批次标为中断，保留子任务和历史；重新启动须重新预览。该能力是本地调度，不代表云端队列已交付。

## 6. 报告比较

一次选择 2–100 份已完成 EEG 报告。按模态、通道与采样率、参考、处理史、上下文、方法参数、检查范围/时长、评分版本和执行源码版本分组。只有条件一致且必要信息已确认，才标注同条件比较。

分项同时保留有效测量量，缺项显示未评。不同组只并列展示，不跨组排名、不补零、不平均成新的数据集总分。比较结果由保存的证据生成，不重新执行算法。

## 7. 后续边界

专家校准、清洗前后配对评价、不同长度的可比性验证、跨模态评分、云端身份隔离及任务资源限额继续单独推进。
