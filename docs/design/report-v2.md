# EEG 初版报告设计

版本：report-view/2-design · 2026-10-31
历史设计记录：本页保留 v0.1 初版方案。当前评分已升级 v0.2，现行要求见 docs/eeg-scoring.md 与 docs/eeg-report.md。

## 1. 初版交付什么

上传数据，得到一份能看懂、能定位问题的报告：**一个基础初评分、三个数值分项、需要复核的通道和时间**。

| 页面层级 | 展示内容 |
| --- | --- |
| 评分概览 | 总分、三个分项、一句结论；文件、通道、采样率、检查范围 |
| 重点复核 | 发现了什么、在哪个通道、哪段时间；工频按命中窗数排序 |
| 检查明细（展开） | 完整性、频谱、通道、生理伪迹、标注的实际结果 |
| 评分依据（展开） | 公式、方法参数、证据文件、版本 |

可选检查缺少条件时，在明细里写清影响哪一项。已完成的检查正常展示，不把整个模块都显示为“受限”。执行失败仍须明确显示。

## 2. 项目试行评分 v0.1

名称：**EEG 基础初评分**。标识：`eeg-basic-screen/0.1`。

| 分项 | 0–100 分计算方法 | 本例 |
| --- | --- | ---: |
| 信号完整性 | 有限且不处于恒值段的样本数 / 已检查样本数 × 100 | 100.00 |
| 工频干扰 | （1 − 命中通道窗数 / 有效通道窗数）× 100 | 98.22 |
| 高频突发 | （1 − 候选通道秒数 / 有效通道秒数）× 100 | 99.96 |
| **总分** | **三项等权平均，使用未舍入的数值计算** | **99.39** |

这是便于试用和讨论的项目自定指数。它概括三项检测的候选负担，尚未经过专家校准，不代表可用数据百分比，也不直接判断临床或任务适用性。暂不设置“优秀、合格、不合格”等级。

计分规则：

- 三项固定；缺少任一项或未覆盖全部选中通道时不生成总分，保留已有分项。
- 工频对同一通道、同一时间窗的多个频带命中去重；重叠窗不换算为污染秒数。
- 高频使用上游已经合并的每通道候选时长与有效观测时长。不同通道的秒数分别计入。
- ADC 端点、参考组内坏道判定、ECG/EOG/EMG 辅助检查暂不参与此基础分；有结果则补充展示。
- 同一方法配置、版本和检查范围下比较。快速预检只评价所选时段。

高分不能覆盖局部问题：本例 CPz 有 90/117 个工频命中窗，必须在总分旁突出显示。无需等待统一行业评分形成后才提供报告；后续依据代表性样本和专家反馈修订此试行规则。

## 3. 真实样例

文件：`ds004584-sub-001-set.zip`。EEGLAB，63 通道，500 Hz；原记录 281.66 秒，本次检查 0–120 秒。

**摘要：工频候选涉及 9 个通道，高频突发有 2 条候选区间。**

| 检查 | 结果 |
| --- | --- |
| 信号完整性 | 3,780,000 个样本；非有限值 0、恒值 0 |
| 工频 | 131/7,371 个通道窗命中；重点看 CPz（90/117）、PO4（27/117） |
| 高频突发 | FT9：37.00–38.50 秒；CP5：37.00–38.75 秒；候选共 3.25 通道秒 / 有效 7,497 通道秒 |
| 通道描述 | 63 道已计算；参考分组待确认，尚未形成组内坏道结论 |
| 文件标注 | 1 条 boundary；不作为任务事件解释 |

原始检测结果保留；正式接口新增 `report_view`，其中 `score` 保留每个分项的分子、分母、权重及版本，`source_fingerprints` 记录原产物指纹；原任务的 `score` 不被覆盖。此前样稿仍作为设计记录保存。

## 4. 接入顺序

1. 已完成：采用上述结构更新 EEG 选区报告和工作台结果区。
2. 将候选通道、时间与波形复核连接起来。
3. 用代表性 EEG 和专家反馈修订规则，再冻结标准版本。

本样稿只针对头皮 EEG 单个选区。整记录汇总和其他模态按其实际数据口径接入，不直接套用本例分数。

## 5. 方法依据

- 项目文档：[EEG 报告要求](../eeg-report.md)、[检查词条](../eeg-checks.md)、[字段字典](../metadata-fields.md)。
- [PREP 原论文](https://www.frontiersin.org/journals/neuroinformatics/articles/10.3389/fninf.2015.00016/full)：用于说明参考方式与坏道检测的关系。
- [MNE 高频伪迹说明](https://mne.tools/stable/generated/mne.preprocessing.annotate_muscle_zscore.html)：用于说明高频检测的频带、阈值等方法要素；项目实现并非原函数的完全等价复现。

这些来源支持检测方法，不提供本项目的等权总分。评分公式及权重属于明确公开的 v0.1 项目规则。

## 2026-10-31 导出与展示更新

EEG 选区报告已增加结果总表，逐项显示得分、扣分与测量分母。报告和 PDF 复用同一份 `report_view`；三项试行评分不因排版变化而更改。候选图重新读取并核验原始来源，最多展示两条高频候选，或在无高频候选时展示工频候选。

PDF 固定两页：第一页评分与检查结果，第二页问题位置、波形、复核栏和追溯标识。当前导出范围为头皮 EEG 选区报告。批量对比及任意候选点击联动仍见 TODO。

后续实现已覆盖 EEG 整份记录，扩展此前仅选区的展示范围。默认后台分段计算，按实际分母汇总，分数公式与检测阈值保持不变。局部关注、通道分项和逐窗报告同时展示。失败、来源缺口或分项缺失不生成整份总分。
