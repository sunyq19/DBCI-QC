# 质控方法适用规则

项目技术规范 · 版本 applicability/1 · 2026-10-31 · 研究用途

## 1 目的与依据

本文件规定从数据描述到检查计划的判定顺序。字段定义见[字段字典](/standards/fields)，当前已执行的规则和限制见[实施清单](/standards/implementation)。这些为项目规定，不是跨物种统一质量阈值。

## 2 判定顺序

### 2.1 数据对象

首先核对信号对象、记录位置及采集技术。连续电压、已分选单元、功率或包络等派生量应走各自已验证的方法。不能因为文件可打开、单位写为V或含“EEG”字样就执行某路线。

### 2.2 技术前提

每个方法应声明所需字段、允许范围、依赖和缺项动作。检查时应使用当前选流、选道、选区的事实，不借用同数据集其他记录的条件。

| 条件 | 可保留的检查 | 受限操作 |
| --- | --- | --- |
| 单位/标定未核实 | 可可靠解释的数字结构检查 | 绝对电压阈值及依赖标定的方法 |
| 位置或坐标系未知 | 不依赖空间信息的方法 | 要求位置的预测、空间插值 |
| 参考或比较组未知 | 部分逐通道描述 | 要求同参考或跨道可比的方法 |
| 时钟/采样率冲突 | 明确可读对象的结构诊断 | 频率、时长或对齐依赖项，必要时拒绝流 |
| 未提供辅助导联 | 其他适用方法 | 需要EOG/ECG等支持的检测 |
| 通道或时间范围不足 | 满足条件的基础指标 | 不足以估计的方法，不能输出空候选成功 |
| 物种或年龄未知 | 已验证适用范围内的技术检查 | 物种/年龄专属解释与阈值 |
| 处理史不明 | 当前信号的有限描述 | 未处理原始噪声或清洗有效性的结论 |

### 2.3 背景与验证范围

任务、物种、年龄、疾病、动物模型和状态应参与解释及验证分层。背景字段不能单独决定坏道、质量分或清洗动作。使用专属阈值时，应关联适用数据、独立验证和规则版本。

动物ECoG可复用适用的数值计算，但人类临床或头皮判坏阈值不能由模态名称自动继承。基础数学可计算与科学判定有效应分别说明。

## 3 方法声明与计划

每个方法应记录稳定ID、模块、上游项目/入口、版本、执行环境、输入条件、依赖、输出、参数来源及验证证据。Python/MATLAB/Octave执行环境应可追溯；兼容层、第三方重实现和作者原实现不得混称。

计划应区分未选择、条件不足、需要确认、待执行、执行失败与计算完成。实际接口可保留既有状态码，但应明确这些含义；partial不应解释为固定百分比或质量等级。

只有所选方法缺失必要条件时才应要求补充相应信息。未知信息可继续保持未知，不能通过猜测让方法显示可运行。

## 4 可选处理

清洗应由用户明确选择，并满足方法自己的前提。去工频、删道、插值、片段剔除和ASR重建是不同动作，不应合并为含义不明的“修复”。

ASR校准应记录范围、来源、滤波和秩，不能把自动选到的片段当作已确认干净。整记录处理应验证状态连续传递和边界；各窗重新校准不得声称等同于全记录一次校准。

处理结果应保留副本、处理记录及前后对照。强烈信号改变、上游过强提示和未处理尾部应披露；质量指标变好不自动触发覆盖来源或接受结果。

## 5 评价和比较

分项应保持原指标、单位、范围和分母；总分须另有经过验证的评价配置。未评项不计正常，不以方法数量、完成率或清洗变化比例替代质量。

比较原始数据应使用原始报告及一致的检查条件；处理后数据另行比较并列出处理方案，不能把不同方案加工过的结果混称原始质量。
