# M01 数据接入与结构核验

模块说明 · 版本 neuropixels-voltage/2 · 2026-10-30

## 1 输入

同一SpikeGLX AP/LF流的.bin和.meta，或一个NWB连续ElectricalSeries；均须明确Neuropixels设备证据。

## 2 处理

按格式核对采样率、源通道、单位、时钟与文件指纹。SpikeGLX核对长度/增益/firstSample并分开同步字；NWB核对ElectricalSeries、电极表行、转换字段和设备证据。

## 3 输出

可追溯连续电压流、原始通道身份、采样时钟、单位、处理声明和读取限制。

## 4 边界

不能将任意裸.bin按Neuropixels解码。读取器识别型号0、21、24；真实数据核验覆盖NP1，NP2仅有合成读取测试；NIDQ、压缩.cbin、NWB-Zarr和其他尚未接入格式不在本版范围；Units不是连续通道。

## 5 来源与复核

本项目独立适配；计算约定与科学判定分开。来源文件、配置和模块版本须随报告保留。
