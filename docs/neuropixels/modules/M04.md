# M04 流内频谱观察

模块说明 · 版本 neuropixels-voltage/2 · 2026-10-30

## 1 输入

被选Neuropixels电压、原生采样率、处理声明和neuropixels频谱设置。

## 2 处理

以Welch生成描述性PSD；Hann窗、50%重叠、逐段去均值。AP默认0.1秒窗，LF/LFP或其他已确认Neuropixels电压默认1秒窗，记录实际频率分辨率。

## 3 输出

PSD（V²/Hz）、实际窗长和可测50/60Hz附近窄带观察。

## 4 边界

短AP窗的分辨率可能不足以分辨邻近谱峰。采集滤波会改变可解释频段；工频观察不是噪声判定，神经放电高频不作为肌电扣分。

## 5 来源与复核

本项目独立适配；计算约定与科学判定分开。来源文件、配置和模块版本须随报告保留。
