# M09 报告与复核

模块说明 · 版本 neuropixels-voltage/2 · 2026-10-30

## 1 输入

冻结计划、探针/流来源、模块输出和环境版本。

## 2 处理

生成连续电压检查报告并保留人工复核链路；显示被选流、来源处理史与未评范围，不把来源已处理LFP称作原始未处理数据。

## 3 输出

HTML/JSON报告、源样本位置、参数与未评说明。

## 4 边界

报告不代表已经执行分选或unit质控。后续unit报告必须引用分选器版本、配置、原始记录、时间映射和独立指标证据。

## 5 来源与复核

本项目独立适配；计算约定与科学判定分开。来源文件、配置和模块版本须随报告保留。
