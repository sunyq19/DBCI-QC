# M08 分项评价与汇总

模块说明 · 版本 neuropixels-voltage/2 · 2026-11-08

## 1 输入

本流实际执行的描述性结果和覆盖信息。

## 2 处理

汇总观察量、未评、失败及证据来源；保留每个流独立的执行范围。

## 3 输出

连续电压分项和project_score，包含配置权重、有效权重及合并证据；旧score.value字段保持null。

## 4 边界

不提供spike sorting质量分、unit产量或可用神经元结论。AP和LF是不同数据流，不算两个独立生物样本。

## 5 来源与复核

本项目独立适配；计算约定与科学判定分开。来源文件、配置和模块版本须随报告保留。

NP09 · [Neuropixels检查规则](/standards/neuropixels-checks)
