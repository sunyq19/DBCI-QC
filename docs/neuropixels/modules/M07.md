# M07 来源事件核对

模块说明 · 版本 neuropixels-voltage/2 · 2026-10-30

## 1 输入

可选登记事件表与被选流的时间基准。

## 2 处理

对已登记或明确映射的事件作字段、范围和样本映射核对；NWB使用被选流的时间原点，不借用其他流时钟。

## 3 输出

时间范围、原始样本及事件来源。

## 4 边界

本版不从同步字自动提取边沿，不作跨探针或AP/LF时钟校准。同名时间戳或同步道存在不证明设备已对齐。

## 5 来源与复核

本项目独立适配；计算约定与科学判定分开。来源文件、配置和模块版本须随报告保留。
