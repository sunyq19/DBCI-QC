# M02 数据画像与检查计划

模块说明 · 版本 neuropixels-voltage/2 · 2026-10-31 · 文档修订 2

元数据设计见[字段字典](/standards/fields)与[方法适用规则](/standards/applicability)。完整字典尚未接入表单与存储，当前能力见[实现范围](/standards/implementation)。现有背景选项不代表已经具备按物种年龄或疾病调整阈值的依据。

## 1 输入

确认后的Neuropixels连续电压流、分析通道、流类型、处理史和范围。

## 2 处理

一次计划选择一个SpikeGLX AP/LF或NWB连续ElectricalSeries，冻结对象路径、电极映射和时钟；只对模拟神经通道计算电压指标，保留同步道但排除其参与。冻结neuropixels-voltage/2参数和来源。

## 3 输出

流专属计划、源通道/样本映射和方法适用性。

## 4 边界

内部modality为extracellular；Neuropixels是记录系统标签。不同流不能强行拼接为同一采样时钟，probe/shank/site信息存在也不代表组织位置已经核验。

## 5 来源与复核

本项目独立适配；计算约定与科学判定分开。来源文件、配置和模块版本须随报告保留。
