# M06 伪迹方法边界

模块说明 · 版本 neuropixels-voltage/2 · 2026-10-30

## 1 输入

未来探针专属噪声、漂移、饱和或运动证据。

## 2 处理

本版本未接入，不调用EEG/ECoG伪迹算法替代；不执行去条纹、公共参考或运动校正。

## 3 输出

明确未评原因。

## 4 边界

探针漂移需要位置/时间和适当检测方法。完整性统计不能替代漂移估计或spike sorting准确率。

## 5 来源与复核

本项目独立适配；计算约定与科学判定分开。来源文件、配置和模块版本须随报告保留。
