# M03 基础信号完整性

模块说明 · 版本 neuropixels-voltage/2 · 2026-10-30

## 1 输入

标定电压、源样本及连续段。

## 2 处理

扫描非有限值和相邻精确恒值连续段；定位证据始终使用原始样本。

## 3 输出

逐通道计数、有限详细位置与覆盖。每窗详细位置上限10,000，截断时保留总数、省略数并标记partial。

## 4 边界

整数ADC量化会产生精确相等样本，不能把每次相等都视为丢包或坏道。本版不以恒值计数诊断采集故障，也不自动修复数据。

## 5 来源与复核

本项目独立适配；计算约定与科学判定分开。来源文件、配置和模块版本须随报告保留。
