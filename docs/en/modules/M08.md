# M08 Evidence summary and comparability

Module guide · Version 0.6 · Implementation 1.0.0rc3.dev16

M08 summarizes executed evidence and verifies source consistency. EEG additionally provides an independently versioned project trial index defined in [EEG scoring rules](/en/standards/eeg-scoring).

[Specification 5.8](/en/standards#58-m08-evidence-summary-and-aggregation) · [M02](/en/standards/modules/M02) · [M09](/en/standards/modules/M09)

## 1 Purpose and scope

Keep measurements, coverage, candidates and reasons separate from execution progress. The EEG score covers integrity, line noise and high-frequency bursts only. It does not assert that other checks passed and is not applied to ECoG, sEEG or Neuropixels.

## 2 Inputs and prerequisites

Inputs are frozen plans, channel selections, configurations, actual artifacts and M01 source fingerprints. Unselected, inapplicable and failed checks remain distinct. EEG scoring requires valid native numerators and denominators for all selected channels and all three dimensions. Whole-record totals also require every window, no source gaps and verified source integrity.

## 3 Processing

### 3.1 Evidence and source summary

Preserve module identity, state, reason and raw summaries. Recheck the main file and required companions by SHA-256. Changes fail M08; absent fingerprints are not a pass.

### 3.2 EEG project trial score

The independent core is `src/ephys_qc/project_scoring.py`. The report adapter calls it using detector evidence; it does not change detectors, signals or frozen M08 output.

- Compute per-channel candidate fractions using each method's valid denominator.
- Component = `100 × (1 − pooled candidate amount / assessed amount)`.
- Total = `Σ(component × weight) / Σweight`. Unavailable checks have zero effective weight; remaining valid checks are renormalized; local candidates remain visible.
- Whole records pool native counts within each channel before scoring, never average window scores.

See [scoring rules](/en/standards/eeg-scoring) for equations, scope, examples and limitations. There are no disease weights, dataset rank normalization or universal acceptance cutoffs.

### 3.3 Comparability

Match score version, channel selection, reference, method settings, bandwidth, processing history and scope. Shared disease or format is insufficient. Removing a channel creates a new configuration.

## 4 Outputs

| Location | Content | Meaning |
| --- | --- | --- |
| M08_assessment.json / score.value | null | No calibrated generic cross-modality score |
| module_assessments | States, measurements and reasons | Execution progress is not quality |
| source_unchanged | true or null; conflicts fail | File-byte consistency only |
| report_view.score | EEG v0.2 score, components, denominators and version | Project trial; missing evidence withholds total |
| report_view.local_quality | Channel fractions and lowest component | Localizes findings |
| report_view.window_scores | Window scores | Not averaged into the recording score |
| report_view.score_revision | Old/current versions and old value | Historical evidence preserved |

## 5 Configuration and traceability

Project weights are frozen with the plan; zero excludes a component, and unavailable evidence is excluded with a reason, and valid checks are renormalized. Detector settings come from the frozen run. Formula changes require versioned documentation and verification.

## 6 Validation and limitations

Arithmetic contracts cover clean/extreme cases, nonincreasing scores with increasing detected burden, concentration, missingness, unequal windows and immutable evidence. Signal-injection checks are distinct from formula tests.

The index does not grade post-threshold amplitude severity or sum every independent risk. Detector error rates, expert agreement and application relevance need separate validation. No calibrated acceptance grade is assigned.
