# M03 Signal integrity

Module guide · Applicable implementation: Workbench 1.0.0rc2 · Document version: 0.2

This module locates non-finite samples, exact constant segments and plateaus at file calibration endpoints. Optional checks assess adjacent-sample changes and fixed-segment amplitudes. Outputs are candidates for review; channels and intervals are not automatically removed.

[Related specification](/en/standards#53-m03-signal-integrity) · [Prerequisite: M02 Data characterization and check plan](/en/standards/modules/M02) · [Downstream: M06 Physiological artifact indicators](/en/standards/modules/M06)

## 1 Purpose and scope

The module applies to voltage-calibrated scalp EEG selections. It identifies missing values, constant signals and amplitude indicators that may affect numerical analysis. Exact constancy differs from physiological signals with low but varying amplitude. A plateau at a file range endpoint does not, by itself, establish hardware saturation.

M03 can be selected independently. Selecting M06 automatically adds M03 so that integrity intervals can protect the high-frequency checks.

## 2 Inputs and prerequisites

M03 depends on M02. Inputs are calibrated EEG voltages, native sampling rate, original channel indices, starting sample, and the digital and physical ranges declared in the file. Auxiliary ECG/EOG/EMG channels are not EEG assessment targets in this module.

Each method checks its own minimum duration and sample count. If an extension is inapplicable, its reason is retained. Completion of the basic integrity check does not imply that an extension ran.

## 3 Processing and methods

### 3.1 Missing values, constant segments and endpoint plateaus — available

BrainElecQC scans consecutive non-finite samples and intervals of exactly equal adjacent finite values. The constancy tolerance is zero. A constant segment requires at least `max(2, ceil(0.1 × fs))` samples; this minimum does not apply to non-finite intervals.

Detected constant segments are classified first by proximity to file calibration endpoints, then by proximity to zero, with other constant segments retained separately. Near-zero tolerance accounts for voltage and quantization step; endpoint tolerance accounts for quantization step and numerical precision. The near-zero threshold classifies constant segments and is not a quality limit for low-amplitude EEG.

### 3.2 MNE adjacent-sample changes / flat segments — optional, available

The adapter calls `mne.preprocessing.annotate_amplitude` and evaluates the absolute difference between adjacent samples. Flat segments use differences no greater than the threshold; peaks use differences no smaller than the threshold. This is not a fixed-window peak-to-peak check.

The bad-segment percentage controls routing to whole-channel candidates or time annotations. A whole-channel candidate may have no abnormal start and stop interval; time localization must not be invented.

### 3.3 autoreject global threshold estimation — optional, available

The adapter calls `autoreject.get_rejection_threshold`. It divides the current continuous selection into fixed, non-overlapping segments, estimates a global peak-to-peak threshold and describes segments exceeding that threshold. These segments are not trials from the original experiment.

The result remains exploratory: threshold fitting and description use the same selection, and internal cross-validation is not independent-data validation. The extension does not run segment rejection or interpolation.

### 3.4 local AutoReject trial quality estimation — planned

The catalog retains this method and its sources, but it is not executed. Integration requires enough trials, reliable channel positions and an appropriate validation design. The available global-threshold estimator must not be presented as full local AutoReject.

## 4 Outputs and interpretation

The basic evidence file is `M03_continuity.json`. Optional extensions retain their actual execution results separately.

| Output or measure | Units and localization | Interpretation |
| --- | --- | --- |
| `candidates`, `kinds` | Original channel index, seconds, half-open sample interval | Distinguishes non-finite samples, endpoint plateaus, near-zero constants and other constants |
| Constant or endpoint value | V; may be displayed in µV | Interpret with the file range and quantization step; does not directly establish hardware damage |
| MNE amplitude candidates | Channel candidates or time candidates | These are different output types; channel counts are not interval counts |
| Global threshold | V | Peak-to-peak threshold estimated from this selection, not a universal clinical threshold |
| Fixed-segment candidates | Segment index and original time | Identifies above-threshold fixed segments, not failed experimental trials |
| Automatic exclusion records / count | `automatic_exclusions` is an empty list in detailed output; module summary count is 0 | Original channels and signals are not automatically deleted or altered |

Zero candidates means only that these definitions produced no candidates under the current conditions. It does not establish absence of disconnections, artifacts or other integrity problems. General repeated-data-block detection is not implemented.

## 5 Configuration

These are current implementation settings, not industry acceptance limits. Reports must retain the values actually used.

| Method | Parameter | Current default and source |
| --- | --- | --- |
| Basic constancy | `min_constant_seconds` | 0.1 s, BrainElecQC default; at least 2 samples |
| Constant classification | `near_zero_volts` | `1e-7 V`, or 0.1 µV; also accounts for half a quantization step |
| Endpoint classification | `endpoint_tolerance_lsb` | 0.25 quantization steps, with floating-point precision accounted for |
| MNE amplitude | `flat_volts`, `peak_volts` | 0 V, disabled; passed to upstream `flat`, `peak` and applied to adjacent differences |
| MNE amplitude | `min_duration_seconds` | 0.1 s, a platform override passed to upstream `min_duration`; differs from the upstream 0.005 s default |
| MNE amplitude | `bad_percent` | 5%; upstream channel/time-annotation routing parameter |
| Global threshold | Fixed segment, cross-validation | 2 s, 5 folds; adapter defaults |
| Global threshold | Random seed, decimation factor | 0, 1; no decimation |

The global-threshold adapter accepts 1–256 EEG channels, 1–10 s segments and 2–10 cross-validation folds. It requires at least `max(20, 4 × folds)` complete segments, or at least 40 s with defaults. Segment length must map to an integer number of native samples; an incomplete tail is not assessed. MNE amplitude checks require at least two samples and enough adjacent differences to form the specified interval duration.

## 6 Validation and limitations

Basic checks cover known constants, non-finite values, range endpoints and original time coordinates. Optional extensions have execution evidence on real public recordings. This supports implementation and interface behavior, not natural-artifact accuracy or clinical sensitivity.

Global thresholds depend on the window, channel composition and physiological amplitude distribution; pathological waveforms may also exceed them. M03 does not diagnose causes, use clinical or source bad-channel labels as detector inputs, or automatically repair data based on candidates.
