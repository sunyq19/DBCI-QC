# M04 Spectrum and line-frequency observations

Module documentation · Version ecog-basic/1 · 2026-10-30

## 1 Inputs

Voltage samples, sample rate and spectral configuration.

## 2 Processing

Estimate Welch PSD with SciPy and describe power and peak location near configured frequencies.

## 3 Outputs

Frequencies, density in V²/Hz, measurable bands and unavailable reasons.

## 4 Boundaries

No FOOOF, alpha score, Thomson decision or muscle threshold is applied. A peak does not establish interference origin.

## 5 Sources and review

Project implementations share existing intake and reporting infrastructure. Implementation and successful execution do not establish detection accuracy.

[SciPy Welch](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.welch.html)
