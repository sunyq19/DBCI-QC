# M09 Reporting and review

Module documentation · Version ecog-basic/1 · 2026-10-30

## 1 Inputs

Results, original waveform, versions and provenance.

## 2 Processing

Generate HTML and JSON evidence; save workbench review decisions separately.

## 3 Outputs

Report, waveform and versioned review entry.

## 4 Boundaries

Review does not overwrite algorithm evidence. The report is not a clinical diagnosis.

## 5 Sources and review

Project implementations share existing intake and reporting infrastructure. Implementation and successful execution do not establish detection accuracy.
