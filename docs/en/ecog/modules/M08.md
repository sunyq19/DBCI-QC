# M08 Evidence summary and aggregation

Module documentation · Version ecog-basic/1 · 2026-10-30

## 1 Inputs

Actual module results and unavailable states.

## 2 Processing

Aggregate execution coverage, observations, failures and unavailable reasons.

## 3 Outputs

Component summary; default total is null.

## 4 Boundaries

Completion is not quality. Different references, windows or processing histories are not directly comparable.

## 5 Sources and review

Project implementations share existing intake and reporting infrastructure. Implementation and successful execution do not establish detection accuracy.

Original MNE flatness/adjacent-change detection exposes contact-candidate and merged-interval fractions as optional score outputs with default weight 0. Explicit weights use the project scoring contract, including unavailable-item handling. These two fractions are not additive contaminated durations.
