# M07 Source event checks

Module documentation · Version ecog-basic/1 · 2026-10-30

## 1 Inputs

Registered events with source hashes.

## 2 Processing

Map source events onto the original clock and current selection.

## 3 Outputs

Events, coverage and provenance.

## 4 Boundaries

Point events remain points. Do not infer clinical intervals or artifact labels from unverified markers.

## 5 Sources and review

Project implementations share existing intake and reporting infrastructure. Implementation and successful execution do not establish detection accuracy.
