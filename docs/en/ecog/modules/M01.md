# M01 Data intake and structure checks

Module documentation · Version ecog-basic/1 · 2026-10-30

## 1 Inputs

Source files, companion files and calibration.

## 2 Processing

Use registered readers and freeze source hashes, native streams and continuous segments.

## 3 Outputs

Structure, source manifest, voltage calibration and native clock.

## 4 Boundaries

A default EEG reader type in BrainVision does not establish scalp placement. ECoG requires explicit source or user confirmation.

## 5 Sources and review

Project implementations share existing intake and reporting infrastructure. Implementation and successful execution do not establish detection accuracy.
