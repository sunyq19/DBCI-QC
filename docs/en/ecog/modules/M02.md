# M02 Data characterization and check plan

Module documentation · Version ecog-basic/1 · 2026-10-31 · Document revision 2

Metadata design: [field dictionary](/standards/fields) and [method applicability](/standards/applicability). The complete dictionary is not yet implemented in intake/storage; see [current scope](/standards/implementation). Existing context fields do not imply species-specific age or disease thresholds.

## 1 Inputs

Confirmed modality, source indices, voltage units and time selection.

## 2 Processing

Read the selected native samples without resampling or rereferencing; preserve channel identity.

## 3 Outputs

Frozen selection, exact sample range, data hash and method eligibility.

## 4 Boundaries

The legacy eeg_indices field denotes ECoG analysis contacts in this route.

## 5 Sources and review

Project implementations share existing intake and reporting infrastructure. Implementation and successful execution do not establish detection accuracy.
