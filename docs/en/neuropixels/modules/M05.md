# M05 Per-channel statistics

Module guide · Version neuropixels-voltage/2 · 2026-10-30

## 1 Input

Selected analog neural channels in calibrated volts.

## 2 Processing

Compute finite count, mean, standard deviation, RMS and peak-to-peak. Never interpret digital sync words as voltages.

## 3 Output

Per-channel observations, denominators and units.

## 4 Limits

RMS includes neural signal and is not an independent noise floor. No unit SNR, ISI violations, drift or confirmed bad-channel labels are computed. A source channel is not a sorted unit.

## 5 Sources and review

Project implementation separates numerical conventions from scientific interpretation. Preserve source files, settings and module versions with every report.

[Route specification](/en/standards/neuropixels)

## 6 Optional SpikeInterface screening

Explicitly select SpikeInterface 0.104.2 std/mad. AP only, at least eight channels in each file-declared shank. Convert V to µV, high-pass at the default 300 Hz and sample with a fixed seed; the default threshold is five times the median dispersion. Retain good/noise candidates, source-channel mapping and parameters. Good means below this threshold, not channel approval. IBL coherence+psd, dead/out, LF and sorted-unit quality are not integrated.
