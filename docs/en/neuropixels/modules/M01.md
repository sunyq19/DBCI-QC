# M01 Data intake and structure checks

Module guide · Version neuropixels-voltage/2 · 2026-10-30

## 1 Input

Paired SpikeGLX .bin/.meta for one AP/LF stream, or one NWB continuous ElectricalSeries; explicit Neuropixels device evidence is required.

## 2 Processing

Check native rate, source channels, units, clock and file fingerprints. For SpikeGLX, check length/gain/firstSample and separate sync words. For NWB, check ElectricalSeries, electrode rows, conversion fields and device evidence.

## 3 Output

Traceable continuous voltage, source identities, sample clock, units, processing declarations and reader limits.

## 4 Limits

An arbitrary bare .bin is not Neuropixels input. The reader accepts declared types 0, 21 and 24. Real-data checks cover NP1; NP2 currently has synthetic decoding tests only. NIDQ, compressed .cbin, NWB-Zarr and other unsupported formats are outside this version. Units are not continuous channels.

## 5 Sources and review

Project implementation separates numerical conventions from scientific interpretation. Preserve source files, settings and module versions with every report.
