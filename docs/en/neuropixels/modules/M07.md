# M07 Source event checks

Module guide · Version neuropixels-voltage/2 · 2026-10-30

## 1 Input

Optional registered events and the selected stream clock.

## 2 Processing

Check registered or explicitly mapped event fields, range and sample mapping. NWB uses the selected stream origin, not another series clock.

## 3 Output

Event scope, source samples and provenance.

## 4 Limits

No automatic sync-edge extraction or cross-probe/AP/LF clock calibration. Similar timestamps or the presence of a sync channel do not establish alignment.

## 5 Sources and review

Project implementation separates numerical conventions from scientific interpretation. Preserve source files, settings and module versions with every report.
