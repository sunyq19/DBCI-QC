# M09 Reporting and review

Module guide · Version neuropixels-voltage/2 · 2026-11-08

## 1 Input

Frozen plan, probe/stream provenance, module evidence and environment versions.

## 2 Processing

Produce a continuous-voltage report with independent review, the selected stream, source processing and unassessed scope. Do not describe source-processed LFP as unprocessed acquisition data.

## 3 Output

HTML/JSON report, source sample locations, settings and limitations.

## 4 Limits

The report does not imply spike sorting or unit QC. Future unit reports must reference sorter version, settings, raw data, clock mapping and independent metric evidence.

## 5 Sources and review

Project implementation separates numerical conventions from scientific interpretation. Preserve source files, settings and module versions with every report.
