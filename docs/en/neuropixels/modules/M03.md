# M03 Basic signal integrity

Module guide · Version neuropixels-voltage/2 · 2026-11-08

## 1 Input

Calibrated voltages, source samples and continuous segments.

## 2 Processing

Scan nonfinite values and exactly equal adjacent runs; locate all evidence in source sample coordinates.

## 3 Output

Per-channel counts, bounded detailed locations and coverage. At most 10,000 detailed entries per window; record omitted counts and partial status.

## 4 Limits

ADC quantization causes equal adjacent samples. Equality does not establish packet loss or bad channels. No fault diagnosis or automatic repair is inferred from these counts.

## 5 Sources and review

Project implementation separates numerical conventions from scientific interpretation. Preserve source files, settings and module versions with every report.

## Current rule mapping

NP03 / NP04 · [Neuropixels check rules](/en/standards/neuropixels-checks)

Record the longest exact run within each processing window and channels constant throughout the window. Do not infer hardware loss from quantized equality. These summaries were added in dev38; missing historical fields remain unassessed.

The initial [scoring rules](/en/standards/neuropixels-scoring) preserve numerical validity and grouped channel-state evidence, effective weights and exclusion reasons; old runs are not rescored.
