# M08 Evidence summary and aggregation

Module guide · Version neuropixels-voltage/2 · 2026-11-08

## 1 Input

Executed descriptive results and coverage for this stream.

## 2 Processing

Summarize observations, not-assessed states, failures and sources; retain stream-specific scope.

## 3 Output

Continuous-voltage components and project_score with configured/effective weights. The legacy score.value field remains null.

## 4 Limits

No sorting-quality score, unit yield or usable-neuron conclusion. AP and LF streams are not two independent biological samples.

## 5 Sources and review

Project implementation separates numerical conventions from scientific interpretation. Preserve source files, settings and module versions with every report.
