# M02 Data characterization and check plan

Module guide · Version neuropixels-voltage/2 · 2026-10-31 · Document revision 2

Metadata design: [field dictionary](/standards/fields) and [method applicability](/standards/applicability). The complete dictionary is not yet implemented in intake/storage; see [current scope](/standards/implementation). Existing context fields do not imply species-specific age or disease thresholds.

## 1 Input

Confirmed Neuropixels continuous voltage, selected channels, stream type, processing history and range.

## 2 Processing

Select one SpikeGLX AP/LF stream or one NWB continuous ElectricalSeries per plan; freeze object path, electrode mapping and clock. Compute voltage metrics only on analog neural channels; retain but exclude sync words. Freeze neuropixels-voltage/2 parameters and sources.

## 3 Output

Stream-specific plan, source-channel/sample mapping and applicability.

## 4 Limits

The internal modality is extracellular; Neuropixels is a recording-system label. Do not join different streams into one sampling clock. Probe geometry does not establish verified tissue location.

## 5 Sources and review

Project implementation separates numerical conventions from scientific interpretation. Preserve source files, settings and module versions with every report.
