# M04 Within-stream spectrum observations

Module guide · Version neuropixels-voltage/2 · 2026-10-30

## 1 Input

Selected Neuropixels voltage, native sample rate, processing declarations and Neuropixels spectrum settings.

## 2 Processing

Use Welch with a Hann window, 50% overlap and per-segment mean removal. Defaults: 0.1-second AP windows; 1-second LF/LFP or other confirmed Neuropixels voltage windows. Record actual resolution.

## 3 Output

PSD in V²/Hz, effective window and measurable narrow-band observations near 50/60 Hz.

## 4 Limits

Short AP windows may not resolve nearby peaks. Acquisition filtering limits interpretation. Line-frequency observations are not noise verdicts; neural high-frequency activity is not a muscle-artifact deduction.

## 5 Sources and review

Project implementation separates numerical conventions from scientific interpretation. Preserve source files, settings and module versions with every report.
