# M06 Artifact method scope

Module guide · Version neuropixels-voltage/2 · 2026-10-30

## 1 Input

Future validated probe-specific noise, drift, saturation or motion evidence.

## 2 Processing

Not implemented in this version; do not substitute EEG/ECoG artifact methods. No destriping, common-reference transformation or motion correction.

## 3 Output

An explicit not-assessed reason.

## 4 Limits

Drift requires suitable spatial/temporal evidence and a validated method. Integrity statistics do not establish drift or spike-sorting accuracy.

## 5 Sources and review

Project implementation separates numerical conventions from scientific interpretation. Preserve source files, settings and module versions with every report.
