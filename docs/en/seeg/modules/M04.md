# M04 Spectrum and line-frequency observations

Module guide · Version seeg-basic/1 · 2026-10-30

## 1 Input

Confirmed sEEG voltage, sample rate and sEEG spectrum configuration.

## 2 Processing

Use SciPy Welch with a Hann window, 50% overlap and per-segment mean removal. Default window: 4 seconds. Describe measurable bands around 50/60 Hz.

## 3 Output

PSD in V²/Hz, frequency resolution, effective window length and per-contact narrow-band observations.

## 4 Limits

Band half-width is max(1 Hz, frequency resolution). No alpha scoring or scalp muscle threshold. High-frequency or pathological activity is not automatically an artifact, and a peak does not establish its cause.

## 5 Sources and review

Project implementation separates numerical conventions from scientific interpretation. Preserve source files, settings and module versions with every report.
