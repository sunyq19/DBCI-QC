# M05 Per-contact statistics

Module guide · Version seeg-basic/1 · 2026-10-30

## 1 Input

Calibrated voltages of selected source contacts.

## 2 Processing

Compute finite count, mean, standard deviation, RMS and peak-to-peak. Retain source identity and do not automatically exclude source bad labels.

## 3 Output

Contact statistics, finite-sample denominators and missing-data reasons.

## 4 Limits

RMS is not an independent noise floor. No scalp PREP, LOF, bridging or inferred cross-shaft adjacency. Different references and anatomical locations are not directly ranked against one baseline.

## 5 Sources and review

Project implementation separates numerical conventions from scientific interpretation. Preserve source files, settings and module versions with every report.
