# M02 Data characterization and check plan

Module guide · Version seeg-basic/1 · 2026-10-31 · Document revision 2

Metadata design: [field dictionary](/standards/fields) and [method applicability](/standards/applicability). The complete dictionary is not yet implemented in intake/storage; see [current scope](/standards/implementation). Existing context fields do not imply species-specific age or disease thresholds.

## 1 Input

Confirmed sEEG source channels, time range, context and available events.

## 2 Processing

Freeze the analysis group, native sample range and seeg-basic/1 settings; retain the reference state stored in the source.

## 3 Output

Executable plan, method applicability, and mapping between source indices and file-relative seconds.

## 4 Limits

The legacy eeg_indices field denotes sEEG contacts here. Shaft, tissue and bipolar pairing remain unknown without evidence. Do not infer them from names or automatically re-reference.

## 5 Sources and review

Project implementation separates numerical conventions from scientific interpretation. Preserve source files, settings and module versions with every report.
