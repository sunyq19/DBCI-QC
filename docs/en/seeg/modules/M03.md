# M03 Basic signal integrity

Module guide · Version seeg-basic/1 · 2026-10-30

## 1 Input

Calibrated source voltages and source sample indices.

## 2 Processing

Scan nonfinite values and consecutive runs of at least two exactly equal samples; retain full counts and a bounded detailed list.

## 3 Output

Per-contact counts and source sample intervals. Over 10,000 detailed entries per window, report omitted counts and partial status.

## 4 Limits

Quantization can produce equal samples; this is not a bad-contact verdict. A file can start at a nonzero acquisition sample. An omitted location is not evidence of normality.

## 5 Sources and review

Project implementation separates numerical conventions from scientific interpretation. Preserve source files, settings and module versions with every report.
