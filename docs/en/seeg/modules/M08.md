# M08 Evidence summary and aggregation

Module guide · Version seeg-basic/1 · 2026-10-30

## 1 Input

Observations, coverage, errors and not-assessed states from executed modules.

## 2 Processing

Summarize actual scope and itemized evidence; distinguish completed, partial, skipped and failed.

## 3 Output

Traceable component results; score.value remains null.

## 4 Limits

Completion is not quality. No unified score across patients, references or anatomy has been calibrated. Epilepsy-related activity is not itself a deduction.

## 5 Sources and review

Project implementation separates numerical conventions from scientific interpretation. Preserve source files, settings and module versions with every report.
