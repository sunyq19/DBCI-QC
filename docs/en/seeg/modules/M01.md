# M01 Data intake and structure checks

Module guide · Version seeg-basic/1 · 2026-10-30

## 1 Input

Source files, reader, explicit sEEG type and calibration evidence.

## 2 Processing

Check fingerprints, channel identity, native sampling streams, continuous segments and units. Distinguish file declarations, companion evidence and user confirmation.

## 3 Output

Structure inventory, source fingerprints, unit and clock evidence, and missing fields.

## 4 Limits

A file extension or a default EEG reader type does not establish electrode anatomy. Unknown units cannot be treated as calibrated voltage.

## 5 Sources and review

Project implementation separates numerical conventions from scientific interpretation. Preserve source files, settings and module versions with every report.
