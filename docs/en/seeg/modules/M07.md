# M07 Source event checks

Module guide · Version seeg-basic/1 · 2026-10-30

## 1 Input

Registered event table, file-relative times and original sample origin.

## 2 Processing

Check fields, valid times and overlap; map events to the selected range and original samples while preserving source categories and durations.

## 3 Output

Selected events, time mapping, source hashes and timing issues.

## 4 Limits

Task and seizure events are not artifact ground truth. Point events are not joined into intervals. Clock mapping does not establish hardware synchronization; unlabelled does not mean normal.

## 5 Sources and review

Project implementation separates numerical conventions from scientific interpretation. Preserve source files, settings and module versions with every report.
