# M09 Reporting and review

Module guide · Version seeg-basic/1 · 2026-10-30

## 1 Input

Frozen input and plan, evidence, software versions and provenance.

## 2 Processing

Write HTML/JSON and evidence artifacts. Store workbench review decisions independently with versions.

## 3 Output

Reports linking to the task and specifications, with units, parameters, source indices and limitations.

## 4 Limits

Human review does not overwrite automatic evidence. This technical report does not replace clinical diagnosis or anatomical verification.

## 5 Sources and review

Project implementation separates numerical conventions from scientific interpretation. Preserve source files, settings and module versions with every report.
