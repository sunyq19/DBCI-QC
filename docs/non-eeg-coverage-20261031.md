- [SEEG Resting State Recording，ds005670 v1.0.0](https://openneuro.org/datasets/ds005670/versions/1.0.0)：两位癫痫患者静息记录，固定 Git 版本 `ff15e6a59c2489532fa5ba2b02f3cb2f7421db59`，CC0。完整 EDF 与源 Git-annex SHA-256 核对一致。
- [HUP iEEG Epilepsy Dataset，ds004100 v1.1.3](https://openneuro.org/datasets/ds004100/versions/1.1.3)：固定 Git 版本 `da07f99bcd7a801f86191eceb2d35b0520c55d1a`，CC0。完整 EDF 与源 Git-annex MD5 核对一致，另保存本地 SHA-256。两份文件的通道表将辅助或头皮名称也归入植入模态；本次人工结合电极表，限定为具有有限定位值的植入触点。这是本轮保守选区，不是“缺坐标就排除”的通用质控规则；未使用 `bad` 标签筛选信号，也未验证解剖定位精度。
- [Longitudinal Multitask Wireless ECoG，ds006890 v1.0.0](https://openneuro.org/datasets/ds006890/versions/1.0.0)：固定 Git 版本 `c97148a9c638c707e0b951e7a4dcb5c67868d7fd`。按通道表精确匹配 32 个 ECOG 通道，排除触发及辅助通道；完整文件与源 SHA-256 一致。`dataset_description.json` 声明 CC0，`README.md` 声明 CC BY 4.0，存在来源许可矛盾，两份原文均已保留。动物信号仅执行描述性检查，未采用人类临床阈值。
- [Paulk 等人类 Neuropixels 数据，Zenodo 5899237 v1](https://zenodo.org/records/5899237)：CC0-1.0。Pt01 为全身麻醉下右背外侧前额叶记录，Pt02 为清醒并接受监测麻醉的左背外侧前额叶记录，均来自运动障碍 DBS 手术。原始 META 及 README 与官方 MD5 核对；片段下载核对 HTTP 206、精确 Content-Range、完整采样帧和派生 SHA-256。未使用经过运动对齐的 `aligned` 文件。

源侧车、下载版本、许可声明、选道依据及摘要均放在各样例的 `来源.json`。本轮无需修改算法即可运行的前提是**先依据来源明确模态和通道**，不能表述为“任意上传后完全自动正确识别”。

## 3. 暴露的处理边界

### 3.1 EDF+D 尚不支持

两份 sEEG 原件都在 EDF 头中声明 `EDF+D`。当前读取入口返回 HTTP 400，提示尚不支持不连续 EDF+D。没有将头标志改成 EDF+C，也没有重建或压平时间轴。

该失败定位于读取器，不能据此认为 sEEG 质控算法失效或数据损坏。若扩展读取器，需要保留并核验 TAL 时间信息、连续段、间隙及原样本对应关系。本轮没有对这两份文件是否实际存在记录间隙作进一步结论。

### 3.2 通道与侧车语义仍需人工核对

EDF 本身没有足够可靠的解剖模态信息。当前工作台要求明确确认，未自动整合这些 BIDS 侧车。

HUP060 和 HUP064 的源通道角色存在歧义，不能把文件中所有电压通道统一视作一种植入模态。monkeyb 的侧车计数合计为 49，文件与通道表为 50；侧车时长为 195.047 秒，EDF 存储时长为 196 秒。报告覆盖的是文件存储范围，不能把末端补齐时间当成额外实验时长。

monkeyb 的 `Misc_InterpMask` 在源通道表中明确表示 `1=已插值、0=原始`。独立读取该通道得到 196,000 个采样点，其中 1,098 个标记为 1（1000 Hz，共 1.098 秒）。当前流程排除了该辅助通道，却没有将其语义引入报告；因此基础波形统计并不包含这项来源质量信息。该计数是源标记复述，不是独立伪迹真值。

### 3.3 连续性候选位置明细过多

现有 M03 将相邻两个完全相等的有限数值列为候选。量化数据中这种现象很常见；它不等价于已确认的长平线或坏道。每窗最多保存 10,000 个候选的位置，所有样本和计数仍被扫描、汇总。

| 样例 | 已观察候选区间数 | 未保存位置明细的区间数 |
|---|---:|---:|
| HUP060 | 198,641 | 161,487 |
| HUP064 | 636,590 | 606,590 |
| monkeyb | 20,549 | 3,186 |
| Pt01 LF | 2,655,213 | 2,645,213 |
| Pt02 AP | 3,719,197 | 3,699,197 |

计数按本次分析窗口相加，不表示跨窗合并后的独立事件数。候选未经过专家质量判定，不能据此估计检测假阳性率。当前结果支持优先改进候选汇总与展示，再决定是否引入经过验证的持续时间规则；不能通过提高存储上限或直接判成坏道来替代验证。

## 4. 已完成的核对

- 7 个文件包实际通过本机上传接口测试；2 个 EDF+D 均按预期拒绝，5 个文件包进入推荐和完整记录执行，未发生其他执行失败。
- 对可读取的 5 份数据，使用直接二进制解码与独立单位换算，在开头、中间和末尾各取 32 点，并反转全部所选通道顺序，核对现有读取器。EDF 最大绝对差约 `5.21e-18 V`，两份 SpikeGLX 差为 0。这是有界抽查，不是所有数值或采集端标定的独立验证。
- 5 份任务完成本地文件全程的执行，输入哈希不变、所选通道和计划一致、无模块执行失败、总分为未校准。M03/M08 的 `partial` 状态及明细限制均保留。
- 5 份总览报告及 12 份逐窗报告共 17 个 HTTP 入口返回有效 HTML。未宣称浏览器视觉验收。

本批未扩展 NP2 或新的 NWB 数据，也未验证疾病诊断、临床伪迹识别或坏道检测准确率。
