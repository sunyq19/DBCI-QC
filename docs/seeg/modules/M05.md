# M05 逐触点统计

模块说明 · 版本 seeg-basic/1 · 2026-10-30

## 1 输入

每个选定源触点的原始标定电压。

## 2 处理

在有限值上计算数量、均值、标准差、RMS及峰峰值；保留源通道身份，不自动删除来源标坏触点。

## 3 输出

逐触点统计表、有效样本分母与缺失说明。

## 4 边界

RMS不是独立噪声地板，幅度不是坏触点结论。不做头皮PREP、LOF、电极桥接或跨杆邻近推断；不同参考和脑区的值不能直接作同一基准排名。

## 5 来源与复核

本项目独立适配；计算约定与科学判定分开。来源文件、配置和模块版本须随报告保留。
