# M02 数据画像与检查计划

模块说明 · 版本 seeg-basic/1 · 2026-10-31 · 文档修订 2

元数据设计见[字段字典](/standards/fields)与[方法适用规则](/standards/applicability)。完整字典尚未接入表单与存储，当前能力见[实现范围](/standards/implementation)。现有背景选项不代表已经具备按物种年龄或疾病调整阈值的依据。

## 1 输入

确认后的sEEG源通道、时间范围、上下文及可用事件。

## 2 处理

冻结本次分析通道组、原生样本范围和seeg-basic/1参数；沿用文件中的参考状态。

## 3 输出

可执行计划及各方法适用性；原始索引和文件内秒坐标映射。

## 4 边界

eeg_indices仅为兼容接口名，在本路线表示sEEG触点。未证实的电极杆、灰白质位置及双极配对保持未知；不由触点名推断或自动重参考。

## 5 来源与复核

本项目独立适配；计算约定与科学判定分开。来源文件、配置和模块版本须随报告保留。
