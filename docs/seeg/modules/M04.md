# M04 频谱与工频观察

模块说明 · 版本 seeg-basic/1 · 2026-10-30

## 1 输入

已确认sEEG电压、采样率与seeg频谱配置。

## 2 处理

使用SciPy Welch：Hann窗、50%重叠、逐段去均值；默认4秒窗，在50/60Hz附近描述可测窄带功率与峰位。

## 3 输出

PSD（V²/Hz）、频率分辨率、实际窗长、每触点窄带观察量。

## 4 边界

窄带半宽为max(1Hz,频率分辨率)。不使用α评分或头皮肌电阈值；高频及病理放电不能仅据频谱判成伪迹，谱峰不能证明来源。

## 5 来源与复核

本项目独立适配；计算约定与科学判定分开。来源文件、配置和模块版本须随报告保留。
