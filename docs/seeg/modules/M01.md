# M01 数据接入与结构核验

模块说明 · 版本 seeg-basic/1 · 2026-10-30

## 1 输入

来源文件、读取器、明确的sEEG类型及标定信息。

## 2 处理

核对文件指纹、通道身份、原生采样流、连续段和单位。区分文件声明、外部配套证据与用户确认。

## 3 输出

结构清单、来源指纹、单位和时钟证据、缺失项。

## 4 边界

格式扩展名或读取器默认EEG类型不证明电极在头皮或脑内；未知单位不得当作已标定电压。

## 5 来源与复核

本项目独立适配；计算约定与科学判定分开。来源文件、配置和模块版本须随报告保留。
