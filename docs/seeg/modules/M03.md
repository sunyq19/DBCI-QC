# M03 基础信号完整性

模块说明 · 版本 seeg-basic/1 · 2026-10-30

## 1 输入

原始标定电压与源样本索引。

## 2 处理

扫描非有限值及至少两个相邻样本完全相等的连续段；保留全量计数和有限数量的详细位置。

## 3 输出

每触点计数、原始样本区间与候选位置；超过每窗10,000条时报告省略数量和partial状态。

## 4 边界

精确恒值可能受量化影响，不等于坏触点。数据片段的首样本可不为0，候选必须定位到实际源样本。未保存位置不能视为正常。

## 5 来源与复核

本项目独立适配；计算约定与科学判定分开。来源文件、配置和模块版本须随报告保留。
