# M07 来源事件核对

模块说明 · 版本 seeg-basic/1 · 2026-10-30

## 1 输入

已登记的事件表、文件内时间及原始样本原点。

## 2 处理

核对事件字段、合法时间和选区重叠，映射到本次选区与原始样本。保留事件原类别和时长。

## 3 输出

选区内事件、时间映射、来源哈希及时间异常说明。

## 4 边界

任务事件和发作事件不是伪迹金标准；点事件不自动拼成区间。来源时钟映射不证明硬件同步准确，未标注不等于正常。

## 5 来源与复核

本项目独立适配；计算约定与科学判定分开。来源文件、配置和模块版本须随报告保留。
