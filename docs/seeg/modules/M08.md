# M08 分项评价与汇总

模块说明 · 版本 seeg-basic/1 · 2026-10-30

## 1 输入

已执行模块的观察量、覆盖、错误及未评状态。

## 2 处理

汇总本次范围、逐项结果和限制；区分完成、部分可评、跳过及失败。

## 3 输出

可追溯分项汇总；默认 score.value 为 null。

## 4 边界

完成率不是数据质量分；暂无跨病人、参考、脑区的统一sEEG评分。不能因癫痫相关活动本身扣分。

## 5 来源与复核

本项目独立适配；计算约定与科学判定分开。来源文件、配置和模块版本须随报告保留。

[本路线规范](/standards/seeg)

原版 MNE 平线／相邻变化提供通道候选占比与合并区间占比两项可选计分输出，默认权重 0。显式设置权重后按项目公式汇总，未评项按评分规则处理；不能将两项相加解释为污染时长。
