# 在线演示版部署准备

更新：2026-11-08。版本：`1.0.0rc3.dev40`。按[演示版方案 v1.0](../design/demo-deployment-v1.md)执行，操作步骤见[部署说明](demo.md)。

## 已准备

- [x] 沿用现有页面、接口、算法和共享数据目录，访客无需账号。
- [x] 固定访问地址及同源校验，增加共享提示；网页不开放服务器运行日志。
- [x] 生成低权限运行用户的 systemd 服务与 Caddy 反向代理配置，独立持久目录。
- [x] 四种模态的缓存示例及全部 256 个关联文件已核对；公开 EEG 下载器记录来源与校验值。
- [x] 全新安装环境下验证实际上传、推荐、计算、报告、PDF、波形、两个客户端共享及服务重启保留。
- [x] 一次接收一个上传，磁盘不足明确拒绝；沿用 7 天上传副本清理和现有任务队列。

## 部署到目标服务器后验收

- [ ] 提供服务器 IP、系统、SSH 管理方式、配置与可用磁盘、网站地址。
- [ ] 安装服务，配置访问端口或域名与 HTTPS，验证自动启动。
- [ ] 两个真实浏览器检查页面、示例、上传与共享记录；确认真实网络下的上传速度。
- [ ] 核对实际数据量的峰值内存、计算耗时、磁盘增长及备份位置。

当前已完成本地接口与实际反向代理验收，**尚未部署到远端服务器**。浏览器视觉检查受已保存的网站权限限制，不能以接口通过代替。验收范围与结果见[记录](../validation/demo-deployment-20261108.md)。

单文件/单记录 2 GiB；管理员预置数据集 10 GiB、100 记录、5,000 文件。所有访客共用“我的数据”，原始上传副本保留 7 天，报告保留。账号/项目隔离、OSS、网页整库上传、多机调度和管理后台暂缓。
