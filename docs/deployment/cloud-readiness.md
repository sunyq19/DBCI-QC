## 云端尚需

- [ ] 部署维护者记录系统、SSH 管理方式、可用 CPU/内存/磁盘和网站地址。
- [ ] 按固定版本更新代码与整套示例缓存；配置公开波形源文件，执行文件一致性检查。
- [ ] 配置域名/HTTPS与自动启动；协作数据库和附件按需迁移，公开运行记录须核验来源，禁止迁移用户临时上传和临时报告。
- [ ] 实际浏览器验证示例、跳转、上传检查、密码编辑、保存与版本切换。
- [ ] 记录目标机器的上传耗时、峰值内存、计算时间，确认备份位置。
