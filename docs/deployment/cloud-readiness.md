# 在线演示版部署准备

更新：2026-11-08。源码基线：`1.0.0rc3.dev39`。当前目标按[在线演示版方案 v1.0](../design/demo-deployment-v1.md)执行。

**把现有质控台部署到服务器，像本地一样使用。** 访客无需账号，共享“我的数据”；仅保留一个管理员负责维护。

## 本轮要做

- [ ] 在一台 Linux 服务器安装现有程序，配置统一访问网址与服务自动启动。
- [ ] 把四类缓存示例和用于运行的公开样本准备好，核对报告、图表与 PDF 链接。
- [ ] 使用一个持久运行目录，所有访客的记录、不同方案和报告统一展示在“我的数据”。
- [ ] 适配外部访问地址、上传与报告路径；复用现有页面和算法，不拆分或重写前后端。
- [ ] 设置一个管理员的维护权限，优先使用服务器配置和命令完成示例更新与数据清理。
- [ ] 用两个浏览器验证共享目录，再检查上传—计算—报告，以及服务重启后的结果保留。

单文件/单记录 2 GiB，数据集 10 GiB、100 记录、5,000 文件，上传副本保留 7 天。数据集先由管理员预置，沿用现有登记与检查功能。访客上传界面说明演示资料共享可见。

## 当前已有与待适配

安装脚本、共享本机运行目录、后台排队、报告缓存、上传限额和 7 天保留已有实现。服务目前仅接受本机地址，外部访问需适配域名与同源请求；管理员维护授权和共享提示仍待接入。当前尚未完成线上部署。

账号注册、项目隔离、私有 OSS、分片续传、独立持久队列、远程执行器和管理后台暂缓。Docker 不作为这次展示的必需项。

部署时需要提供服务器访问方式和可用地址。配置、上传文件与运行目录保存在服务器，不随代码推送到 GitHub。开发进度见 [TODO](../../TODO.md)；已确认的产品范围以[演示版方案](../design/demo-deployment-v1.md)为准。
