# 云部署准备

更新：2026-11-08。源码基线：`1.0.0rc3.dev39`。本页记录下一阶段的交付顺序；当前可运行的是本地单用户质控台。

## 本次固定的基础

- 独立读取器、M01–M09 信号模块、D01–D04 数据集检查与复核，继续使用现有接口。
- EEG、ECoG、sEEG、Neuropixels 各自的试行评分、可调权重、受限项排除和同类问题合并规则。
- 中英文界面、HTML/PDF 报告、公开数据展示快照、安装脚本与回归检查。
- 流程网页从 GitHub 上的代码目录同步；团队说明与固定版本独立保留。见[协作网页说明](../../apps/flow-editor/README.md)。

## 云端首版范围

沿用 [platform-design/1.0](../design/platform-v1.md) 和 `cloud-intake/1.3`，不另立一套限额。

| 项目 | 首版约定 |
| --- | --- |
| 单文件 / 单份记录 | 2 GiB；配套文件合计、ZIP 展开后也须满足 |
| 数据集 | 10 GiB、100 份记录、5,000 个文件；按完整快照核验 |
| 初始计算并发 | 1 个信号任务；超额排队，不同时占满内存 |
| 上传副本 | 7 天；运行中任务延后清理，报告与检查证据保留 |
| 试用数据 | 先用已登记公开样例，完成隔离验收后再开放受控上传 |
| 初始资源预算 | 既定估算为 8 vCPU、32 GiB 内存、300–500 GB 工作盘及私有 OSS，无 GPU；采购前以本版代表性任务实测确认 |

## 开发顺序与验收

| 顺序 | 要做什么 | 完成的判断 |
| --- | --- | --- |
| 1. 可复现部署 | 固定 Python/依赖、容器构建、配置模板、持久目录、健康检查与部署脚本 | 空白 Linux 环境启动；四类示例可打开；合成 EDF 可检查并导出报告；更新后旧报告仍可读 |
| 2. 账号与项目隔离 | 数据、任务、报告、波形、下载统一校验权限；替换本地路径登记入口 | 两个账号各自上传，互相不能列出或通过已知 ID 访问对方任何资源 |
| 3. 持久后台任务 | 网页服务与计算进程分开；持久化队列、幂等提交、取消、失败重试、资源限制 | 服务重启不丢任务；重复提交不重复计算；中断范围如实保存；恢复或重试不覆盖旧结果 |
| 4. 私有对象存储 | OSS 限范围临时上传授权、分片续传、配套文件关联、服务端实际字节核验 | 超限拒绝；续传和复用对象仍按完整数据集计量；不依赖浏览器声明；过期副本清理不删除报告 |
| 5. 试用与回退 | HTTPS、日志脱敏、磁盘/内存监测、备份恢复、固定版本部署与回退 | 完成上传—确认—排队—报告—PDF 全流程及两账号隔离；压测后确认并发与成本 |

第一步可先交付仅团队可访问的公开样例演示环境；开放多人上传须完成第 2–5 步。容器只是部署载体，不替代权限隔离和任务管理。

## 当前实现边界

`apps/workbench/server.py` 使用本机 HTTP 服务并仅监听 `127.0.0.1`。任务文件已保存，重启后未完成任务会标记为中断；尚未实现可持久恢复的云端队列。上传保留策略和限额核心已有本地实现，OSS 授权、云端账号隔离与并发配额尚未实现。

下一阶段保留 `src/ephys_qc/` 的算法接口，以适配器连接存储、任务和身份服务；不为部署重新实现一套算法。云端报告仍保存实际模块、参数、权重、评分版本、输入快照和执行范围。

代码与文档进入 GitHub；原始数据、个人上传、运行目录、账号密钥不进入仓库。发布示例仅包含经检查的公开数据展示快照，旧快照不随软件更新重写。
