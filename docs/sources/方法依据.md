# EEG 顶层模块化设计：常用坏道方法、条件与门控底稿

核对日期：2026-10-28。性质：原始论文、作者/项目官方文档及官方源码的只读研究；未运行 QC 算法，未改网站或远端代码。线上文档版本不代表本地安装版本。本稿是设计建议，不是临床验证或标准符合性结论。

## 1. 主张与方法边界

主张：顶层流程应固定为 **读取与完整性检查 → 元数据/适用性判断 → 可运行的检测模块 → 通道×时间证据 → 人工复核 → 可选修复及复核**。按采集条件启用模块，避免每种数据各自堆一套不可比较的流程。疾病标签不直接决定好坏，统计异常也不自动等于伪迹。

本稿把三种对象分开：

- **检测**：给出观测量、阈值、通道、时段和可疑原因，原始样本不变。
- **排除**：删除/屏蔽通道或时间段；必须保留原始坐标和删除掩码。
- **修复**：重参考、滤波、插值、ASR 重建、ICA 成分删除等形成派生信号；必须保留来源和前后差异。算法内部为了检测使用的临时滤波，也应记录，但不能冒充用户原始信号。

以下是有原论文和成熟开源入口的候选，不是“所有 EEG 都要依次运行”的推荐清单。

## 2. 方法对照

| 方法 / 建议拆分模块 | 判定的对象与主要证据 | 检测、排除、修复的区别 | 关键输入条件及边界 |
|---|---|---|---|
| PREP / PyPREP 的 `NoisyChannels` | 全记录坏道；依据幅度离群、通道相关、掉线、高频噪声、可选 RANSAC 等，部分证据来自窗口汇总 | 检测器可以独立调用；它不等于完整 PREP。输出整道列表时仍应保存对应时段和覆盖比例 | 正确的 EEG 类型、单位、参考和采样信息；辅助导联不能混入 EEG 比较池。RANSAC 需空间位置；非空间指标不能因缺位置一并禁用。[P2](https://pyprep.readthedocs.io/en/stable/generated/pyprep.NoisyChannels.html) |
| 完整 PREP | 以可靠坏道检测支持稳健参考，减少坏道污染平均参考的风险 | 完整流程含线噪处理、重参考及坏道插值，属于预处理；不能直接替代只读质检 | 头皮覆盖不足时插值应谨慎。原文明确坏 epoch 剔除不属于稳健参考步骤；不能把 PREP 的“通过”解释为所有伪迹已去除。[P1](https://www.frontiersin.org/journals/neuroinformatics/articles/10.3389/fninf.2015.00016/full)、[P3](https://pyprep.readthedocs.io/en/stable/generated/pyprep.PrepPipeline.html) |
| EEGLAB `clean_rawdata` 的坏道部分 | 平线、线噪及相对其他通道预测不足；窗口证据可累计为整道排除 | 默认工作流会移除通道，并可能滤波；若纳入质检应在副本上运行并抽取证据/掩码 | 空间相关检测需要大致正确的位置；没有位置时软件有不同的无位置回退，不能把二者当同一方法。需记录实际执行分支。[C1](https://eeglab.org/plugins/clean_rawdata/)、[C2](https://github.com/sccn/clean_rawdata/blob/master/clean_artifacts.m) |
| ASR：独立的“异常子空间/时段”模块 | 将短时多通道活动与校准数据比较，处理突发性异常子空间；主要不是静态整道坏道表 | 可以重建，包装流程也可删除受影响时段；两者含义不同。校正量不等于已经证实的伪迹量 | 依赖多通道结构、可用秩、采样率、预处理和具有代表性的校准段。核心 ASR 不以电极坐标为必需输入；包装流程的空间坏道检测另有要求。原始展示场景包括高密度干电极 EEG，不能据此保证少导或临床波形安全。[A1](https://escholarship.org/uc/item/24h701z6)、[C1](https://eeglab.org/plugins/clean_rawdata/)、[C2](https://github.com/sccn/clean_rawdata/blob/master/clean_artifacts.m) |
| Autoreject local | 通道×epoch 的峰峰值异常；交叉验证学习阈值，再决定局部修复或整 epoch 排除 | `fit` 后可只取 `get_reject_log`；`transform` 才应用修复/剔除。训练内部使用插值构造参考，不表示源数据已获人工确认 | 需明确 epoch 定义、足够可分折的 epoch 和有效通道位置；本次官方实现检查预加载及位置。原论文主要验证 EEG/MEG 和诱发响应，不能等同临床事件保真已验证。[R1](https://arxiv.org/html/1612.08194v3)、[R2](https://autoreject.github.io/stable/generated/autoreject.AutoReject.html)、[R4](https://autoreject.github.io/stable/_modules/autoreject/utils.html) |
| Autoreject global threshold | 学习某类通道的整体峰峰值拒绝阈值，用于 epoch 层面 | 是阈值估计，不自动提供哪个坏道可可靠重建的证明 | 与 local 的插值路径不同，应单独登记接口、交叉验证划分及阈值；不能用少导绕开 local 的检查后仍宣称完整 local 验证。[R3](https://autoreject.github.io/stable/_modules/autoreject/autoreject.html) |
| FASTER：分开登记通道、epoch、ICA、局部通道-epoch | 通道统计包括相关、方差、Hurst；完整流程还处理 epoch、ICA 成分和 epoch 内局部通道 | 作者手册的完整流程会插值坏道、删除 epoch/ICA 成分；可用 `*_properties` + `min_z` 抽取检测，但需要单独封装并验证 | 官方手册要求配置位置、EEG/外部导联、参考、epoch/事件；ICA 的 EOG 相关需 EOG 或经确认的代理。手册称主要设计面向高密度阵列，少于 32 道未测试；不是永久性禁用结论。[F1](https://pubmed.ncbi.nlm.nih.gov/20654646/)、[F2](https://sourceforge.net/projects/faster/files/FASTER%20manual.pdf/download) |

## 3. 阈值属于实现与配置，不是国际统一质量线

| 已核对事实 | 对平台的要求 |
|---|---|
| PyPREP 本次 stable 页面标为 0.10.0：相关窗口 1 s、相关阈值 0.4、坏窗比例 0.01；幅度/高频 z 阈值 5；RANSAC 相关阈值 0.75、坏窗比例 0.4、窗长 5 s。平线默认 `1e-15` 的单位是 **V**。[P2](https://pyprep.readthedocs.io/en/stable/generated/pyprep.NoisyChannels.html) | 保存实际包版本、调用入口、参数和单位。不能把这些值直接写为平台验收标准；也不能把新版参数归入旧版本的既有实现。 |
| PREP 2015 原文的 RANSAC 段落同时出现默认 5 s 与 4 s，后续图和分析使用 4 s；原文说明默认值来自经验选择。[P1](https://www.frontiersin.org/journals/neuroinformatics/articles/10.3389/fninf.2015.00016/full) | 复现依据应是固定版本源码及完整参数，不能仅凭论文中一个数字。 |
| 当前 `clean_artifacts.m` 源码 `BurstCriterion=5`，注释指出 GUI 默认 20；源码 `BurstRejection='off'`，官网说明离线 GUI 默认使用拒绝时段。官网坏道相关默认 0.8、平线 5 s、线噪标准差数 4。[C1](https://eeglab.org/plugins/clean_rawdata/)、[C2](https://github.com/sccn/clean_rawdata/blob/master/clean_artifacts.m) | “使用 ASR 默认参数”信息不足；必须同时写 GUI/脚本入口与删除/重建模式。不同算法的 z 值也不能直接互换。 |
| Autoreject 0.5.1 源码在 `n_interpolate=None` 且所选通道少于 4 时抛错；这是该默认实现分支的检查。[R3](https://autoreject.github.io/stable/_modules/autoreject/autoreject.html) | **4 道不是充分适用条件**，显式覆盖参数绕过检查不等于得到验证。需看同类型、同参考组中真正可用于预测的导联和几何覆盖。 |
| FASTER v1.2.3b 手册第 25 页说明测试使用 3Z，其他范式/设备可能需要不同值；第 32 页说明少于 32 道未测试，并提示少导时可关闭通道拒绝和 epoch 插值。[F2](https://sourceforge.net/projects/faster/files/FASTER%20manual.pdf/download) | 将“历史验证范围”和“我们的配置门控”分别存储；32 不应被写成 EEG 通用最小通道数。 |

设备计量性能与上述数据质控阈值也须分开：设备噪声、共模抑制、输入范围等测试需要规定的输入/负载/测量条件；记录中相对功率或离群值既不证明设备合格，也不单独证明设备故障。

## 4. 建议的 tags：描述数据条件，不预先判好坏

以下表格是工程建议，不是任何论文或标准中的强制字段。每个 tag 都应带来源（文件头/采集记录/人工/算法推断）、可信度和 `unknown`，避免把缺失当成正常。

| 标签组 | 最小内容 | 影响哪些模块 |
|---|---|---|
| `modality` / `channel_type` | scalp EEG、sEEG、ECoG；每导 EEG/EOG/EMG/ECG/参考/触发等 | 决定比较池与方法范围；不能把所有导联直接送入 EEG 统计 |
| `channel_identity` / `derivation` | 稳定通道 ID、显示名、原索引；单极/双极及正负电极 | 防止坏道结果错配；双极导联不等价于一个物理电极 |
| `reference` / `comparison_group` | 采集参考、离线参考、参考变更；每组成员 | 幅度、相关、秩及跨道比较；不同参考不得静默混组 |
| `geometry` | 有效位置、坐标系、位置来源/质量、覆盖范围、可用导联数 | 空间 RANSAC、插值、头皮图；数量与覆盖都要检查 |
| `sampling` / `bandwidth` | 原始/当前采样率、有效通带、重采样和滤波史 | 窗口、频谱和高频噪声适用性；不能只看文件头采样率 |
| `units` / `hardware` | 物理单位、数字/物理量转换、ADC 极值、设备/采集配置 | 幅度与削顶检查；未确认量程时只能报告候选削顶 |
| `recording_structure` | 连续/epoch、时长、缺口、暂停、事件时钟、切窗策略 | 防止跨缺口相关/滤波；给出检测覆盖和分母 |
| `state` | 清醒/睡眠阶段/镇静/未知；可随时间变化 | 状态分层的阈值评估、校准段匹配；状态不是质量标签 |
| `analysis_target` / `protected_event` | ERP、运动想象、睡眠结构、尖波/发作、慢波、高频活动；已标注事件区间 | 防止把目标活动作为伪迹删除；未知目标降低自动修复权限 |
| `artifact_context` / `auxiliary_available` | 运动/刺激/操作注释；EOG、EMG、ECG、加速度等是否真实存在 | 提供伪迹归因的独立证据；缺辅助导联不等于无伪迹 |
| `history` / `calibration` | 已知坏道/人工注释、插值/ICA/ASR史、有效秩；校准段来源、状态、时段与哈希 | 防止重复处理、用合成通道充当独立好道、用已污染校准拟合 |
| `clinical_context` / `review_policy` | 必要且受控的临床背景、使用目的、复核者；默认检测或允许派生修复 | 临床背景只提醒适用范围与复核；不得以“患病/健康”直接扣分或赋予合格 |

对分类研究额外记录 `subject_id_pseudonym`、session、device/site、训练/验证划分。质量规则不能利用测试集诊断/结局来选阈值，否则容易把标签信息混入前处理。训练时学习出的参数和评测时可允许的无标签校准须事先区分并冻结。

## 5. 模块门控建议

这些是根据方法假设提出的工程门控，尚未在本地系统实现或验证。

| 条件 | 建议行为 | 必须给出的解释 |
|---|---|---|
| 文件可读但通道类型、单位或参考缺失 | 先做可判定的结构完整性检查；暂停依赖缺失信息的比较/物理阈值 | `insufficient_metadata`，列出缺失项，不用默认猜测冒充已知 |
| 无有效坐标，或坐标与导联身份不匹配 | 禁用空间 RANSAC/空间插值；可运行已验证的非空间检测；若走无位置回退，明确另一个方法 ID | `missing_or_invalid_geometry`；缺位置不是坏道证据 |
| 导联少、有效比较组更少，或只覆盖局部头皮 | 优先完整性、掉线、削顶候选、单通道时频证据；跨道离群仅候选；关闭未经该配置验证的自动重建 | 不设一个“所有算法通用 N≥X”。Autoreject 默认分支及 FASTER 历史范围分别说明 |
| 采样率 ≤100 Hz | 不运行 PyPREP 的 >50 Hz 高频噪声方法；其他模块独立判断 | `unsupported_frequency_band`。[P2](https://pyprep.readthedocs.io/en/stable/generated/pyprep.NoisyChannels.html) |
| fs>100 但数据已低通到 40 Hz，或目标频带已滤除 | 高频方法仍不应声称观察到原始高频质量；线噪也需标明已 notch | 有效带宽与处理历史门控，不能把“被滤没了”当作原始干净 |
| 长记录含不同状态、切换、暂停或强运动 | 明确分段、有效分母与抽样覆盖；不把少量抽样全体外推 | 报告哪些区间未检测；全局坏道与局部坏段分列 |
| 睡眠/儿童/病理活动或其保留是分析目标 | 相应方法先以候选/检测模式运行；按状态验证阈值，并对受保护事件复核后才允许删除/修复 | 慢波、K-complex、尖波或高幅放电可能是目标信号；统计罕见本身不是排除依据 |
| ASR 没有可辩护的校准段，或校准状态与目标明显不匹配 | 暂停自动重建；显示校准不足，不能静默把整段记录当干净参考 | 保存校准选择规则、入选时间、质量证据及状态匹配 |
| Autoreject epoch 数/长度不支持设定的交叉验证，或连续记录切窗规则未定 | 暂停拟合或采用另一个经过验证的只检测配置 | 报 `insufficient_epochs`；不能为了跑通随意切窗后继续沿用原验证声明 |
| ICA 缺足够数据、秩/参考未知，或无可靠眼动证据 | 禁用自动成分删除；允许有说明的探索性可视化 | 不能将 ICA/FASTER 的成分异常分数直接当真值；不伪造 EOG 标签 |
| 输入已插值/修复，或准备比较多种方法 | 保存原始与每个派生版本；统一可比较的前处理条件；分别报告检测和信号变化 | 同一输出不得既作为“人工参考”又作为待测算法结果 |

特别是睡眠与疾病：不能概括成“ASR 一律不适用”。已有原始研究在婴儿痉挛患者与对照的睡眠/清醒 EEG 上使用 ASR+ICA，并比较不同清洗强度；这只支持其特定设计下的应用，不等于所有发作或尖波形态均得到保护。[临床原始研究](https://pubmed.ncbi.nlm.nih.gov/34823159/) 因此建议把保真问题转化为任务验收，而不是疾病黑名单。

## 6. 顶层接口与最小验收

建议每个模块返回统一对象，至少包含：`method_id`、版本/入口/参数、输入与配置哈希、适用性、未运行原因、稳定通道 ID、原始时间区间、观测值及单位、阈值来源、检测覆盖/分母、候选原因、人工复核状态、是否生成派生数据及变更掩码。`not_run`、`not_applicable`、`insufficient_evidence` 都不能转成 `good`。

通道状态建议至少区分“全段不可用”“局部可疑”“已修复的派生通道”“证据不足”；记录级可用性应说明**对哪个分析目标**。全零、全部缺失等硬故障不能被其他模块满分抵消；少导导致部分方法不运行时，也不能隐式补满分。

第一阶段不需要把四个预处理体系全接入。建议先做统一元数据/证据接口，再接 PREP 的明确检测子集、基础坏段检测和人工复核；Autoreject 用于有明确 epoch 的适用场景；ASR/FASTER 的修复作为独立、可关闭的后续模块。

最小验收产物建议为：

1. **适用性矩阵**：至少覆盖全头皮多导、少导睡眠/混参考、缺坐标、低采样/已低通、已有坏道注释。每例逐模块说明执行/跳过原因；这些是设计用例，不声称本次已运行。
2. **盲法复核样本**：分别评估通道和通道×时间，保留两名复核者分歧。疾病组标签不直接进入 QC 判分；评价是否误删预先标注的目标活动。
3. **修复保真报告**：原始与派生并存，报告被改写/删除的时间和通道、目标事件保留率，以及与研究目标相符的波形/频谱/事件特征变化。数值验收线须由先导数据与用途确定并预先冻结，不能从最终结果倒推。
