# 版本管理与发布验收

## 1. 维护对象

源码、接口约定、方法目录、项目技术规范、测试及公开数据来源清单纳入Git。原始记录、患者信息、本机路径、日志、运行结果、临时文件与私有标注不进入Git。

软件版本唯一来源为`src/ephys_qc/version.py`；包元信息、服务健康信息、界面与运行环境记录引用它。软件版本、接口schema版本、项目技术规范版本和输入/复核修订号分别维护，不能互相代替。

## 2. 修改与冻结

每项可独立验收的修改形成一个提交。改变输入、方法参数、默认门槛或报告语义时，更新对应文档并运行受影响的自动检查。新功能完成后做一次完整回归与真实文件流程检查。

使用语义化版本：不兼容接口或结果语义变更增加主版本，兼容功能增加次版本，修复增加补丁版本。候选版本形如`1.0.0rc1`，Git标签为`v1.0.0-rc.1`。标签创建后不移动、不覆盖；发现问题使用新的提交和候选号。正式标签仅标记已满足发布条件的提交。

候选版之后尚未发布的开发快照使用下一候选号加`.devN`，例如`1.0.0rc3.dev0`。数据基线保留实际执行时的软件版本，不随当前目录或界面升级改写；开发快照不创建正式候选标签。

公开源码仓库为 [sunyq19/DBCI-QC](https://github.com/sunyq19/DBCI-QC)，主分支为 `main`。首次公开使用经过内容清理的源码快照；此前开发历史及 `v1.0.0-rc.1` 标签保留在原本地仓库，不推送到公开远程。历史验收记录中的早期提交号用于本地追溯，可能不在公开提交图中。公开源码不等于已发布正式版；项目及第三方许可见仓库说明。

后续修改在公开 `main` 的共同历史上维护，不再重新生成初始快照。已有本地候选标签不移动或复用；下次候选使用新的版本号和标签。向公开远程仅推送明确选择的分支或标签，不使用全引用或镜像推送。

2026-10-31的`1.0.0rc3.dev8`公开更新以既有`main`为父提交汇总本地开发更新，清除来源清单、文档与下载脚本中的本机目录。原开发分支保留在本地，验收记录中的开发提交号用于本地追溯；公开分支继续保留已有公开历史，不推送包含本机路径的开发中间提交。后续公开开发从更新后的`main`开始。此次为开发版本源码更新，不创建正式发布标签。

## 3. 正式版本的发布条件

1. 全部Python测试与工作台JavaScript契约、国际化、规范导航、布局检查通过。
2. EDF、BDF、BrainVision、EEGLAB、FIF真实文件读取到报告的流程通过；来源字节不变，未评状态如实保留。
3. 真实数据的输入修订、分块覆盖、候选定位、复核保存/冲突和复制重跑通过；断点、非零样本原点、短尾窗、失败与取消有独立测试。
4. 原有历史任务与报告继续可读；更新服务前确认没有运行中的任务，保留原运行目录。
5. 浏览器人工走查桌面与窄屏，完成上传、确认、更正、预览、运行、定位候选、保存复核、刷新恢复、中英文及返回质控台流程。
6. 变更记录、功能边界、验收记录、环境版本与恢复方式齐备。

当前自动浏览器访问曾被审批阻止，未绕过该限制；第5项尚未完成，因此本次保留候选版本身份。它不表示临床诊断器械或正式发布的行业标准。

自动回归入口为`python scripts/check_release.py`，须使用`.local/workbench.json`指定的科学Python环境。真实文件验收分别运行`scripts/validate_multiformat_workbench.py`和`scripts/validate_release_workflow.py`，输出必须指定新的仓库外目录；不会覆盖历史验收结果。

## 4. 运行与来源版本

输入修订创建新ID、记录家族、递增修订号和父输入ID，不覆盖原record.json。每个任务冻结输入版本、来源与配套文件指纹、方法选择、配置、计划ID和软件环境。复制重跑创建新任务并记录parent_job_id。

人工意见保存在独立reviews.json，使用expected_version检测冲突并追加历史。重新计算不覆盖算法result.json；旧候选身份不自动转移到新方法、新参数或新数据的候选。

中断任务保留检查进度，未完成范围保持未评。当前不自动续算中断窗口，使用复制配置新建任务；不能把已有片段视为整份记录成功。

## 5. 恢复

先停止当前服务并确认任务已结束，再在独立目录检出需要的标签；不要在有未提交修改的目录强制回退。使用独立运行目录验证旧版本，历史目录保持只读备份。只有核对接口、输入修订和复核schema兼容后才能切换日常运行目录。不得用旧版本软件覆盖新schema文件。

本机环境清单见`profiles/tested-environment.json`。BrainElecQC及其他第三方依赖单独安装，不将算法源码、原始数据或许可未确认的样例打入软件发布包。
