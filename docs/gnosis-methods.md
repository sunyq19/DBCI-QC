# 灵犀云可选质控方法

版本：2026-11-07 · 原版接口适配，供团队确认。

来源：[GnosisNeuroDynamicSE](https://github.com/Gnosis-Neurodynamics/GnosisNeuroDynamicSE)，固定提交 `3547548bb81e1e1e2bc90226add5574437921c0c`。调用 `SignalQualityEval 3.0.0`、`eegaux 2.0.9`、`eegext 2.1.9` 提供的原版函数。算法以编译 wheel 提供，本项目不重写这些算法、不再分发 wheel。

## 1. 在现有流程中的位置

```text
读取文件 → 确认头皮EEG、通道、单位和比较组
                     ↓
           选择需要的灵犀云子方法
                     ↓
        各子方法准备自己的分析副本
        ≤256 Hz、1–70 Hz、平均参考
             ┌───────┴────────┐
       通道和时间检查       频域统计
       线长坏道候选        默认伪差区间筛选
       伪差区间与占比      保留>10秒的连续片段
       低频/高频异常       功率、幅值、PSD差异
             └───────┬────────┘
                可选参考范围对照
                     ↓
          分项测量、候选与复核证据
```

8 项方法分别勾选，不要求运行整本 Notebook。副本准备和频域片段筛选属于方法的内部依赖；选择一项频域方法时，默认会执行其所需的伪差检测，但不会顺带执行其他频域统计。结果与原来的 PREP、工频等结果并列保留，**不并入当前基础总分**。

## 2. 模块划分

| 所属模块 | 独立选项 | 原版接口 | 输出 |
| --- | --- | --- | --- |
| M05 通道质量 | 线长坏道候选 | `get_bad_channels` | 候选通道、逐道平滑线长总量 |
| M06 伪迹线索 | 伪差区间与占比 | `get_Artifact` | 逐道/全局区间、异常时间占比 |
| M06 伪迹线索 | 低频异常区间 | `get_abnormal_inertvals` | 1–13 Hz 候选区间与占比 |
| M06 伪迹线索 | 高频异常区间 | `get_abnormal_inertvals` | 13–40 Hz 候选区间与占比 |
| M04 频谱与干扰 | 相对频带功率 | `cal_psd_freq`、`bands_repower` | 五频带比例、PSD |
| M04 频谱与干扰 | 频带平均幅值 | `bands_amp` | 五频带平均绝对幅值，μV |
| M05 通道质量 | PSD 通道差异 | `cal_psd_freq`、`detect_bad_channels_psd` | 对数频谱距离、候选通道 |
| M04 频谱与干扰 | 参考分布对照 | 上述频域接口及包内 `Standard` 表 | 数值、参考上下界及偏离方向 |

共同运行条件：头皮 EEG、物理单位 V、3–128 个同一参考比较组通道、采样率大于 140 Hz；当前适配按 12–120 秒窗口执行，长记录由现有后台分窗。这里是首版工程范围，并非所有灵犀云函数的理论适用上限。双极/混合参考和其他模态不套用这套通道比较。

整份检查采用预先确定的分段策略：启用灵犀云方法时，短于半个处理窗的尾段与前一窗均分，前提是均分后两段都至少 12 秒。例如 733 秒记录的最后 120+13 秒改为 66.5+66.5 秒；不丢弃样本、不重叠计分，也不跨采集缺口。计划保存 `gnosis_balanced_short_tail/1`。真正没有足够连续片段的数据仍可能未评，不能靠调整分段保证所有数据都有分数。

原示例针对静息态头皮 EEG。任务、睡眠、疾病数据中的真实活动也可能触发统计离群；可以探索其指标，但不据此自动删道或判定疾病信号为伪迹。

## 3. 参数和依赖

- `prepare_copy=true`：调用原版 `preprocess_raw`，仅处理本方法的副本。关闭时必须已有经过核实的 ≤256 Hz、1–70 Hz 输入。
- `exclude_artifacts=true`：频域项默认调用 `get_Artifact`，取全局伪差补集，只保留持续时间严格大于 10 秒的区间。没有足够片段时报告“未评”。显式设为 `false` 后使用整个分析副本，并保留这个处理选择。
- 线长方法的 `threshold=4.5`，低频 `3.5`，高频 `6`，PSD 差异 `3`。它们是上游示例的参数，不是通用合格线。
- `get_Artifact` 内部有固定的振幅、线长窗和合并设置，外层参数并非都生效；界面不提供无效参数。结果记录原版内部预处理。
- 频域片段按上游示例拼接。拼接接缝可能影响滤波和 PSD；仅返回整体统计，不把拼接后的时间当作原始时间。时间检测的候选仍映射回原记录。
- 低/高频方法若出现指数溢出，仅在独立子进程内将原版 `exp` 运算提升至扩展精度，仍调用原版 `get_power_ratio`、`get_abnormal_inertvals`，不改公式、阈值或候选区间规则。结果保存 `numerical_precision`、溢出数量及适配版本；正常路径仍采用原版 float64。运行平台无扩展指数范围、统计量退化或重试后仍非有限时保留“未评”，不替换为零或满分。安装的 wheel 文件与 NumPy 全局模块不修改。

## 4. 与整本 Notebook 的区别

**没有自动执行 ICA，也没有按线长候选自动删道。** 上游 Notebook 的 ICA 会分类并移除部分成分；这会改变后续统计，仍属于待确认的独立清洗功能。当前各子方法在用户确认的同一通道组上计算，原始文件及其他路线的信号不变。

参考分布对照只展示包内阈值和当前值，不直接沿用雷达图归一化为质量总分。上游雷达图的线长偏离度与 `get_bad_channels` 的双阈值判据也并非同一公式。参考库的人群、设备、状态及外部有效性仍待提供方确认。

## 5. 运行环境与使用

默认不启用。读取文件并确认信息后，在 **高级设置 / 可选方法** 或模块详情中勾选相应“灵犀云”选项。记录中需确认共同/连接耳参考，并声明所选通道属于同一比较组。运行证据保存原版包版本、编译模块 SHA-256、输入哈希、参数、候选区间和所用片段；没有运行的项目不按 0 处理。

独立 Python 3.12 环境的安装遵循[上游说明](https://github.com/Gnosis-Neurodynamics/GnosisNeuroDynamicSE#环境与依赖)。本版验证固定 MNE 1.12.1、NumPy 2.4.6、SciPy 1.18.0、pandas 2.3.3；包版本不符时不静默执行。

在仓库 `.local/gnosis-runtime.json` 中配置：

```json
{"python": "/absolute/path/to/gnosis-python312/bin/python"}
```

也可通过管理员环境变量 `DBCI_QC_GNOSIS_CONFIG` 指向该配置。路径只从受信任的本地配置读取，不接受上传文件或任务请求指定执行程序。临时信号文件在本地使用并在计算结束后清理；网站只发布模块设计，不含信号或运行环境路径。

Notebook/文档采用 MIT；二进制 wheel 按提供方授权使用。公共仓库包含适配器和安装说明，不含 wheel、患者数据或本机配置。
