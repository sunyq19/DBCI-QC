# 头皮脑电数据质量控制技术规范

项目技术规范 · 征求意见稿 · 版本 0.8 · 2026年10月31日

本文件规定人类连续头皮 EEG 基础技术质控的项目要求，不是已发布的国家、行业或团体标准。符合本项目报告格式不表示符合外部标准，也不证明检测准确性或临床有效性。

## 1 范围

本文件适用于有来源依据的人类连续头皮 EEG 的基础技术质量检查，包括文件与标定、信号完整性、频谱描述、窄带干扰线索、通道候选、辅助信号线索、标注核对及结果追溯。记录可包含清醒、睡眠或疾病背景，但相关背景不自动改变判定阈值。

不适用于临床诊断、设备电气安全检验、侵入式电生理、动物电生理及分选后神经元单元的质量判定。对其他范围可保留已可靠计算的技术描述，但不应声明完成本文件范围内的评价。物种或记录位置未知时，应保留范围未确认状态。

技术质量与特定应用的适用性应分别评价。技术异常候选不直接决定数据必须弃用；是否可用于疾病识别、运动解码、负样本研究等用途，应有单独的应用方案和验证。

外部规范性引用文件：无。编制参考文件见附录 A 与[来源与依据](/standards/eeg-evidence)。外部资料作为数据管理、采集背景或方法定义的依据，不将其中适用于其他目的的要求直接转为本项目通用合格线。

本文件的具体检查定义见[检查规则](/standards/eeg-checks)，报告要求见[EEG 质控报告](/standards/eeg-report)。应用时应同时记录各文件与规则目录的版本；内部模块编号不替代检查定义。

## 3 术语

| 术语 | 定义 |
| --- | --- |
| 基础技术质量 | 关于数据结构、标定、连续性及可解释信号证据的属性，不包括特定应用的性能保证 |
| 检查词条 | 具有稳定标识、适用条件、计算口径、输出与依据的检查项目；一个模块可实现多个词条 |
| 观察量 | 在明确范围与参数下计算的数值或描述，不必然包含质量判定 |
| 质量候选 | 按声明规则标记的可疑通道、时间段、通道对或分段，尚待复核 |
| 确认结果 | 经规定复核程序认定的质量结论；应记录适用范围与复核依据 |
| 检查覆盖 | 本次实际完成评价的通道、时间及频率范围，区别于输入文件范围与波形展示范围 |
| 评价配置 | 方法、参数、阈值、适用条件、汇总规则及其版本 |
| 阈值性质 | 判据属于外部要求、方法定义、自适应统计界限或项目暂定参数的分类；须保留具体来源 |
| 未评 | 未选择、条件不足或执行失败而未形成有效评价；不等于未检出异常 |
| 参考 | 采集或计算电压时采用的电位参照；ECG、EOG、EMG 辅助通道不因此成为 EEG 参考电极 |

“应”表示要求，“宜”表示推荐，“可”表示允许。

## 4 通用要求

### 4.1 数据身份与来源

应记录唯一标识、来源、版本、文件校验值、原始或派生属性及配套文件关系。未知信息应明确标记，不应推测补全。来源标签、人工补充与程序派生的信息应分别记录。

报告不应包含非必要的个人身份信息。文件指纹一致只证明文件字节一致，不证明来源标注或采集声明准确。

### 4.2 元数据与通道

应核对物种、记录位置、信号对象、格式、通道数、采样率、长度、单位、标定及时间轴。应区分文件记录通道数、已选分析通道数和各方法实际有效通道数；保留原始通道索引和名称，不合并重名通道。格式不应作为模态或疾病的确认依据。

应区分 EEG、ECG、EOG、EMG 及其他角色，单独记录采集参考与当前参考。比较组、位置、滤波史及背景信息应有来源；缺项应限制相应方法或解释，不要求使用者填入猜测值。

年龄应保留数值或范围、单位、起算依据与对应采集时间；未知疾病不等于健康，未知物种不等于人类。背景字段未经独立验证，不应驱动自动扣分。

### 4.3 数据保全

不应覆盖原始文件。滤波、重参考、重采样及分段应记录参数；排除或修复结果应另存，并保留原始对应关系。检查过程中的副本处理和最终交付清洗数据应分别标识；指标下降不单独证明清洗改善了质量。

### 4.4 执行计划

应先提取技术信息，再确认模态、通道和背景，随后生成适用建议。运行前应记录检查词条、方法、依赖、参数及未评原因，并冻结配置。应声明选区或整记录范围；整记录分块应保留各窗原始坐标、执行覆盖、来源缺口和未评原因。未经验证，不应按疾病或任务改变阈值。

应依据各词条前提选择方法。辅助导联、位置或标注缺失时，只限制依赖该信息的检查，不应将其余已完成的技术测量一并作废，也不应省略未评项目。

### 4.5 坐标与统计

结果应定位到原始通道及时间或样本坐标，并声明区间端点、统计分母与未覆盖部分。重叠时段应按声明规则合并计时；未定义合并规则时，只报告原始观测数与对应窗口，不输出总异常时长。

通道数、通道对数、事件数和分段数不应混用；未评部分不应计为正常。比例应有明确的分子、分母和去重规则。计算内部单位与展示单位不同时，应说明转换；不可计算或非有限数值应保存为 null 并记录状态或原因，不应补为零。

### 4.6 状态与判定

应区分未选择、条件不足、执行失败、完成检查和待复核。模块状态、方法状态、候选状态和人工决定应分别记录。计算完成不等于质量合格，未检出候选不等于不存在质量问题。

生理变化、病理活动及任务响应不应直接判为技术伪迹。自动候选应保留理由和证据，人工确认应遵循可记录的复核程序，不覆盖初始算法结果。

### 4.7 语言一致性

中文与英文应分开呈现。语言切换不应改变原始名称、稳定标识、数值、单位、配置和判定。

## 5 模块要求

本章保留 M01–M09 实施模块的职责与跳转。检查要求按评价目的定义，模块是其实现映射；替换算法或软件后仍应保持词条语义、输出与验证要求。详细计算口径以[检查规则](/standards/eeg-checks)及本次冻结配置为准。

### 5.1 M01 数据接入与结构核验

对应 EEG-001 文件、来源与结构核验。

- 应通过格式适配器核对文件结构、记录长度、通道、时钟、标定及主文件和必要成员的指纹。
- 应输出技术头、单位转换依据和结构问题；可读性不应代替信号质量结论。不同格式缺少的硬件标定信息应明确标记，不借用其他格式的能力声明。

[模块说明](/standards/modules/M01)

### 5.2 M02 数据画像与检查计划

对应 EEG-002 信息、参考与检查范围。

- 应依据 M01 结果和确认的选区核对适用性，记录流、原始通道、参考、比较组、依赖、参数和配置标识。
- 应输出数据画像、执行集合和未评原因；背景标签不应单独产生质量扣分。选区实际边界与原生样本数应保留，不以请求时长代替实际读取范围。

[模块说明](/standards/modules/M02)

### 5.3 M03 信号完整性

对应 EEG-003 非有限值、恒值与端点线索。

- 应分别定义非有限值、恒值及端点候选，记录时间窗、容差、最短持续时间与保护范围。
- 应输出候选类别、通道、区间与指标；低幅活动不应混称恒值，端点平台不应直接归因为硬件饱和。没有有效模数转换端点标定时，不应声称已完成硬件端点核验。

[模块说明](/standards/modules/M03)

### 5.4 M04 频谱与窄带干扰

对应 EEG-004 Welch 功率谱密度、EEG-005 窄带工频线索、EEG-006 谱模型与 alpha 描述。

- 应记录谱估计窗口、窗函数、重叠、去趋势、分辨率、功率单位和统计方法；窄带检查应限于可测频带，条件不足部分应标记未评。
- 工频候选应记录中心频率、扫描频带、背景估计或比较方法、观测窗口和判据；使用独立比较频带时还应记录其边界。谱峰不单独证明电源干扰。
- 应分别输出谱峰、背景谱、频带功率与模型拟合状态；alpha 或非周期成分的描述不应直接换算为通用质量分，也不应以缺少 alpha 判定记录无效。

[模块说明](/standards/modules/M04)

### 5.5 M05 通道质量候选

对应 EEG-007 非空间坏道候选。

- 应核对参考、比较组及方法所需位置条件，在可比通道集合内计算。组内统计量应说明有效通道集合、排除规则和阈值是否实际启用。
- 应输出通道身份、分项指标、阈值、覆盖及候选理由；整段候选不应补造时段，通道对不应等同已确认坏道。来源坏道标签应与算法输出独立保存；方法之间一致不代替独立标注验证。

[模块说明](/standards/modules/M05)

### 5.6 M06 生理伪迹线索

对应 EEG-008 辅助信号锁时线索、EEG-009 高频活动线索。

- 应核对辅助信号角色、采样时钟及完整性保护范围，分别记录锁时与高频分析。辅助事件检测成功不代表同时检测到了 EEG 污染。
- 应输出事件、指标和辅助支持状态；生理事件不应直接判为污染，无充分证据的高频活动不应确认为肌电。辅助通道缺失、恒值或片段不足应分别记录。

[模块说明](/standards/modules/M06)

### 5.7 M07 状态与事件核对

对应 EEG-010 标注与时间核对。

- 应核对标注来源、定义、时间单位、顺序、越界、重叠及覆盖，保留原始时间和映射关系。
- 应区分睡眠、任务、临床事件和质量标签；缺少标注不应判为正常，未提取不应写为已确认无标注，时间映射不应代替硬件同步测量。

[模块说明](/standards/modules/M07)

### 5.8 M08 分项评价与汇总

对应 EEG-011 分项证据与检查覆盖。

- 应汇总实际结果、覆盖和未评原因，保留分项原值及评价配置。每项结论应能追溯到词条、实际方法及其产物。
- 未建立独立校准时，不应输出已校准的质量等级或外部标准合格结论。可输出明示公式与版本的项目试行指数，按[评分规则](/standards/eeg-scoring)实施；未评项不应计为满分，执行覆盖不得换算为质量分。

[模块说明](/standards/modules/M08)

### 5.9 M09 报告与复核

对应 EEG-012 报告、追溯与人工复核。

- 应保持报告、图示和结构化结果的通道、时间、单位及状态一致；未复核结果应明确标识。报告章节和字段遵循[报告要求](/standards/eeg-report)。
- 人工复核应独立于算法产物追加保存，记录候选标识、结论、理由、人员标识、时间及版本，防止并发覆盖。质量报告不应替代临床诊断。

[模块说明](/standards/modules/M09)

## 6 评价与报告

### 6.1 指标与阈值

指标应记录方法、单位、参数、统计范围、有效样本或通道数和适用条件。阈值应记录来源、性质、适用范围与验证依据；自适应阈值还应记录估计数据、估计方法和启用状态。

软件默认值、统计显著性水平和本项目试验参数不应称为行业合格线。尚无独立验证的判据可作为明确标识的候选筛查规则，不应表述为普遍适用的合格或不合格结论。外部资料原文、项目转化要求和算法实现应可分别查阅。

### 6.2 比较与总分

比较应核对参考、采样、带宽、处理史、状态、检查覆盖及配置版本。同一疾病或同一文件格式不足以保证指标可比；不同定义的同名指标不得直接混合。

项目试行分数应事先固定用途、公式、通道权重、缺项与版本规则，并与检测证据一同展示。EEG 基础指数按[评分规则](/standards/eeg-scoring)实施，分项采用通道异常占比均方根，总分取最低分项；其有效性尚待专家独立评价。未完成必要测量时总分为 null。已校准等级与行业合格线在独立验证完成前不建立。

### 6.3 报告内容

| 章节 | 必须记录 |
| --- | --- |
| 记录概览 | 记录来源、版本、校验值、物种与记录位置状态、通道及采集信息、缺项 |
| 覆盖与适用性 | 输入与实际分析范围、通道与频带、选区或整记录、未覆盖部分、方法适用限制 |
| 分项证据 | 检查词条、执行状态、观察量、单位、分母、阈值性质及证据位置 |
| 候选与波形 | 候选类型、原始坐标、理由、展示范围和显示处理；无定位时明确说明 |
| 方法与来源 | 规则版本、方法实现、依赖环境、实际参数、来源与冻结计划 |
| 复核与限制 | 复核状态、决定与版本、未评或失败原因、试行评分版本与校准状态、解释边界 |

详细字段、条件要求与当前产物位置见[EEG 质控报告](/standards/eeg-report)。字段值未知时，应报告其未知状态；不应为了凑齐报告表格而推测补全。

### 6.4 结果一致性

图示应标明展示范围及显示处理。包络预览应保留桶内极值时序，不应作为原生全样本显示；仅有整窗或通道对定位的候选不应补造精确异常时段。结构化结果应保留复算所需参数、坐标和证据引用；报告生成不应作为检测准确或已复核的证明。

项目规则快照应记录目录版本、校验值、检查标识、执行状态及证据引用。快照只说明本次报告如何对应项目规则，不构成自动符合性认证。失败、跳过、部分可评及缺少证据的条目应继续可见。

## 7 验证

### 7.1 验证方案

方法应声明适用范围、验证目标、输入、预期行为和验收准则；工程正确性、检测性能及应用效用应分别记录。每个检查词条应能对应验证记录和已知限制；“有测试”不等于完成全部验证层次。

### 7.2 工程验证

应核验读取与标定、通道身份、时间映射、适用性、依赖、错误与取消处理、数据保全及报告一致性。支持与不支持的输入均应有处理验证。数值测量应记录参考值或独立复算方法、允许误差及边界条件。

### 7.3 检测性能

宜用已知故障注入核对定位、单位和边界，并用独立真实标签评价误报与漏检。注入结果不应代替自然伪迹评价；少量示例跑通不应称为总体准确率。

标签应记录类别、粒度、依据、复核程序和分歧处理；生理、病理、技术故障及不确定样例应分别保留。检测评价应说明比较单位是通道、事件、时间段还是样本，以及匹配容差、有效分母和不确定标签处理方式。

### 7.4 数据隔离与证据

开发与最终评价应按受试者、会话或实际依赖关系隔离；最终评价标签不应进入检测器或调参过程。

验证记录应说明数据量、设备、参考、状态、异常类型及未验证条件。不一致结果和负结果应保留。尚未完成独立专家验证时，应明确披露，不能以报告结构完整、公开数据数量或方法数量替代。

## 8 变更管理

规范、检查词条、方法、配置和软件应分别标识版本。变更应记录依据、生效范围及相关验证结果；历史配置与结论不应被覆盖。输入字段与标注映射修订应生成新版本，并保留原始标签、对应关系及依据。

实现说明应与实际能力一致，未满足的要求应明确披露。新增规则快照不应回填为旧任务运行时已经使用的规则；对历史任务重新整理时，应注明整理时间、原始运行版本与整理规则版本。
