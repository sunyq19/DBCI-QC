# 模块协作页

[打开模块协作页](https://sunyq19.github.io/DBCI-QC/) · [质控台](http://10.100.21.50:8769/)

用于围绕质控模块讨论方法、修改方案草稿、固定讨论版本。公开链接可查看；输入团队编辑密码即可修改，无需注册账号。

## 使用

1. **连接关系**：选中模块直接改标题、正文；拖动调整位置，从右侧圆点拉出连线。点击连线可写说明或删除。
2. **层级流程**：展开模块选择子项，使用同一编辑区；可直接添加模块或子模块。
3. **附件与批注**：模块内添加图片、PDF、Office、文本或 CSV 等资料；批注可标为已处理。
4. **保存**：一键保存草稿；“存为版本”把文字、附件、连接和批注一起固定，再分享版本链接。
5. **可视化示例**：10 个已接入子模块提供真实效果图、CSV 测量数据及公开原始数据链接；点击图片放大。脑地形图和雷达图仍标为待接入。
6. **参考说明**：需要核对实现时，再展开查看从质控台同步的输入、输出、适用条件和评分规则。

共同草稿不是自动生效的算法配置。团队形成意见后，由开发修改质控台代码，再同步新的实现说明。

## 密码编辑与旧版起草

- 右上角“编辑”输入团队密码；可填写批注署名，无需账号或独立编辑链接。
- 从版本下拉框或“修改历史”打开任意已保存版本，点击“基于此版修改”。
- 修改后“另存草稿”，记录来源版本。原版和其后的历史均保留。需要对外固定讨论结论时，再点击“存为版本”。
- 起草保留来源版本的方案、批注和布局；当前实现同步到最新代码目录。不是修改历史快照，也不会把旧算法直接设为运行配置。
- 共同草稿若被他人更新，保存会提示冲突并保留输入，不会静默覆盖。

部署时通过私密运行变量 `FLOW_EDIT_PASSWORD_VERIFIER` 设置 PBKDF2-SHA256 密码校验值（10万次迭代、随机盐），不把密码放入源码。编辑会话8小时有效，结束编辑即时失效，修改密码校验值后旧会话失效。旧成员链接不再授权写入。署名仅用于讨论辨认，不代表实名验证。

## 同步与版本

- 质控台模块及评分规则是代码生成的只读来源。合并到 `main` 后，`Sync QC module catalog` 自动生成并校验目录。
- 页面从共同后端读取当前草稿和版本，不在前端另存一份公开数据。访问草稿时检查新目录，缓存最多5分钟；已打开页面提示加载新版，不打断正在输入的内容。
- 正文、附件、连线、批注和原团队记录按稳定模块编号保留，目录同步不覆盖。移除的模块保留记录并标为未接入。
- 保存使用版本检查；同时修改时拒绝覆盖并保留当前页面的输入，可导出备份后合并。
- 历史和固定版本只追加、不改写。固定讨论版本不等于通过专家审核。

## 开发与部署

Node.js 24，Python 3.11+。安装依赖后：

```bash
node scripts/sync-catalog.mjs
node scripts/build-pages.mjs
```

`config/navigation.json` 统一配置公开网址、后端及质控台入口。后端发布后运行 `scripts/publish-pages.mjs` 发布公开前端。数据库结构使用追加的 Drizzle 迁移；不得重写已应用的迁移和固定版本。

- `lib/sync.ts`：按编号同步当前实现，保留协作内容。
- `lib/repository.ts`：草稿、批注、修改历史与固定版本。
- `lib/access.ts`：密码核验、临时编辑会话及退出。
- `app/draft-canvas.tsx`、`app/draft-panel.tsx`：可拖动连接的画布与直接编辑区。
- `app/api/attachments/route.ts`：附件上传与读取；D1 保存索引，R2 `BUCKET` 保存文件。单个10 MiB，每模块最多10个。删除草稿中的引用不删除历史版本的附件。
- `content/visual-examples.json`、`public/visual-examples/`：真实可视化预览、测量数据及来源说明。
- `content/module-catalog.json`、`content/sync-manifest.json`、`content/scoring-rules/`：生成文件，应修改对应质控台来源。

协作页分享模块方案、附件和公开示例。附件随版本公开查看，原始 EEG 文件不打包到页面中。实际质检仍在质控台执行。

检查：`node scripts/test-flow.mjs` 覆盖版本、同步、密码、附件和示例文件；`node node_modules/typescript/bin/tsc --noEmit` 检查类型。
